# [등굣길](https://school.programmers.co.kr/learn/courses/30/lessons/42898)

## 문제 설명
계속되는 폭우로 일부 지역이 물에 잠겼습니다. 물에 잠기지 않은 지역을 통해 학교를 가려고 합니다. 집에서 학교까지 가는 길은 m x n 크기의 격자모양으로 나타낼 수 있습니다.

아래 그림은 m = 4, n = 3 인 경우입니다.

<img src="https://asset.programmers.co.kr/files/ybm/056f54e618/f167a3bc-e140-4fa8-a8f8-326a99e0f567.png">

가장 왼쪽 위, 즉 집이 있는 곳의 좌표는 (1, 1)로 나타내고 가장 오른쪽 아래, 즉 학교가 있는 곳의 좌표는 (m, n)으로 나타냅니다.

격자의 크기 m, n과 물이 잠긴 지역의 좌표를 담은 2차원 배열 puddles이 매개변수로 주어집니다. 오른쪽과 아래쪽으로만 움직여 집에서 학교까지 갈 수 있는 최단경로의 개수를 1,000,000,007로 나눈 나머지를 return 하도록 solution 함수를 작성해주세요.

## 제한사항
- 격자의 크기 m, n은 1 이상 100 이하인 자연수입니다.
- m과 n이 모두 1인 경우는 입력으로 주어지지 않습니다.
- 물에 잠긴 지역은 0개 이상 10개 이하입니다.
- 집과 학교가 물에 잠긴 경우는 입력으로 주어지지 않습니다.

## 입출력 예
|m|n|puddles|return|
|--|--|------|--|
|4|3|\[\[2, 2]]|4|

## ver1. BFS & DP
```
const int dx[]={-1, 0, 1, 0};
const int dy[]={0, -1, 0, 1};
int solution(int m, int n, vector<vector<int>> puddles) {
    vector<vector<int>> dp(n+1, vector<int>(m+1, 0));
    vector<vector<int>> v(n+1, vector<int>(m+1, 1));
    for(int i=0; i<puddles.size(); i++)
        v[puddles[i][1]][puddles[i][0]]=0;
    
    queue<pair<int,int>> q;
    q.push({1,1});
    for(int x, y; !q.empty(); q.pop())
    {
        y=q.front().first, x=q.front().second;
        for(int i=0, nx, ny; i<4; i++)
        {
            ny=y+dy[i], nx=x+dx[i];
            if(nx<1||ny<1||nx>m||ny>n) continue;
            if(v[ny][nx]==0) continue;
            if(v[ny][nx]>1 && v[y][x]+1>v[ny][nx]) continue;
            
            if(v[ny][nx]==1) v[ny][nx]+=v[y][x];
            dp[ny][nx]++;
            q.push({ny,nx});
        }
    }
    
    int answer = dp[n][m];
    return answer;
}
```
### 시간복잡도
- visited 없어서 같은 노드가 큐에 재삽입
- 최악 경우 노드 하나가 여러번 큐에 들어감 + 4방향 탐색 재삽입 = 삽입횟수 그리드 크기에 대해 지수적 증가

### 문제점
- 종료 조건 부재: pop()은 하지만 재방문 막는 장치 없음 = 큐 계속 불어남
- v\[ny]\[nx]==1 일 때만 갱신: 첫 방문만 v 세팅 (이후에 X) =
- dp\[ny]\[nx]++: 경로 개수 X, 간선 개수

## ver2. ver1에서 중복 삽입 제거
```
const int dx[]={-1, 0, 1, 0};
const int dy[]={0, -1, 0, 1};
int solution(int m, int n, vector<vector<int>> puddles) {
    vector<vector<int>> dp(n+1, vector<int>(m+1, 0));
    vector<vector<bool>> vis(n+1, vector<bool>(m+1, false));
    vector<vector<int>> v(n+1, vector<int>(m+1, 1));
    for(int i=0; i<puddles.size(); i++)
        v[puddles[i][1]][puddles[i][0]]=0;
    
    queue<pair<int,int>> q;
    q.push({1,1});
    vis[1][1]=true;
    for(int x, y; !q.empty(); q.pop())
    {
        y=q.front().first, x=q.front().second;
        for(int i=0, nx, ny; i<4; i++)
        {
            ny=y+dy[i], nx=x+dx[i];
            if(nx<1||ny<1||nx>m||ny>n) continue;
            if(v[ny][nx]==0) continue;
            if(vis[ny][nx] && v[y][x]+1>v[ny][nx]) continue;
            
            if(v[ny][nx]==1) v[ny][nx]+=v[y][x];
            if(dp[ny][nx]==0) 
            {
                q.push({ny,nx});
                if(ny>1) dp[ny][nx]+=dp[ny-1][nx];
                if(nx>1) dp[ny][nx]+=dp[ny][nx-1];
            }
            else dp[ny][nx]++;   
            vis[ny][nx]=true;
        }
    }
    
    int answer = (dp[n-1][m]+dp[n][m-1])%1000000007;
    return answer;
}
```
### 시간복잡도
- dp\[ny]\[nx]==0일 때만 push = 노드 당 최대 1번만 큐에 들어감 (단, 부모가 여럿일 수 있으니 dp\[ny]\[nx]는 계속됨)
- 각 노드는 1번만 BFS 대상. 간선 수는 (O(nm)(4방향 그리드))
- v 갱신도 첫 방문 시 1회 제한이므로, 무한 갱신 X

### 문제점
- dp\[ny]\[nx]: 경로 수 X, 간선 수(ver1과 같은 문제)
- answer = dp\[n-1]\[m]+dp\[n]\[m-1]: 이미 dp에 정상 값 아님
- v, vis(BFS 구조) 불필요: 단조 격자 DAG

## ver+. 2중 for문 DP
```
int solution(int m, int n, vector<vector<int>> puddles) {
    vector<vector<int>> dp(n+1, vector<int>(m+1, 0));
    vector<vector<int>> v(n+1, vector<int>(m+1, 1));
    for(int i=0; i<puddles.size(); i++)
        v[puddles[i][1]][puddles[i][0]]=0;
    
    dp[1][1]=1;
    for(int y=1; y<=n; y++)
    {
        for(int x=1; x<=m; x++)
        {
            if(x==1&&y==1) continue;
            if(v[y][x]==0) continue;
            dp[y][x]=(dp[y-1][x]+dp[y][x-1])%1000000007;
        }
    }
    
    int answer = dp[n][m];
    return answer;
}
```
### 시간복잡도
- O(n * m)

### 핵심
- dp\[y]\[x] += dp\[predecessor] (= dp\[y-1]\[x]+dp\[y]\[x-1]) = 경로 수 누적
- 웅덩이는 puddle로 체크해서 그 칸 유지

# [최적의 행렬](https://school.programmers.co.kr/learn/courses/30/lessons/12942)

## 문제 설명
크기가 a by b인 행렬과 크기가 b by c 인 행렬이 있을 때, 두 행렬을 곱하기 위해서는 총 a x b x c 번 곱셈해야합니다.
예를 들어서 크기가 5 by 3인 행렬과 크기가 3 by 2인 행렬을 곱할때는 총 5 x 3 x 2 = 30번의 곱하기 연산을 해야 합니다.

행렬이 2개일 때는 연산 횟수가 일정 하지만, 행렬의 개수가 3개 이상일 때는 연산의 순서에 따라서 곱하기 연산의 횟수가 바뀔 수 있습니다. 
예를 들어서 크기가 5 by 3인 행렬 A, 크기가 3 by 10인 행렬 B, 크기가 10 by 6인 행렬 C가 있을 때, 
순서대로 A와 B를 먼저 곱하고, 그 결과에 C를 곱하면 A와 B행렬을 곱할 때 150번을, AB 에 C를 곱할 때 300번을 연산을 해서 총 450번의 곱하기 연산을 합니다. 
하지만, B와 C를 먼저 곱한 다음 A 와 BC를 곱하면 180 + 90 = 270번 만에 연산이 끝납니다.

각 행렬의 크기 matrix_sizes 가 매개변수로 주어 질 때, 모든 행렬을 곱하기 위한 최소 곱셈 연산의 수를 return하는 solution 함수를 완성해 주세요.

## 제한 사항
- 행렬의 개수는 3이상 200이하의 자연수입니다.
- 각 행렬의 행과 열의 크기는 200이하의 자연수 입니다.
- 계산을 할 수 없는 행렬은 입력으로 주어지지 않습니다.

## 입출력 예
|matrix_sizes|result|
|-|-|
|/[/[5,3],/[3,10],/[10,6]]|270|

## ver1. 그리디 + 재귀
```c++
void func(vector<int> &v, int &ans)
{
    int idx, mul=INT_MAX;
    for(int i=0, t; i+2<v.size(); i++)
    {
        t=v[i]*v[i+2];
        if(t<mul) idx=i, mul=t;
    }
    
    ans+=v[idx]*v[idx+1]*v[idx+2];
    v.erase(v.begin()+idx+1);
    if(v.size()>2) func(v, ans);
}

int solution(vector<vector<int>> matrix_sizes) {
    vector<int> v;
    for(vector<int> &t:matrix_sizes)
    {
        if(v.empty()) v.push_back(t[0]);
        v.push_back(t[1]);        
    }
        
    int answer = 0;
    func(v, answer);
    
    return answer;
}
```
### 시간복잡도
- 재귀 n-2 번 반복
  - 재귀 1회 = 최솟값 탐색 + erase = O(n) + O(n)
- = O(n^2)

### 동작 원리
- matrix_sizes를 차원 배열 v로 변환
- v\[i]*v\[i+2]가 최소인 위치 i를 찾음
- 그 위치의 곱셈 비용 v\[i]*v\[i+1]*v\[i+2]를 ans에 더함
- 가운데 차원 v\[i+1]을 삭제 = 두 행렬 하나로 합쳐짐
- v의 크기가 2가 될때까지 재귀

### 문제점
- 그리디 최적 보장 X
- 행렬 1개 경우 for문 돌지 않아 초기화되지 않은 idx 사용하는 미정 동작
- 재귀,erase 반복 = 비효율적

## ver+. 구간 DP
```c++
int solution(vector<vector<int>> matrix_sizes) {
    vector<int> p;
    for(vector<int> &v:matrix_sizes)
    {
        if(p.empty()) p.push_back(v[0]);
        p.push_back(v[1]);
    }
    
    const int S=matrix_sizes.size();
    vector<vector<int>> dp(S, vector<int>(S,0));    // 행렬 i~j까지 최소
    for(int n=2; n<=S; n++)
        for(int i=0, j=i+n-1; j<S; i++, j++)
        {
            dp[i][j]=INT_MAX;
            for(int k=i; k<j; k++)
                dp[i][j]=min(dp[i][j], dp[i][k]+dp[k+1][j]+p[i]*p[k+1]*p[j+1]);
        }
        
    
    int answer = dp[0][S-1];
    return answer;
}
```
### 시간복잡도
- 구간 = O(n^2)
- 분할점 k 시도 = O(n)
- = O(n^3)

### 동작 원리
- 차원 배열 p 만듦(행렬 n개면, 크기는 n+1)
- dp\[i]\[j]는 i~j번 행렬을 곱하는 최소 비용 (단일 행렬(i==j)는 0)
- 구간 길이 n을 2부터 S까지 늘리며 모든 구간 계산
- 각 구간을 k에서 나눠 dp\[i]\[k] + dp\[k+1]\[j] + p\[i]*p\[k+1]*p\[j+1]의 최솟값 취함
- dp\[0]\[S-1] = 정답

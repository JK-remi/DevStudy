# [유사 칸토어 비트열](https://school.programmers.co.kr/learn/courses/30/lessons/148652#)

## 문제 설명
수학에서 칸토어 집합은 0과 1 사이의 실수로 이루어진 집합으로, \[0, 1]부터 시작하여 각 구간을 3등분하여 가운데 구간을 반복적으로 제외하는 방식으로 만들어집니다.

남아는 칸토어 집합을 조금 변형하여 유사 칸토어 비트열을 만들었습니다. 유사 칸토어 비트열은 다음과 같이 정의됩니다.

- 0 번째 유사 칸토어 비트열은 "1" 입니다.
- n(1 ≤ n) 번째 유사 칸토어 비트열은 n - 1 번째 유사 칸토어 비트열에서의 1을 11011로 치환하고 0을 00000로 치환하여 만듭니다.

남아는 n 번째 유사 칸토어 비트열에서 특정 구간 내의 1의 개수가 몇 개인지 궁금해졌습니다.
n과 1의 개수가 몇 개인지 알고 싶은 구간을 나타내는 l, r이 주어졌을 때 그 구간 내의 1의 개수를 return 하도록 solution 함수를 완성해주세요.

## 제한사항
- 1 ≤ n ≤ 20
- 1 ≤ l, r ≤ 5n
  - l ≤ r < l + 10,000,000
  - l과 r은 비트열에서의 인덱스(1-base)이며 폐구간 \[l, r]을 나타냅니다.

## 입출력 예
|n|l|r|result|
|--|--|--|--|
|2|4|17|8|

### 입출력 예 설명
2 번째 유사 칸토어 비트열은 "110 **\[11110110000011]* 01111011" 입니다. 음영 표시된 부분은 폐구간 \[4, 17] 이며 구간 내의 1은 8개 있습니다.

## ver1. 스택 기반 재귀적 구간 확장-절단
```c++
const vector<string> cantor = {"00000","11011"};
int solution(int n, long long l, long long r) {
    stack<pair<long long,long long>> st;
    
    for(long long tl=l-1, tr=r-1, i=0; i<n; i++, tl/=5, tr/=5)
        st.push({tl,tr});
    
    int answer = 0;
    for(string str = "1", tmp=""; !st.empty();)
    {
        tmp="";
        int cnt=0;
        for(int i=0; i<str.length(); i++)
        {
            tmp+=cantor[str[i]-'0'];
            cnt+=str[i]=='1';            
        }
        if(cnt==0) return 0;
        
        auto [nl, nr] = st.top();
        st.pop();
        str=tmp.substr(nl%5ll, nr-nl+1);
        
        if(st.empty())
        {
            for(int i=0; i<str.length(); i++)
                answer+=str[i]=='1';
            break;
        }
    }
    
    return answer;
}
```
## 시간복잡도
- O(n + (r-l))
  - 요청 구간의 폭(r-l)에 비례
- 매 단계 문자열 5배 불어났다가 필요한만큼 잘림
  - 이 폭이 기하급수(공비 1/5)로 줄어들며 합쳐짐
  - 총 작업량 = 최종 폭(r-l, 최대 10,000,000)의 상수배

## 동작 원리
- (l-1, r-1)을 0-indexed로 두고, 5로 반복해서 나누며 (tl, tr)쌍을 스택에 쌓음
  - 트리 구조에서 루트로 거슬러 올라감
- 스택을 pop 하면서 실제 문자열 str을 만듦
  - 매 단계마다 현재 str의 각 글자를 "11011"/"00000"으로 치환해 5배 늘린 tmp만듦
  - 필요 구간만 substr로 잘라내 str 갱신
- 스택이 비면(원래 목표 위치까지 처리) 마지막 str에서 '1'의 개수를 세어 반환
- 중간에 str에 '1'이 하나도 없으면 바로 0을 반환해 가지치기

## 문제점
- 시간/메모리가 실제 쿼리 폭(r-l)에 비례
  - 제약(r-l<10,000,000)에서는 통과하지만 제약 큰 경우 문자열 만드는 방식이 부담
- **부분 문자열을 실제로 생성**하는절차적 방식이라 경계 처리 버그나귀 쉬움
  - 경계: 블록 경계를 걸치는 구간, l=1같은 극단값
- 매 단계 string을 새로 할당/복사하므로 상수 계수가 상대적으로 큼

## ver+.
```c++
long long f(int level, long long pos, const long long* pw5, const long long* ones) {
    if (pos <= 0) return 0;
    if (level == 0) return 1;
    long long blockSize = pw5[level - 1];
    long long q = (pos - 1) / blockSize;        // 몇 번째 블록까지 걸치는지 (0~4)
    long long rem = (pos - 1) % blockSize + 1;  // 그 블록 안에서 몇 번째까지

    long long result = 0;
    for (long long b = 0; b < q; b++)
        result += (b == 2) ? 0 : ones[level - 1]; // 완전히 포함된 블록: 표만 더함
    result += (q == 2) ? 0 : f(level - 1, rem, pw5, ones); // 걸친 블록만 재귀

    return result;
}

int solution(int n, long long l, long long r) {
    long long pw5[21], ones[21];
    pw5[0] = 1;
    ones[0] = 1;
    for (int i = 1; i <= n; i++) {
        pw5[i] = pw5[i-1] * 5;
        ones[i] = ones[i-1] * 4;
    }
    return (int)(f(n, r, pw5, ones) - f(n, l - 1, pw5, ones));
}
```
## 시간복잡도
- O(n)
  - 재귀 깊이 = n (최대 20)
  - 각 레벨 하는 일 = 블록 번호 계산 + 최대 4개 블록 합산 = 상수 시간

## 동작 원리
- f(level, pos) = **level 번째 비트열의 앞에서부터 pos개 안에 있는 1의 개수"로 정의
- 정답 = f(n, r) - f(n, l-1)
  - 누적합의전형적인 **구간 합 = 오른쪽 누적-왼쪽 누적**
- f 내부에서는 pos가 속한 블록 번호(q, 0~4)와 그 블록 안에서의 위치(rem)를 계산
- q보다 앞선, 완전히 포함된 블록들은재귀 없이 미리 계산해둔 ones\[level-1]를 더함
- 마지막에 걸친 q번째 블록만 f(level-1, rem)으로 재귀 호출
  - 매 레벨 재귀 호출 = 1번
- level==0에서 재귀 종료 (길이 1인 문자열이므로, pos>=1이면 1반환)

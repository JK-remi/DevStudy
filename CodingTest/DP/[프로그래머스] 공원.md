# [공원](https://school.programmers.co.kr/learn/courses/30/lessons/340198)

## 문제 설명
지민이는 다양한 크기의 정사각형 모양 돗자리를 가지고 공원에 소풍을 나왔습니다. 공원에는 이미 돗자리를 깔고 여가를 즐기는 사람들이 많아 지민이가 깔 수 있는 가장 큰 돗자리가 어떤 건지 확인하려 합니다. 
예를 들어 지민이가 가지고 있는 돗자리의 한 변 길이가 5, 3, 2 세 종류이고, 사람들이 다음과 같이 앉아 있다면 지민이가 깔 수 있는 가장 큰 돗자리는 3x3 크기입니다.

<img src="https://grepp-programmers.s3.ap-northeast-2.amazonaws.com/files/production/b303f9e8-1d3e-4e44-a75e-e8deb64c8e6c/10.jpg">

지민이가 가진 돗자리들의 한 변의 길이들이 담긴 정수 리스트 mats, 현재 공원의 자리 배치도를 의미하는 2차원 문자열 리스트 park가 주어질 때 지민이가 깔 수 있는 가장 큰 돗자리의 한 변 길이를 return 하도록 solution 함수를 완성해 주세요. 아무런 돗자리도 깔 수 없는 경우 -1을 return합니다.

## 제한사항
- 1 ≤ mats의 길이 ≤ 10
  - 1 ≤ mats의 원소 ≤ 20
  - mats는 중복된 원소를 가지지 않습니다.
- 1 ≤ park의 길이 ≤ 50
1 ≤ park\[i]의 길이 ≤ 50
  - park\[i]\[j]의 원소는 문자열입니다.
  - park\[i]\[j]에 돗자리를 깐 사람이 없다면 "-1", 사람이 있다면 알파벳 한 글자로 된 값을 갖습니다.

## 입출력 예
|mats|park|result|
|---|----------------|--|
|\[5,3,2]|\[\["A", "A", "-1", "B", "B", "B", "B", "-1"], \["A", "A", "-1", "B", "B", "B", "B", "-1"], \["-1", "-1", "-1", "-1", "-1", "-1", "-1", "-1"], \["D", "D", "-1", "-1", "-1", "-1", "E", "-1"], \["D", "D", "-1", "-1", "-1", "-1", "-1", "F"], \["D", "D", "-1", "-1", "-1", "-1", "E", "-1"]]|3|

## ver1. 칸 별 정사각형 확장 탐색 (Brute-force)
```
int w,h;
bool func(const vector<vector<string>> &park, int depth, pair<int,int> pos)
{
    int y=pos.first+depth, x=pos.second+depth;
    if(y>=h || x>=w) return false;
    if(park[y][x][0]!='-') return false;
    
    for(int i=1; i<=depth; i++)
    {
        if(park[y-i][x][0]!='-') return false;
        if(park[y][x-i][0]!='-') return false;
    }
    
    return true;
}

int solution(vector<int> mats, vector<vector<string>> park) {
    h=park.size(), w=park[0].size();
    vector<vector<int>> p(h, vector<int>(w, 0));
    int tmp=0;
    for(int i=0; i<h; i++)
        for(int j=0; j<w; j++)
            if(park[i][j][0]=='-')
            {
                p[i][j]=1;
                for(int t=1; func(park, t, {i,j}); t++)
                    p[i][j]++;
                tmp=max(tmp,p[i][j]);
            }
    
    int answer = -1;
    sort(mats.begin(), mats.end(), greater<int>());
    for(int i=0; i<mats.size()&&answer<0; i++)
        if(tmp>=mats[i])
            answer=mats[i];
    
    return answer;
}
```
### 시간복잡도
- depth마다 O(t)만큼 동작 = O(k^2)
  - k = (i,j)에서 가능한 최대 크기
- k는 최대 min(h, w)까지 커질 수 있으므로, 시작점 하나 당 최악 = O(min(h,w)^2)
- = O(h * w * min(h*w)^2) = 50 * 50 * 2500 = 625만

### 동작 방식
- 비어있는 각 칸 (i,j)을 좌상단 꼭지점 고정
- depth늘려가며 func 호출해 그 크기 정사각형 유효 검사

## ver+. DP
```
int solution(vector<int> mats, vector<vector<string>> park) {
    int h = park.size(), w = park[0].size();
    vector<vector<int>> dp(h, vector<int>(w, 0));
    int tmp = 0;

    for (int i = 0; i < h; i++)
        for (int j = 0; j < w; j++)
            if (park[i][j][0] == '-')
            {
                if (i == 0 || j == 0) dp[i][j] = 1;
                else dp[i][j] = min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]}) + 1;
                tmp = max(tmp, dp[i][j]);
            }

    sort(mats.begin(), mats.end(), greater<int>());
    for (int m : mats)
        if (tmp >= m) return m;

    return -1;
}
```
### 시간복잡도
- 각 칸 한 번 방문 = O(1)
- 방문 당 작업 = min(3개 값) + 1 = O(1)
- = O(h * w) = 2500

### 동작 방식
- dp\[i]\[j]: **(i,j)를 오른쪽 아래 꼭지점으로 하는 최대 정사각형의 한 변**
- 왼쪽, 위, 대각선 세 칸의 dp값을 이용해 각 칸을 한 번씩 계산

# [보행자 천국](https://school.programmers.co.kr/learn/courses/30/lessons/1832)

## 문제 설명
카카오내비 개발자인 제이지는 시내 중심가의 경로 탐색 알고리즘 개발 업무를 담당하고 있다. 
최근 들어 보행자가 자유롭고 편리하게 걸을 수 있도록 보행자 중심의 교통 체계가 도입되면서 도심의 일부 구역은 자동차 통행이 금지되고, 
일부 교차로에서는 보행자 안전을 위해 좌회전이나 우회전이 금지되기도 했다. 
복잡해진 도로 환경으로 인해 기존의 경로 탐색 알고리즘을 보완해야 할 필요가 생겼다.

도시 중심가의 지도는 m × n 크기의 격자 모양 배열 city_map으로 주어진다. 자동차는 오른쪽 또는 아래 방향으로 한 칸씩 이동 가능하다.

city_map/[i]/[j]에는 도로의 상황을 나타내는 값이 저장되어 있다.

- 0인 경우에는 자동차가 자유롭게 지나갈 수 있다.
- 1인 경우에는 자동차 통행이 금지되어 지나갈 수 없다.
- 2인 경우는 보행자 안전을 위해 좌회전이나 우회전이 금지된다. (왼쪽에서 오던 차는 오른쪽으로만, 위에서 오던 차는 아래쪽으로만 진행 가능하다)

<img src="https://t1.kakaocdn.net/codefestival/oneway500.png">

도시의 도로 상태가 입력으로 주어졌을 때, 왼쪽 위의 출발점에서 오른쪽 아래 도착점까지 자동차로 이동 가능한 전체 가능한 경로 수를 출력하는 프로그램을 작성하라. 
이때 가능한 경로의 수는 컴퓨터가 표현할 수 있는 정수의 범위를 넘어설 수 있으므로, 가능한 경로 수를 20170805로 나눈 나머지 값을 출력하라.

## 입력 형식
입력은 도시의 크기를 나타내는 m과 n, 그리고 지도를 나타내는 2차원 배열 city_map으로 주어진다. 제한조건은 아래와 같다.

- 1 <= m, n <= 500
- city_map의 크기는 m × n이다.
- 배열의 모든 원소의 값은 0, 1, 2 중 하나이다.
- 출발점의 좌표는 (0, 0), 도착점의 좌표는 (m - 1, n - 1)이다.
- 출발점과 도착점의 city_map/[i]/[j] 값은 0이다.

## 출력 형식
출발점에서 도착점까지 이동 가능한 전체 경로의 수를 20170805로 나눈 나머지를 리턴한다.

## 예제 입출력
|m|n|city_map|answer|
|-|-|--------|--|
|3|3|/[/[0, 0, 0], /[0, 0, 0], /[0, 0, 0]]|6|
|3|6|/[/[0, 2, 0, 0, 0, 2], /[0, 0, 2, 0, 1, 0], /[1, 0, 0, 2, 2, 0]]|2|

### 예제에 대한 설명
첫 번째 예제는 모든 도로가 제한 없이 통행 가능한 경우로, 가능한 경우의 수는 6가지이다.
두 번째 예제는 문제 설명에 있는 그림의 경우이다. 가능한 경우의 수는 빨간 실선과 노란 점선 2가지뿐이다.

## ver1. BFS 완전 탐색
```c++
int MOD = 20170805;
struct pos
{
    int y,x;
    int d; // 0:좌우, 1:상하
    pos(int ny, int nx, int nd)
    {
        y=ny, x=nx, d=nd;
    }
    pos(){}
};

// 전역 변수를 정의할 경우 함수 내에 초기화 코드를 꼭 작성해주세요.
int solution(int m, int n, vector<vector<int>> city_map) {
    const int dx[]={1,0}, dy[]={0,1};
    MOD = 20170805;
    
    // 0: 자동차, 1: 자동차X, 2: 직진 only
    queue<pos> q;
    q.push(pos(0,0,-1));
    int answer = 0;
    for(pos p; !q.empty(); q.pop())
    {
        p=q.front();
        
        for(int i=0, nx,ny; i<2; i++)
        {
            ny=dy[i]+p.y, nx=dx[i]+p.x;
            if(ny==m||nx==n||city_map[ny][nx]==1
                || (city_map[p.y][p.x]==2 && i!=p.d)) continue;
            
            if(ny==m-1&&nx==n-1) answer++;
            else q.push(pos(ny,nx,i));
        }
    }
    
    return answer%MOD;
}
```
### 시간복잡도
- 최악 O(경로 수) = 지수적
  - 칸이 아닌 경로의 상태가 쌓이므로, 같은 칸이 경로 수만큼 중복 처리
  - 500 x 500 격자에서는 끝나지 않음

### 동작 원리
- (0,0)에서 시작해 오른쪽, 아래쪽으로만 이동하며, 큐에(좌표, 마지막 이동 방향)을 삽입
- 현재 칸이 2(직진 only)면 들어온 방향과 같은 방향으로만 나감
- 범위를 벗어나거나 1(통행금지)인 칸은 건너 뜀
- 도착 칸에 닿을 때마다 answer++하고, 마지막에 %MOD

### 문제점
- 같은 칸을 반복 방문하는 중복 계산 때문에 시간초과
- 경로 수에 비례해 큐가 커져서 메모리도 위험
- answer에 MOD를 매번 적용하지 않아 경로가 많으면 int 오버플로우 가능성

## ver+. 방향별 상태 분리 DP
```c++
int MOD = 20170805;
void func(const vector<vector<int>> &c, vector<vector<vector<int>>> &dp, int y, int x, int dir)
{
    if(c[y][x]==1) return;
    
    int py=(dir==0)?y:y-1, px=(dir==0)?x-1:x;
    if(py<0||px<0) return;
    
    int type=c[py][px];
    if(type==0)
        dp[y][x][dir]=(dp[py][px][0]+dp[py][px][1])%MOD;
    else if(type==2)
        dp[y][x][dir]=dp[py][px][dir];
}

// 전역 변수를 정의할 경우 함수 내에 초기화 코드를 꼭 작성해주세요.
int solution(int m, int n, vector<vector<int>> city_map) {
    MOD = 20170805;
    
    vector<vector<vector<int>>> dp(m, vector<vector<int>>(n, vector<int>(2,0)));
    dp[0][0][0]=1;
    for(int i=0; i<m; i++)
        for(int j=0; j<n; j++)
            for(int k=0; k<2; k++)
                func(city_map, dp, i, j, k);
    int answer = (dp[m-1][n-1][0]+dp[m-1][n-1][1])%MOD;
    return answer;
}
```
### 시간복잡도
- O(m * n)
  - 칸마다 방향 2개를 상수 시간에 계산
- 공간 = O(m * n)

### 동작 원리
- dp\[y]\[x]\[0]은 (y,x)에 오른쪽 이동으로 도착하는 경우의 수, dp\[y]\[x]\[1]은 아래쪽 이동 도착 경우의 수
- func는 이전칸(dir==0이면 왼쪽, 아니면 위쪽)의 종류를 봄
  - 0이면 이전 칸의 두 방향 값을 합산 (방향 꺾여도 가능)
  - 2이면 이전 칸의 같은 방향 값만 가져옴(직진만 가능)
  - 1이면 아무것도 하지 않으므로, 0만 남음
- 위 → 아래, 왼 → 오른쪽 순서로 순회하므로 이전 칸 값이 항상 먼저 채워져 있음
- 시작값은 dp\[0]\[0]\[0]=1하나만 처리. 둘 다 1이면 시작 칸에서 나갈 때 1+1=2가 되어 모든 경로가 2배
- 정답은 (dp\[m-1]\[n-1]\[0] + dp\[m-1]\[n-1]\[1]) % MOD

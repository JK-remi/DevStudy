# [110 옮기기](https://school.programmers.co.kr/learn/courses/30/lessons/77886)

## 문제 설명
0과 1로 이루어진 어떤 문자열 x에 대해서, 당신은 다음과 같은 행동을 통해 x를 최대한 사전 순으로 앞에 오도록 만들고자 합니다.

- x에 있는 "110"을 뽑아서, 임의의 위치에 다시 삽입합니다.

예를 들어, x = "11100" 일 때, 여기서 중앙에 있는 "110"을 뽑으면 x = "10" 이 됩니다. 뽑았던 "110"을 x의 맨 앞에 다시 삽입하면 x = "11010" 이 됩니다.

변형시킬 문자열 x가 여러 개 들어있는 문자열 배열 s가 주어졌을 때, 각 문자열에 대해서 위의 행동으로 변형해서 만들 수 있는 문자열 중 사전 순으로 가장 앞에 오는 문자열을 배열에 담아 return 하도록 solution 함수를 완성해주세요.

## 제한사항
- 1 ≤ s의 길이 ≤ 1,000,000
- 1 ≤ s의 각 원소 길이 ≤ 1,000,000
- 1 ≤ s의 모든 원소의 길이의 합 ≤ 1,000,000

## 입출력 예
|s|result|
|-|-|
|\["1110","100111100","0111111010"]|\["1101","100110110","0110110111"]|

## ver1. 재귀 find/erase
```c++
const string T="110", O="11";
const int C1=2, L=T.length();
void func(string &str, int idx)
{
    //cout<<str<<','<<idx<<':';
    int n=str.find(T, idx);
    if(n==string::npos) return;
    
    int s=str.find(O, idx);
    if(s!=string::npos && s<n)
    {
        str.erase(n,L);
        str=str.substr(0,s)+T+str.substr(s);
    }
    //cout<<str<<' ';    
    
    func(str,s+L);
}

vector<string> solution(vector<string> s) {
    vector<string> answer(s);
    for(string &str:answer)
        func(str,0);//, cout<<endl;
    return answer;
}
```
### 시간복잡도
- 최악 O(N^2) (erase, substr 재조립을 110마다 반복)
- 재귀 깊이 = O(N)

### 동작 원리
- 110을 찾고, 그보다 앞에 11이 있으면 110ㅇ르 지운 뒤 그 11 앞에 삽입
- 이후 s+L부터 다시 재귀

### 문제점
- 삽입 위치 기준 틀림
  - 정답 = **마지막 0 뒤**
  - 현재 = **처음 나오는 11 앞**
- 연쇄 110 처리 X
  - 110 삭제 후 새로 생기는 110 놓침
- s==n 이면 아무 일도 하지 않고 넘어감
- 재귀 깊이가 최대 약 33만이라 스택 오브플로 위험 + 문자열 복사 = 시간 초과

## ver+1. stack<char> + 앞쪽 prepend
```c++
const string T="110";
const int L=T.length(), C=2;
vector<string> solution(vector<string> s) {
    vector<string> answer(s.size(),"");
    for(int a=0, cnt; a<s.size(); a++)
    {
        stack<char> st;
        cnt=0;
        for(int i=0; i<s[a].length(); i++)
        {
            st.push(s[a][i]);
            
            if(s[a][i]=='0'&&st.size()>=L)
            {
                string tmp="";
                for(int j=0; j<L; j++, st.pop())
                    tmp=st.top()+tmp;
                
                if(tmp==T) cnt++;
                else 
                    for(int j=0; j<L; j++)
                        st.push(tmp[j]);
            }
        }
        
        while(!st.empty())
        {
            if(st.top()=='0')
            {
                for(; cnt>0; cnt--)
                    answer[a]=T+answer[a];
            }
            
            answer[a]=st.top()+answer[a];
            st.pop();
        }
        
        for(; cnt>0; cnt--)
            answer[a]=T+answer[a];
    }
    return answer;
}
```
### 시간복잡도
- 스택 순회 = O(N)
- 결과 조립에서 prepend 반복해 최악 O(N^2)

### 동작 원리
- 문자를 push하다가 0이 들어오면 위 3글자를 꺼내 110인지 확인
  - 맞으면 cnt++로 제거하고, 아니면 다시 push
  - 연쇄 110도 이 방식으로 자동 처리
- 조립은 스택을 뒤에서부터 pop하면서 앞에 붙이다가, 처음 만나는 0(=마지막 0) 직전에 110을 cnt개 붙임
- 이 0은 아직 붙이지 않은 상태라 110이 0뒤에 위치하게 됨
- 0이 없으면 맨 앞에 붙임

### 문제점
- answer\[a]=st.top()+answer\[a]가 호출마다 전체 복사
  - 길이 1,000,000이면 시간초과 위험
  - tmp=st.top()+tmp는 3글자라 무사해도 되지만, 매번 pop/push 반복하는 오버헤드 있음

## ver+2. string 스택 + 일괄 삽입 
```c++
const string T="110";
vector<string> solution(vector<string> s) {
    vector<string> answer(s.size(),"");
    for(int i=0, z, cnt; i<s.size(); i++)
    {
        string tmp; 
        cnt=0, z=0;
        for(int j=0; j<s[i].length(); j++)
        {
            if(s[i][j]=='0'&&tmp.length()>=2)
            {
                if(tmp.back()=='1'&&tmp.back()==tmp[tmp.length()-2])
                {
                    cnt++;
                    for(int k=0; k<2; k++, tmp.pop_back());                    
                }
                else 
                    tmp.push_back(s[i][j]);
            }   
            else 
                tmp.push_back(s[i][j]);
            
            if(!tmp.empty() && tmp.back()=='0')
                z=tmp.length();
        }
        
        answer[i]=tmp.substr(0,z);
        for(int j=0; j<cnt; j++)
            answer[i]+=T;
        answer[i]+=tmp.substr(z);
    }
    return answer;
}
```
### 시간복잡도
- O(N)
  - 각 문자는 push 한 번과 pop최대 한 번
  - 조립은 한 번의 연결

### 동작 원리
- string tmp를 스택으로 사용
- 0이 들어올 때, 끝 두 글자가 11이면 두 글자를 pop하고, cnt++ 아니면 push
- 매번 끝이 0이면 z(마지막 0 바로 뒤 위치) 갱신
- 조립은 tmp.substr(0,z) + "110"*cnt + tmp.substr(z)

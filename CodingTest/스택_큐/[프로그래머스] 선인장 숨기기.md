# [선인장 숨기기](https://school.programmers.co.kr/learn/courses/30/lessons/468379)

## 문제 설명
m개의 행과 n개의 열로 구성된 격자가 주어지며, 이는 사막 지도를 나타냅니다. 사막 지도의 가장 왼쪽 위칸 좌표는 (0, 0), 오른쪽 아래칸 좌표는 (m-1, n-1)입니다. 
이 사막 어딘가에 가로 w, 세로 h 크기의 선인장 구역을 조성하려 합니다. 선인장 구역은 격자 축에 맞춘 연속된 w × h 크기의 부분 격자이며, 회전할 수 없습니다.

비구름은 미리 정해진 순서대로 격자의 여러 칸에 비를 뿌립니다. 이때 빗방울이 처음으로 선인장 구역에 포함된 칸에 떨어졌을 때, 그 시점을 선인장이 처음으로 비를 맞는 순간으로 기록합니다. 
당신은 선인장이 가능한 한 늦게 비를 맞도록, 선인장 구역의 위치를 정하려고 합니다.

- 선인장이 비를 맞지 않도록 선인장 구역의 위치를 정할 수 있다면 해당 위치가 가장 우선됩니다.
- 가능한 늦게 비를 맞는 선인장 구역 후보가 여러 개라면 그중 가장 위쪽 행, 그래도 여러 개면 가장 왼쪽 열에 위치한 구역을 선택합니다.

격자의 세로 길이와 가로 길이를 나타내는 정수 m, n, 선인장 구역의 세로 길이와 가로 길이를 나타내는 정수 h, w, 
그리고 빗방울이 떨어지는 순서대로 칸의 좌표를 담은 2차원 정수 배열 drops가 매개변수로 주어집니다. 
주어진 조건을 만족하는 선인장 구역에 포함된 가장 왼쪽 위칸의 좌표를 정수 배열로 return 하도록 solution 함수를 완성해 주세요.

## 제한사항
- 1 ≤ m, n ≤ 500,000
- 1 ≤ m × n ≤ 500,000
- 1 ≤ h ≤ m
- 1 ≤ w ≤ n
- 1 ≤ drops의 길이 ≤ m × n
  - drops\[i]는 \[r, c] 형태입니다.
  - drops\[i]는 i + 1번째로 떨어진 빗방울의 좌표를 의미합니다.
  - 0 ≤ r < m
  - 0 ≤ c < n
  - drops의 모든 원소는 서로 다른 칸을 나타냅니다.

## ver1. 완전 탐색 (모든 후보 위치 x drops 선형 스캔)
```c++
vector<int> solution(int m, int n, int h, int w, vector<vector<int>> drops) {
    const int M=drops.size();
    
    vector<int> answer(2,0);
    for(int y=0, t=0; y<=m-h && t<M; y++)    
        for(int x=0; x<=n-w && t<M; x++)
        {
            bool f=false;
            for(int i=0, ny, nx; i<M && !f; i++)
            {
                ny=drops[i][0], nx=drops[i][1];
                if((ny>=y && ny<y+h) && (nx>=x && nx<x+w))
                {
                    if(t<i) t=i, answer[0]=y, answer[1]=x;
                    f=true;
                    break;
                }
            }
            
            if(!f) t=M, answer[0]=y, answer[1]=x;
        }
        
    return answer;
}
```
### 시간복잡도
- 후보 수 = m * n
- 후보마다 drops 최대 M번 훑음
- = 최대 2.5*10^11 번

### 동작 원리
- 선인장 구역의 왼쪽 위 좌표 (y,x)를 위쪽, 왼쪽 순으로 하나씩 전부 시도
- 후보마다 drops를 0번부터 순서대로 훑으면서 처음으로 구역 안에 떨어지는 빗방울 의 순번 i를 찾음
- 지금까지의 최고 기록 t보다 i가 크면 정답 좌표 갱신
  - 동률 시 갱신 X (위쪽, 왼쪽 우선 조건 지켜짐)
- 어떤 후보가 끝까지 안 젖으면 t=M으로 두고 반복 종료 = 더 좋은 후보 없음

### 문제점
- 같은 정보 반복 계산
  - 각 칸 몇 번째에 젖는가는 변하지 않음에도 후보마다 drops 전체 다시 검사
- 인접 후보끼리 윈도우가 거의 겹침에도 활용 X

## ver+. 2차원 슬라이딩 윈도우 최솟값 (monotonic deque)
```c++
vector<int> solution(int m, int n, int h, int w, vector<vector<int>> drops) {
    const int M = drops.size();
    
    vector<vector<int>> map(m, vector<int>(n, M));
    for(int i=0, y, x; i<M; i++)
    {
        y=drops[i][0], x=drops[i][1];
        map[y][x]=i;
    }
    
    deque<int> q;
    for(int i=0; i<m; i++)
    {
        q.clear();
        for(int j=0; j<n; j++)
        {
            while(!q.empty() && q.front()<=j-w) 
                q.pop_front();
            
            while(!q.empty() && map[i][q.back()]>=map[i][j])
                q.pop_back();
            
            q.push_back(j);
            if(j>=w-1) map[i][j-w+1]=map[i][q.front()];
        }
    }
        
    for(int j=0; j<n-w+1; j++)
    {
        q.clear();
        for(int i=0; i<m; i++)
        {
            while(!q.empty() && q.front()<=i-h) 
                q.pop_front();
            
            while(!q.empty() && map[q.back()][j]>=map[i][j])
                q.pop_back();
            
            q.push_back(i);
            if(i>=h-1) map[i-h+1][j]=map[q.front()][j];
        }
    }
    
    vector<int> answer(2,0);
    for(int i=0, t=0; i<=m-h && t<M; i++)
        for(int j=0; j<=n-w && t<M; j++)
            if(t<map[i][j])
                t=map[i][j], answer[0]=i, answer[1]=j;
    
    return answer;
}
```
### 시간복잡도
- 격자 초기화 & drops 기록 = O(m*n + M)
- 가로, 세로 패스 = O(m*n) (각각 모든 칸 deque에 한 번 넣고, 한 번 뺌)
- 마지막 탐색 = O(m*n)

### 동작 원리
- **시간 격자 만들기**
  - 모든 칸을 M(안 젖음)으로 초기화
  - drops 한 번 순회하여, map\[y]\[x]=i로 그 칸이 젖는 순번 기록
  - 윈도우 안에서 처음 젖는 시점은 윈도우 안 값들의 최솟값
- **가로 패스**
  - 각 행에서 폭 w 슬라이딩 윈도우 최솟값을 구해 map\[i]\[j-w+1]에 덮어씀
  - deque에는 최솟값 후보 인덱스만 값이 오름차순이 되도록 유지
  - 범위 밖인 앞 인덱스는 버림
- **세로 패스**
  - 가로 패스 결과에서 각 열마다 높이 h 슬라이딩 윈도우 최솟값을 구해 map\[i-h+1]\[j]에 덮어씀
  - map\[y]\[x] = (y,x)가 왼쪽 위인 h*w 구역의 첫 피격 시점
- **정답 선택**
  - 위쪽, 왼쪽 순으로 순회하면서 t<map\[i]\[j]일 때만 갱신해 최댓값의 첫 위치 찾음
  - 값이 M이면 안 젖는 구역이라 t<M 조건으로 즉시 종료

- 5 ≤ n ≤ 1,000,000
- 0 ≤ k < n
- 1 ≤ cmd의 원소 개수 ≤ 200,000

  - X는 1 이상 300,000 이하인 자연수이며 0으로 시작하지 않습니다.
  - X가 나타내는 자연수에 ',' 는 주어지지 않습니다. 예를 들어 123,456의 경우 123456으로 주어집니다.
  - cmd에 등장하는 모든 X들의 값을 합친 결과가 1,000,000 이하인 경우만 입력으로 주어집니다.
  - 표의 모든 행을 제거하여, 행이 하나도 남지 않는 경우는 입력으로 주어지지 않습니다.
  - 본문에서 각 행이 제거되고 복구되는 과정을 보다 자연스럽게 보이기 위해 "이름" 열을 사용하였으나, "이름"열의 내용이 실제 문제를 푸는 과정에 필요하지는 않습니다. "이름"열에는 서로 다른 이름들이 중복없이 채워져 있다고 가정하고 문제를 해결해 주세요.
- 표의 범위를 벗어나는 이동은 입력으로 주어지지 않습니다.
- 원래대로 복구할 행이 없을 때(즉, 삭제된 행이 없을 때) "Z"가 명령어로 주어지는 경우는 없습니다.
- 정답은 표의 0행부터 n - 1행까지에 해당되는 O, X를 순서대로 이어붙인 문자열 형태로 return 해주세요.

## ver1. vector erase/insert
```c++
string solution(int n, int k, vector<string> cmd) {
    stack<int> st;
    vector<int> v(n);
    for(int i=0; i<n; i++)
        v[i]=i;
    
    for(int i=0,cnt; i<cmd.size(); i++)
    {
        switch(cmd[i][0])
        {
            case 'U':
            {
                cnt=stoi(cmd[i].substr(2));
                k=clamp(k-cnt,0,(int)v.size()-1);
                break;
            }
            case 'D':
            {
                cnt=stoi(cmd[i].substr(2));
                k=clamp(k+cnt,0,(int)v.size()-1);
                break;
            }
            case 'C':
            {
                st.push(v[k]);
                v.erase(v.begin()+k);
                k=clamp(k,0,(int)v.size()-1);
                break;
            }
            case 'Z':
            {
                auto it=find_if(v.begin(), v.end(), [&](int a){
                    return a>st.top();
                });
                if(st.top()<v[k]) k++;
                v.insert(it,st.top());
                st.pop();
                break;
            }
        }  
    }
    
    string answer(n,'X');
    for(int i=0; i<v.size(); i++)
        answer[v[i]]='O';
    
    return answer;
}
```
### 시간복잡도
- U/D = O(1)
- C = O(n) (erase)
- Z = O(n) (find_if + insert)
- = O(S * n) (S=cmd 수) = 최악 20만 * 100만 = 2천만

### 동작 원리
- v에 삭제되지 않은 행 번호를 오름차순으로 저장 (k=v의 인덱스)
- U/D는 k를 clamp로 이동
- C는 v\[k]를 스택에 넣고 erase
- Z는 스택 top보다 큰 첫 원소 위치(find_if)에 insert하고, 복구된 행이 현재 행보다 위면 k++로 보정

### 문제점
- 효율성 테스트 시간 초과
- 인덱스 보정(k++)이 필요해 실수하기 쉬움

## ver2. 문자열 상태 + 선형 스캔
```c++
string solution(int n, int k, vector<string> cmd) {
    string answer(n,'O');
    stack<int> st;
    for(int i=0,l=0,r=n-1,cnt; i<cmd.size(); i++)
    {
        switch(cmd[i][0])
        {
            case 'U':
            {
                cnt=stoi(cmd[i].substr(2));
                for(int j=0; j<cnt&&k>=l; k--)
                    if(answer[k]=='O') 
                        j++;
                if(k<l)k=l;
                break;
            }
            case 'D':
            {
                cnt=stoi(cmd[i].substr(2));
                for(int j=0; j<cnt&&k<=r; k++)
                    if(answer[k]=='O') 
                        j++;
                if(k>r)k=r;
                break;
            }
            case 'C':
            {
                answer[k]='X';
                st.push(k);
                k=answer.find('O',k);
                if(k==string::npos)
                    k=answer.rfind('O');
                
                l=answer.find('O');
                r=answer.rfind('O');
                break;
            }
            case 'Z':
            {
                answer[st.top()]='O';
                l=min(st.top(),l);
                r=max(st.top(),r);
                st.pop();
                break;
            }
        }
    }
    
    return answer;
}
```
### 시간복잡도
- U/D = O(n) (삭제된 칸까지 훑음)
- C = O(n) (find/rfind)
- Z = O(1)
- = O(S * n) (S=cmd 수) = 최악 20만 * 100만 = 2천만 

### 동작 원리
- 행 번호가 곧 인덱스, answer의 O/X로 삭제 여부 표시
- U/D는 k를 한 칸씩 움직이며 살아있는 칸만 카운트
- C는 X로 바꾸고, 스택 저장 후 find로 아래쪽 살아 있는 칸을 찾고 없으면 rfind로 위쪽을 찾음
  - l/r은 살아있는 첫 행과 마지막 행
- Z는 O로 되돌리고 l/r 갱신

### 문제점
- 정확성: 현재 칸 먼저 카운트한 뒤 이동해서, 도착칸이 삭제된 칸일 수 있음. 먼저 이동한뒤 살아있는 칸일 때만 카운트
- 효율성: 삭제가 많이 쌓이면 시간 초과

## ver+. 배열 기반 이중 연결리스트 
```c++
string solution(int n, int k, vector<string> cmd) {
    vector<int> prev(n,-1), next(n,-1);
    for(int i=1, j=n-2; i<n; i++, j--)
        prev[i]=i-1, next[j]=j+1;
    
    stack<int> st;
    string answer(n,'O');
    for(const string& str:cmd)
    {
        if(str[0]=='U')
        {
            int cnt=stoi(str.substr(2));
            for(int i=0; i<cnt; i++)
            {
                if(prev[k]<0) break;
                k=prev[k];
            }
        }
        else if(str[0]=='D')
        {
            int cnt=stoi(str.substr(2));
            for(int i=0; i<cnt; i++)
            {
                if(next[k]<0) break;
                k=next[k];
            }
        }
        else if(str[0]=='C')
        {
            answer[k]='X';
            st.push(k);
            
            if(prev[k]>=0) next[prev[k]]=next[k];
            if(next[k]>=0) prev[next[k]]=prev[k];
            
            if(next[k]<0) k=prev[k];
            else k=next[k];
        }
        else if(str[0]=='Z')
        {
            int idx=st.top();
            st.pop();
            
            answer[idx]='O';
            
            if(prev[idx]>=0) next[prev[idx]]=idx;
            if(next[idx]>=0) prev[next[idx]]=idx;
        }
    }
    
    return answer;
}
```
### 시간복잡도
- 초기화 = O(n)
- C/Z = O(1)
- U/D = O(X)
- = O(n + ΣX) = 최악 100만 + 100만 = 200만 (X 총합 100만 이하)

### 동작 원리
- prev\[i], next\[i]에 위, 아래 이웃 행 번호를 저장하고, 경계는 -1
- U/D는 링크를 X번 따라감
- C는 이웃끼리 서로 연결하고 k를 아래로(없으면 위로) 옮김
  -  삭제 노드의 prev/next는 그대로
- Z는 스택에서꺼낸 노드가 기억한 prev/next로 이웃과 다시 연결
  - answer의 O/X는 삭제 여부 기록

## 참고
### 센티널 (Sentinel)

#### 정의
- 데이터가 아니라 **경계 처리를 위해 양 끝에 추가하는 가짜 노드(보초)**
- 실제 첫 행, 마지막 행도 양쪽에 이웃이 있는 일반 노드처럼 취급 가능

#### 사용 이유
- 연결 리스트에서 첫 노드의 prev, 마지막 노드의 next는 "없음"
- `-1`로 처리하면 `if (prev[k] >= 0)` 같은 분기가 곳곳에 필요
- 센티널을 두면 prev/next가 항상 유효한 노드를 가리켜 분기 제거

#### 구조 (프로그래머스 81303 기준)
- 행 번호 1~n, **0번(앞 센티널)**, **n+1번(뒤 센티널)** 추가
- 배열 크기 n+2

```
[0] ⇄ [1] ⇄ [2] ⇄ ... ⇄ [n] ⇄ [n+1]
센티널                          센티널
```

#### 초기화
- `up[i] = i-1`, `down[i] = i+1` (i = 0 ~ n+1 전체)

#### 연산별 적용
| 연산 | 코드 | 비고 |
|---|---|---|
| C (삭제) | `down[up[k]] = down[k]`<br>`up[down[k]] = up[k]` | 분기 없이 연결 |
| C (커서) | `down[k] == n+1`이면 `k = up[k]`, 아니면 `k = down[k]` | 비교 필요 |
| Z (복구) | `down[up[idx]] = idx`<br>`up[down[idx]] = idx` | 분기 없이 재연결 |
| U / D | X번 링크 따라가기 | 범위 이탈 없으므로 경계 체크 불필요 |

#### 주의사항
- 센티널은 **연결 갱신 분기**만 없애줌
- **커서를 어디로 옮길지 판단**은 여전히 필요
- 센티널은 데이터가 아니므로 삭제 대상, 결과 출력에 포함하지 않음
- 행 번호를 1부터 쓰면 결과는 `answer[i-1]`로 접근
- 변수명 `prev`, `next`는 `std::prev`, `std::next`와 겹치므로 `up`, `down` 권장

#### -1 방식과 비교
| 방식 | 경계 처리 | 비용 |
|---|---|---|
| -1 | 매번 `>= 0` 분기 | 없음 |
| 센티널 | 분기 없음 | 노드 2개 추가 |

#### 한 줄 정리
- 경계 예외 처리를 데이터 구조 쪽으로 밀어 넣어 코드를 단순하게 만드는 기법

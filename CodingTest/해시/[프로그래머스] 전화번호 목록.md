# [전화번호 목록](https://school.programmers.co.kr/learn/courses/30/lessons/42577#)
## 문제 설명
전화번호부에 적힌 전화번호 중, 한 번호가 다른 번호의 접두어인 경우가 있는지 확인하려 합니다.  
전화번호가 다음과 같을 경우, 구조대 전화번호는 영석이의 전화번호의 접두사입니다.  
  
구조대 : 119  
박준영 : 97 674 223  
지영석 : 11 9552 4421  
전화번호부에 적힌 전화번호를 담은 배열 phone_book 이 solution 함수의 매개변수로 주어질 때, 어떤 번호가 다른 번호의 접두어인 경우가 있으면 false를 그렇지 않으면 true를 return 하도록 solution 함수를 작성해주세요.  

## 제한 사항
phone_book의 길이는 1 이상 1,000,000 이하입니다.  
각 전화번호의 길이는 1 이상 20 이하입니다.  
같은 전화번호가 중복해서 들어있지 않습니다.  

### 입출력 예제
|phone_book|return|
|---|---|
|\["119", "97674223", "1195524421"\]|false|
|\["123","456","789"\]|true|
|\["12","123","1235","567","88"\]|false|

### 입출력 예 설명
입출력 예 #1  
앞에서 설명한 예와 같습니다.  
  
입출력 예 #2  
한 번호가 다른 번호의 접두사인 경우가 없으므로, 답은 true입니다.  
  
입출력 예 #3  
첫 번째 전화번호, “12”가 두 번째 전화번호 “123”의 접두사입니다. 따라서 답은 false입니다.

### ver1. 전화 번호 길이 측정 후 각각의 전화번호를 측정한 길이별로 잘라서 비교.  
``` 
bool solution(vector<string> phone_book) {
    vector<int> v(21, 0);
    for(int i=0; i<phone_book.size(); i++)
        v[phone_book[i].length()]++;
        
    unordered_map<string, int> m;
    for(int i=0; i<phone_book.size(); i++)
    {
        int l = phone_book[i].length();
        string temp;
        for(int j=0; j<v.size() && j<=l; j++)
        {
            if(v[j]==0) continue;
            temp = phone_book[i].substr(0, j);
            m[temp]++;
            if(m[temp]>1) return false;
        }
    }
    
    return true;
}
```
반례: \["100000000", "100000001", "12345"\] true
자른 값이 전화번호 목록 중에 존재하는 지 확인 X

### ver2. n*n 순회하며, 작은 문자열이 큰 문자열에 포함됬는 지 확인(compare)
```
int cmp(const string &str1, const string &str2)
{
    string s1 = str1.length()<str2.length()?str1:str2;
    string s2 = str1.length()>str2.length()?str1:str2;
    
    return s2.compare(0, s1.length(), s1);
}

bool solution(vector<string> phone_book) {
    for(int i=0; i<phone_book.size(); i++)
        for(int j=0; j<phone_book.size(); j++)
        {
            if(i==j || phone_book[i].length() == phone_book[j].length()) continue;
            if(cmp(phone_book[i], phone_book[j])==0)
                return false;
        }
    
    return true;
}
```
시간복잡도: O(N^2)
방향은 맞으나 효율성 좋지 않음.

### ver3. 정렬 후 다음 문자열과 비교
```
bool solution(vector<string> phone_book) {
    sort(phone_book.begin(), phone_book.end());
    
    for(int i=0; i<phone_book.size()-1; i++)
        if(phone_book[i+1].compare(0, phone_book[i].length(), phone_book[i])==0)
            return false;
    
    return true;
}
```
시간복잡도: O(N logN) - 정렬  
정렬 후 접두어 관계 있을 시, 반드시 순서상 바로 인접한 쌍에서 검출  
ex. A가 B의 접두어 = 사전순 A < B  

### ver+. unordered_set 사용한 비교 (by Claude)
```
bool solution(vector<string> phone_book) {
    unordered_set<string> numbers(phone_book.begin(), phone_book.end());
    for (const string& num : phone_book) {
        string prefix;
        for (int i = 0; i < num.size() - 1; i++) {
            prefix += num[i];
            if (numbers.count(prefix)) return false;
        }
    }
    return true;
}
```
unordered_set에 전체 번호 삽입 후 각 번호의 모든 접두어 검색  
각 문자열을 일일히 자른 값을 대입하는 데에 있어서 비효율적 
(하지만 정렬과는 상수 수준 차이이기 떄문에 큰 차이는 없으나, 문자열 크기나 수가 많아짐에 따라 차이 커짐)

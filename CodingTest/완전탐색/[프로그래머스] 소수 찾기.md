# [소수 찾기](https://school.programmers.co.kr/learn/courses/30/lessons/42839)

## 문제 설명
한자리 숫자가 적힌 종이 조각이 흩어져있습니다. 흩어진 종이 조각을 붙여 소수를 몇 개 만들 수 있는지 알아내려 합니다.  

각 종이 조각에 적힌 숫자가 적힌 문자열 numbers가 주어졌을 때, 종이 조각으로 만들 수 있는 소수가 몇 개인지 return 하도록 solution 함수를 완성해주세요.  

## 제한사항
numbers는 길이 1 이상 7 이하인 문자열입니다.  
numbers는 0~9까지 숫자만으로 이루어져 있습니다.  
"013"은 0, 1, 3 숫자가 적힌 종이 조각이 흩어져있다는 의미입니다.  

## 입출력 예
|numbers|return|
|---|---|
|"17"|3|
|"011"|2|

### 입출력 예 설명
예제 #1  
\[1, 7]으로는 소수 \[7, 17, 71]를 만들 수 있습니다.

예제 #2  
\[0, 1, 1]으로는 소수 \[11, 101]를 만들 수 있습니다.
* 11과 011은 같은 숫자로 취급합니다.

## ver1. 순열 조합
```
int solution(string numbers) {
    unordered_set<int> s;
    sort(numbers.begin(), numbers.end());
    do
    {
        for(int cnt=1; cnt<=numbers.length(); cnt++)
            s.insert(stoi(numbers.substr(0, cnt)));
    }
    while(next_permutation(numbers.begin(), numbers.end()));
    
    int answer = 0;
    for(auto it = s.begin(); it!=s.end(); ++it)
    {
        bool f=*it>1;
        for(int i=2; i*i<=*it && f; i++)
            if(*it%i==0) 
                f=false;
        
        answer += f;
    }
    return answer;
}
```
시간복잡도: 순열 수(O(N!)) + 순열 당 작업(O(N^2)) = O(N! * N^2)  
정렬 후 순열 생성 (next_permutation)  
부분 문자열 삽입 (substr(0, cnt)로 자른 문자열을 stoi로 변환해 삽입)  
소수 판별 (unordered_set 순회 하면서 소수 판별 (2~sqrt(i))  

## ver+. DFS
```
unordered_set<int> nums;
vector<bool> visited;

void dfs(const string &numbers, string picked) {
    if (!picked.empty())
        nums.insert(stoi(picked));

    for (int i = 0; i < numbers.size(); i++) {
        if (visited[i]) continue;
        visited[i] = true;
        dfs(numbers, picked + numbers[i]);
        visited[i] = false;
    }
}

bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; (long long)i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

int solution(string numbers) {
    visited.assign(numbers.size(), false);

    dfs(numbers, "");

    int answer = 0;
    for (int n : nums)
        if (isPrime(n)) answer++;

    return answer;
}
```
시간복잡도: 순열 수(O(N!)) + 순열 당 작업(O(N)) = O(N! * N)
dfs(numbers, "")에서 시작. 아직 안 쓴 자리 골라 picked에 붙이고 재귀호출  
각 재귀마다 picked 비어있지 않으면 숫자로 변환해서 저장  
함수 빠져나올 때 visited를 되돌려서(백트래킹) 다른 조합도 계속 시도

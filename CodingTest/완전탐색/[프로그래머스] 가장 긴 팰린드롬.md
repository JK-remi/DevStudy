# [가장 긴 팰린드롬](https://school.programmers.co.kr/learn/courses/30/lessons/12904)

## 문제 설명
앞뒤를 뒤집어도 똑같은 문자열을 팰린드롬(palindrome)이라고 합니다.
문자열 s가 주어질 때, s의 부분문자열(Substring)중 가장 긴 팰린드롬의 길이를 return 하는 solution 함수를 완성해 주세요.

예를들면, 문자열 s가 "abcdcba"이면 7을 return하고 "abacde"이면 3을 return합니다.

## 제한사항
- 문자열 s의 길이 : 2,500 이하의 자연수
- 문자열 s는 알파벳 소문자로만 구성

## 입출력 예
|s|answer|
|-----|-----|
|"abcdcba"|7|
|"abacde"|3|

### 입출력 예 설명
#### 입출력 예 #1
4번째자리 'd'를 기준으로 문자열 s 전체가 팰린드롬이 되므로 7을 return합니다.

#### 입출력 예 #2
2번째자리 'b'를 기준으로 "aba"가 팰린드롬이 되므로 3을 return합니다.

---

## ver1. 완전탐색(substr + reverse)
```c++
int solution(string s)
{
    int answer=0;
    for(int i=s.length(); i>0; i--)
    {
        for(int j=0; j+i<=s.length(); j++)
        {
            string t=s.substr(j,i);
            string r=t;
            reverse(r.begin(), r.end());

            if(t==r) 
              return i;

        }
    }

    return answer;
}
```
### 시간복잡도
- 모든 부분 문자열 O(n^2) * 복사/reverse/비교 O(n) = O(n^3)

### 동작 원리
- 길이 i를 n부터 1까지, 시작 위치 j를 옮기며 모든 부분 문자열을 검사
- substr로 복사한 t를 뒤집은 r과 비교해 같으면 팰린드롬, 최대 길이 갱신

### 문제점
- 매 구간마다 문자열 2개 새로 만들어 복사/할당 비용 큼

## ver2. 완전탐색 (양끝 포인터 + 조기 종료)
```c++
int solution(string s)
{
    int answer=0;
    for(int i=s.length(); i>0 && answer==0; i--)
    {
        for(int j=0; j+i<=s.length() && answer==0; j++)
        {
            bool f=true;
            for(int l=j, r=j+i-1; l<r&&f; l++, r--)
                if(s[l]!=s[r]) f=false;
            
            if(f) answer=i;
        }
    }

    return answer;
}
```
### 시간복잡도
- 이론상 최악 O(n^3)
  - 불일치 즉시 비교를 끝내고, 첫 발견에서 전체 탐색을 끝내 실제로는 훨씬 빠름 

### 동작 원리
- 길이를 내림차순으로 보므로, 처음 발견한 팰린드롬의 길이가 곧 최댓값
- 복사 없이 s\[l], s\[r]을 양 끝에서 안쪽으로 비교
- 'answer==0'조건으로 바깥 두 반복문을 함께 탈출

### 문제점
- 최악 복잡도는 여전히 O(n^3)이라 통과 여부가 테스트 데이터에 의존
- 길이 1 문자열: 안쪽 비교가 없어 f가 true로 유지되어 정상 동작하지만 조기종료 조건이 'answer==0'이라 길이 0입력은 고려 대상이 아님
- 팰린드롬이 짧고, 부분 일치가 많은 입력에서 느려짐

## ver+1. 중심 확장
```c++
int solution(string s)
{
    int answer=0;
    for(int i=0, l,r; i<s.length(); i++)
    {
        for(l=i-1, r=i+1; l>=0 && r<s.length(); l--, r++) // odd
            if(s[l]!=s[r]) break;
        answer=max(answer, r-l-1);
        
        for(l=i, r=i+1; l>=0 && r<s.length(); l--, r++) // even
            if(s[l]!=s[r]) break;
        answer=max(answer, r-l-1);
    }
    return answer;
}
```
### 시간복잡도
- 중심 O(n) * 확장 최대 O(n) = O(n^2)

### 동작 원리
- 모든 위치를 중심으로 잡고, 홀수(중심 1글자), 짝수(중심 2글자) 두 경우를 각각 확장
- 불일치 또는 범위 이탈로 멈추면 포인터가 한 칸씩 더 나간 상태이므로 길이는 'r-l-1'

## ver+2. 구간 DP
```c++
int solution(string s)
{
    const int l=s.length();
    vector<vector<bool>> dp(l, vector<bool>(l,false));
    
    int answer=0;
    for(int i=l-1; i>=0; i--)
        for(int j=i; j<l; j++)
        {
            if(s[i]==s[j] && (j-i<2 || dp[i+1][j-1]))
                dp[i][j]=true;
            
            if(dp[i][j]) answer=max(answer, j-i+1);
        }

    return answer;
}
```
### 시간복잡도
- 모든 (i,j)쌍을 한 번씩 계산

### 동작 원리
- 'dp\[i]\[j]' = i~j 구간이 팰린드롬인가
- 양끝 글자가 같고, 길이가 2 이하이거나 안쪽 'dp\[i+1]\[j-1]'이 참이면 참
- 'i'를 뒤에서 앞으로 돌려 안쪽 구간(아랫줄)이 먼저 채워지도록 보장
- 'j-i<2'가 길이 1,2 기저 조건을 통합하고, 단락 평가로 범위 밖 참조도 차단

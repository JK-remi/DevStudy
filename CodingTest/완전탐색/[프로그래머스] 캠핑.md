# [캠핑](https://school.programmers.co.kr/learn/courses/30/lessons/1833)

## 문제 설명
<img src="https://t1.kakaocdn.net/codefestival/tent.png">

무지를 돌보느라 지친 콘은 한적한 시골의 한 캠핑장에 놀러 갔다. 
캠핑장은 텐트를 칠 수 있는 넓은 평지를 제공하고 있는데, 이 평지에는 이미 캠핑장에서 설치해 놓은 n개의 쐐기가 박혀 있다. 
캠핑장 이용 고객은 이 쐐기들 중 한 쌍을 골라 다음과 같은 조건을 만족하도록 텐트를 설치해야 한다.

- 텐트는 직사각형 형태여야 한다.
- 텐트의 네 면이 정확하게 동, 서, 남, 북을 향해야 한다.
- 대각에 위치하는 텐트의 두 꼭짓점이 정확하게 선택한 두 개의 쐐기에 위치해야 한다.
- 텐트가 점유하는 직사각형 영역의 넓이는 0보다는 커야 한다.
- 텐트가 점유하는 직사각형 영역 내부에 다른 쐐기를 포함하면 안 된다. (다른 쐐기가 경계에 위치하는 경우는 허용함)

캠핑장에서는 위와 같은 조건을 만족하는 위치라면 어디든 고객이 텐트를 설치할 수 있도록 정확한 크기의 텐트를 모두 구비하여 대여해준다고 한다.

당신은 위와 같은 조건을 만족하는 텐트를 설치할 수 있는 쐐기의 쌍의 개수는 총 몇 가지가 될지 궁금해졌다.

n개의 쐐기의 위치가 좌표로 주어질 때, 위의 조건을 만족하는 쐐기의 쌍의 개수를 계산하는 프로그램을 작성하시오. 단, 동서 방향은 x축, 남북 방향은 y축과 평행하다고 가정한다.

## 입력 형식
입력은 쐐기의 개수를 의미하는 정수 n과, n × 2 크기의 2차원 배열 data로 주어지며, 배열의 각 행은 캠핑장에 설치된 쐐기의 x좌표와 y좌표를 의미한다. 제한 조건은 다음과 같다.

- 2 <= n <= 5,000
- n개의 쐐기는 모두 x좌표 0 이상 2^31-1 이하, y좌표 0 이상 2^31-1 이하에 위치한다.
- 입력되는 n개의 쐐기 중 x좌표와 y좌표가 모두 같은 경우는 없다.

## 출력 형식
입력에 주어진 각 케이스에 대해 가능한 텐트의 쐐기의 쌍의 개수를 정수 형태로 리턴한다.

## 예제 입출력
|n|data|answer|
|-|--------|--|
|4|/[/[0, 0], /[1, 1], /[0, 2], /[2, 0]]|3|

### 예제에 대한 설명
예제에는 총 4개의 쐐기가 있으며 이 중 (0,0)-(1,1), (0,2)-(1,1), (1,1)-(2,0)의 세 가지 위치에만 텐트를 설치할 수 있다. 
(0,0)-(0,2)와 (0,0)-(2,0)의 경우에는 직사각형 영역의 넓이가 0이 되기 때문에 조건을 만족하지 못하며, 
(0,2)-(2,0)의 경우 (1,1) 위치의 쐐기가 직사각형의 내부에 포함되므로 조건을 만족하지 못한다.

## ver1. 좌표 압축 + 2차원 누적합
```c++
int solution(int n, vector<vector<int>> data) {
    // 1. 좌표 압축
    vector<int> xs, ys;
    for (auto& d : data) { xs.push_back(d[0]); ys.push_back(d[1]); }
    sort(xs.begin(), xs.end()); xs.erase(unique(xs.begin(), xs.end()), xs.end());
    sort(ys.begin(), ys.end()); ys.erase(unique(ys.begin(), ys.end()), ys.end());
    int X = xs.size(), Y = ys.size();

    vector<int> cx(n), cy(n);
    for (int i = 0; i < n; i++) {
        cx[i] = lower_bound(xs.begin(), xs.end(), data[i][0]) - xs.begin() + 1;  // 1-indexed
        cy[i] = lower_bound(ys.begin(), ys.end(), data[i][1]) - ys.begin() + 1;
    }

    // 2. 2차원 grid에 쐐기 표시 후 누적합
    vector<vector<int>> ps(X + 1, vector<int>(Y + 1, 0));
    for (int i = 0; i < n; i++) ps[cx[i]][cy[i]] = 1;
    for (int a = 1; a <= X; a++)
        for (int b = 1; b <= Y; b++)
            ps[a][b] += ps[a - 1][b] + ps[a][b - 1] - ps[a - 1][b - 1];

    // 3. 모든 쌍을 확인
    int answer = 0;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            if (cx[i] == cx[j] || cy[i] == cy[j]) continue;  // 넓이 0

            int x1 = min(cx[i], cx[j]) + 1, x2 = max(cx[i], cx[j]) - 1;  // 내부 범위
            int y1 = min(cy[i], cy[j]) + 1, y2 = max(cy[i], cy[j]) - 1;

            if (x1 > x2 || y1 > y2) { answer++; continue; }  // 내부에 격자 자체가 없음

            int cnt = ps[x2][y2] - ps[x1 - 1][y2] - ps[x2][y1 - 1] + ps[x1 - 1][y1 - 1];
            if (cnt == 0) answer++;
        }

    return answer;
}
```
### 시간복잡도
- 압축: O(n logn)
- 누적합: O(X * Y)
- 쌍 검사: O(n^2)
- = O(n^2)

### 동작 원리
- 좌표를 순위로 압축해 grid크기를 최대 5000 x 5000으로 줄인다
- grid에 쐐기를 1로 표시하고 2차원 누적합을 만든다
- 모든 쌍을 돌면서 두 꼭짓점의 바로 안쪽 범위에 쐐기가 0개인지 O(1)로 확인
- 변 위의 쐐기는 안쪽 범위에서 제외되므로 경계 허용이 자연스럽게 처리

### 문제점
- 공간 = O(n^2) = 5001 * 5001
  - int = 약 100MB라 메모리 제한
  - 누적합이 5000이하라 short으로 바꿔도 50MB
- vector<vector<int>>는 접근 패턴 때문에 캐시 효율이 떨어짐
- 압축과 누적합 코드가 길고 인덱스 (1-indexed, ±1) 실수 나오기 쉬움

## ver+. 정렬 + 기준점별 위/아래 경계 스캔
```c++
int solution(int n, vector<vector<int>> data) {
    sort(data.begin(), data.end());
    
    int answer = 0;
    for(int i=0, x, y; i<n; i++)
    {
        
        x=data[i][0], y=data[i][1];
        for(int j=i+1, uy=INT_MAX,dy=0,tuy=uy, px=x, nx, ny; j<n;j++)
        {
            nx=data[j][0], ny=data[j][1];
            if(x==nx||y==ny) continue;    // 넓이 0

            if(px!=nx)
            {
                px=nx;
                tuy=uy;
            }
            
            if(y<ny)
            {
                if(ny<=tuy) answer++;
                uy=min(uy,ny);
            }
            else if(y>ny && dy<=ny)
                answer++, dy=ny;
        }
    }
    
    return answer;
}
```
### 시간복잡도
- 정렬: O(n logn)
- 스캔: O(n^2)
- = **O(n^2)**
- 공간 = O(1)

### 동작 원리
- (x,y) 오름차순 정렬
- 기준점 i마다 뒤의 j를 순서대로 보면서, 위쪽과 아래쪽에서 i에 가장 가까운 y를 경계값 (uy,dy)으로 유지
- j가 경계값과 같거나 안쪽이면 사이에 막는 쐐기가 없으므로 카운트하고 경계값을 좁힘
- 같은 x그룹은 서로 막지 않으므로, 위쪽은 그룹 진입 전 경계값(tuy)로 판정
- 아래쪽은 y 오름차순에서 먼 점이 먼저 와서 바로 갱신해도 맞음

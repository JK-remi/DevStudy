# [외벽 점검](https://school.programmers.co.kr/learn/courses/30/lessons/60062)

## 문제 설명
레스토랑을 운영하고 있는 "스카피"는 레스토랑 내부가 너무 낡아 친구들과 함께 직접 리모델링 하기로 했습니다. 레스토랑이 있는 곳은 스노우타운으로 매우 추운 지역이어서 내부 공사를 하는 도중에 주기적으로 외벽의 상태를 점검해야 할 필요가 있습니다.

레스토랑의 구조는 완전히 동그란 모양이고 외벽의 총 둘레는 n미터이며, 외벽의 몇몇 지점은 추위가 심할 경우 손상될 수도 있는 취약한 지점들이 있습니다. 따라서 내부 공사 도중에도 외벽의 취약 지점들이 손상되지 않았는 지, 주기적으로 친구들을 보내서 점검을 하기로 했습니다. 다만, 빠른 공사 진행을 위해 점검 시간을 1시간으로 제한했습니다. 친구들이 1시간 동안 이동할 수 있는 거리는 제각각이기 때문에, 최소한의 친구들을 투입해 취약 지점을 점검하고 나머지 친구들은 내부 공사를 돕도록 하려고 합니다. 편의 상 레스토랑의 정북 방향 지점을 0으로 나타내며, 취약 지점의 위치는 정북 방향 지점으로부터 시계 방향으로 떨어진 거리로 나타냅니다. 또, 친구들은 출발 지점부터 시계, 혹은 반시계 방향으로 외벽을 따라서만 이동합니다.

외벽의 길이 n, 취약 지점의 위치가 담긴 배열 weak, 각 친구가 1시간 동안 이동할 수 있는 거리가 담긴 배열 dist가 매개변수로 주어질 때, 취약 지점을 점검하기 위해 보내야 하는 친구 수의 최소값을 return 하도록 solution 함수를 완성해주세요.

## 제한사항
- n은 1 이상 200 이하인 자연수입니다.
- weak의 길이는 1 이상 15 이하입니다.
  - 서로 다른 두 취약점의 위치가 같은 경우는 주어지지 않습니다.
  - 취약 지점의 위치는 오름차순으로 정렬되어 주어집니다.
  - weak의 원소는 0 이상 n - 1 이하인 정수입니다.
- dist의 길이는 1 이상 8 이하입니다.
  - dist의 원소는 1 이상 100 이하인 자연수입니다.
- 친구들을 모두 투입해도 취약 지점을 전부 점검할 수 없는 경우에는 -1을 return 해주세요.

## 입출력 예
|n|weak|dist|result|
|--|-----|-----|--|
|12|\[1, 5, 6, 10]|\[1, 2, 3, 4]|2|
|12|\[1, 3, 4, 9, 10]|\[3, 5, 7]|1|

## ver1. 그리디
```c++
int func(int n, int s, int e)
{
    int r = e-s;
    if(r<0) r+=n;
    return r;
}

int solution(int n, vector<int> weak, vector<int> dist) {
    const int ws=weak.size(), ds=dist.size();
    sort(dist.begin(), dist.end());
    
    int answer = ds+1;
    for(int i=0, s,e, sum, cnt, b; i<ws; i++)
    {
        s=i, cnt=1, b=ds-1;
        for(int r=1, p; r<ws; r++)
        {
            e=(i+r==ws)?0:i+r;
            sum=func(n, weak[s], weak[e]);
            if(sum>dist[b])
                s=e, cnt++, b--;
        }
        
        answer=min(answer,cnt);
    }
    
    for(int i=0, s,e, sum, cnt, b; i<ws; i++)
    {
        s=i, cnt=1, b=ds-1;
        for(int r=1, p; r<ws; r++)
        {
            e=(i-r<0)?ws-1:i-r;
            sum=func(n, weak[s], weak[e]);
            if(sum>dist[b])
                s=e, cnt++, b--;
        }
        
        answer=min(answer,cnt);
    }
    
    if(answer>ds) answer=-1;
    return answer;
}
```
### 시간복잡도
- O(S^2) (=시작점 S * 이동 S) + O(D logD) (정렬)

### 동작 원리
- dist를 오름차순 정렬, 가장 큰 값(b=ds-1) q부터 한명 씩 사용
- 각 시작점 i에서 취약 지점을 한 칸씩 이동하며, 현재 출발점 s에서 e까지의 거리가 dist\[b] 넘으면 e에서 다음 투입(cnt++, b--)
- 첫 루프는 시계방향, 두 번째 루프는 반시계 방향

### 문제점
- 큰 dist부터 고정 순서로 사용하기 떄문에 최적 보장 X

## ver2. BFS 상태 탐색 시도
```c++
struct st
{
    vector<int> weak;
    int back;
    int dir;
    int cnt;
    
    st(const vector<int> &w, int b, int d, int c)
    {
        back=b, dir=d, cnt=c;
        weak=w;
    }
};

int func(int n, int s, int e)
{
    int r = e-s;
    if(r<0) r+=n;
    return r;
}

int solution(int n, vector<int> weak, vector<int> dist) {
    const int ws=weak.size(), ds=dist.size();
    sort(dist.begin(), dist.end());
    
    int answer = ds+1;
    queue<st> q;
    for(int a=0; a<ws && answer>1; a++)
    {
        q.push(st(weak, ds-1, 1, 1));
        q.push(st(weak, ds-1, -1, 1));
        
        while(!q.empty())
        {
            st tmp = q.front();
            q.pop();
            if(tmp.cnt==answer) continue;

            vector<int> &w=tmp.weak;
            for(int i=0, s=w.size(); i<s; i++)
            {
                for(int r=1,e,sum; r<s; r++)
                {
                    e=i+tmp.dir*r;
                    if(e<0) e=s-1;
                    else if(e>=s) e=0;
                    sum=func(s, w[i], w[e]);
                    if(sum>dist[tmp.back])
                    {
                        tmp.cnt++, tmp.back--;
                        w.erase(w.begin(), w.begin()+e);
                        if(w.size()==1) answer=min(answer,tmp.cnt);
                        else
                        {
                            q.push(tmp);
                            q.push(st(w, tmp.back, tmp.dir*-1, tmp.cnt));
                        }
                        
                        break;
                    }
                }
            }
        }
        
        weak.push_back(weak[0]);
        weak.erase(weak.begin());
    }
    
    if(answer>ds) answer=-1;
    return answer;
}
```
### 시간복잡도
- 상태에 벡터 통째 복사 & 중복 제거 없으므로, 상한 잡기 어려움
- = 지수적 폭발 (정상 동작해도 효율 나쁨)

### 동작 원리
- 시작점을 회전(a 루프) 시키고, 큐에 (남은 취약 지점 목록, 사용할 dist 인덱스, 방향, 인원 수) 상태 삽입
- 한 명이 커버한 지점을 erase로 지우고, 방향을 유지하거나 바꿔서 다음 상태를 큐에 삽입
- 남은 지점이 1개가 되면 인원 수로 answer 갱신

### 문제점
- 지점 erase 시 원형 구조 꺠져서 남은 지점 거리 잴 기준 사라짐
- erase(begin, begin+e)는 시계 방향에만 합당 (반시계는 다름)
- break가 r루프만 빠져나와 모든 i에 대해 상태 계속 생성
- dist\[tmp.back]에서 back 음수 가능성
- w.size()==1 이면 성공 판정 근거 없음

## ver+. 배열 2배 확정 + dist 순열 완전 탐색
```c++
int solution(int n, vector<int> weak, vector<int> dist) {
    const int S=weak.size(), MAX=dist.size()+1;
    sort(dist.begin(), dist.end());
    
    vector<int> w(2*S);
    for(int i=0; i<S; i++)
        w[i]=weak[i], w[S+i]=weak[i]+n;
    
    int answer = MAX;
    do
    {
        for(int i=0, di=0; i<S; i++, di=0)
        {
            for(int j=0, s=i, e; j<S && di<dist.size(); j++)
            {
                e=i+j;
                if(w[e]-w[s]>dist[di])
                    s=e, di++;
            }
            
            answer=min(answer,di+1);
        }
    }while(next_permutation(dist.begin(), dist.end()));
    
    if(answer==MAX) answer=-1;
    return answer;
}
```
### 시간복잡도
- O(D! * S^2) = 8! * 15^2 = 900만

### 동작 원리
- 원형을 풀려고 w를 길이 2S로 생성(뒤쪽 값에 +n)
- next_permutation으로 dist의 모든 투입 순서 시도
- 각 순열마다 시작점 i를 전부 시도하고, 시계 방향으로 이동하며 w\[e]-w\[s]가 현재 친구의 dist\[di]를 넘으면 다음 친구 투입
- 전부 지나갔을 때의 인원 di+1로 answer를 갱신
  - 친구 모자라면 di+1이 MAX가 되어 영향 없고, 끝까지 MAX면 -1

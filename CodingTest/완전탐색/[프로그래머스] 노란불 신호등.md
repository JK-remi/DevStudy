# [노란불 신호등](https://school.programmers.co.kr/learn/courses/30/lessons/468371?language=cpp)

## 문제 설명
어떤 도로에 차량 신호등이 n개 있습니다. 모든 신호등은 항상 초록불 → 노란불 → 빨간불 순서로 반복되며, 각 신호의 지속 시간은 신호등마다 다릅니다. 시간은 1초부터 시작하며, 각 신호등은 처음에는 초록불 상태로 시작합니다.

이 도로에서는 가끔 정전이 일어나는데, 모든 신호등이 모두 노란불이 되면 정전이 발생한다는 사실이 밝혀졌습니다.

예를 들어 신호등이 2개이고, 각 신호등의 주기가 다음과 같다고 가정해 보겠습니다.

|신호등|초록불|노란불|빨간불|
|---|---|---|---|
|1번|2초|1초|2초|
|2번|5초|1초|1초|

위 그림과 같이 13초에 처음으로 두 신호등이 모두 노란불이 됩니다.

신호등 n개의 신호 주기를 담은 2차원 정수 배열 signals가 매개변수로 주어집니다. 모든 신호등이 노란불이 되는 가장 빠른 시각(초)을 return 하도록 solution 함수를 완성해 주세요. 
만약 모든 신호등이 노란불이 되는 경우가 존재하지 않는다면 -1을 return 해주세요.

## 제한사항
- 2 ≤ signals의 길이 = n ≤ 5
  - signals의 원소는 \[G, Y, R] 형태의 길이가 3인 정수 배열입니다. 순서대로 초록불, 노란불, 빨간불의 지속 시간을 의미합니다.
  - 1 ≤ G, Y, R ≤ 18
  - 3 ≤ G + Y + R ≤ 20

## ver1. 노랑 구간 점프 + 교집합 검사
```c++
struct st
{
    int time;
    int total;
    int y;
    st(const vector<int> &info)
    {
        time=info[0];
        total=info[0]+info[1]+info[2];
        y=info[1];
    }
    
    void add(int t)
    {
        while(end()<=t)
            time+=total;
    }
    
    int end() {return time+y;}
};

int solution(vector<vector<int>> signals) {
    const int n = signals.size();
    vector<st> v;
    int MAX=1, time=0;
    for(int i=0; i<n; i++)
    {
        v.push_back(st(signals[i]));
        MAX*=v.back().total;        
        time=max(v.back().time, time);
    }
    
    int answer = -1;
    for(int l, r; time<=MAX && answer<0; time=l)
    {
        l=0, r=MAX;
        for(int i=0; i<n; i++)
        {
            v[i].add(time);
            l=max(l, v[i].time);
            r=min(r, v[i].end());            
        }
        
        if(l<r) answer=l+1;
    }
    
    return answer;
}
```
### 시간복잡도
- 매 반복 최소 한 신호등이 한 주기씩전진하므로, 반복 횟수는 최대 약 Σ(MAX/P_i)
  - 반복 한 번의 비용은 O(n)
- 이론상 상한은 O(n^2 * MAX/Pmin)으로 수천만 수준
  - but, l로 한 번에 점프하기 때문에 실제로는 훨씬 적음

### 동작 원리
- 각 신호등의 노란 구간을 (time, time+y]로 보고, time은 노랑이 시작되기 직전 시각(초기값=G)로 설정
- 기준 시각 time(초기값=G 최대값)에서 구간이 이미 끝난 신호등(end()<=time)만 한 주기씩 앞으로 보냄
- 이후시작점의 최댓값 l과 끝점의 최솟값 r을 구해서 l<r이면 교집합 (l,r]이 존재하므로 l+1이 답
- 아니면 time=l로 올리고 반복. 이떄 r<=l이라 끝점이 r인 신호등은 다음 바퀴에서 반드시 한 주기 이동하므로, 매번 전진함
- time이 MAX(주기들의 곱)를 넘으면 해가 없다고 보고 -1을 반환  

### 문제점
- 불변식(각 구간을 버려도 되는 이유, 진전 보장)을 증명해야 하므로, 실수하기 쉬움

## ver+. 시각별 완전 탐색 + 모듈러 연산 노랑 판정 
```c++
const int MAX=pow(20,5);
int solution(vector<vector<int>> signals) {
    int answer = -1;
    for(int t=1; t<=MAX && answer<0; t++)
    {
        bool f=true;
        for(int i=0, tmp; i<signals.size()&&f; i++)
        {
            tmp=(t-1)%(signals[i][0]+signals[i][1]+signals[i][2]);
            f&=(tmp>=signals[i][0] && tmp<signals[i][0]+signals[i][1]);
        }
        
        if(f) answer=t;
    }        
    return answer;
}
```
### 시간복잡도
- 최악 O(MAX * n) = 320만 * 5 = 1600만 번
- 구현 단순하므로, 시간 제한 걱정 X

### 동작 원리
- t를 1부터 올리면서 신호등마다 (t-1)%P를 구함
- 그 값이 [G, G+Y)에 들면 노랑
- 모든 신호등이 노랑이면 t가 답. 하나라도 아니면 바로 다음 신호등 검사를 멈추고(&&f) 다음 시각 체크
- 끝까지 못 찾으면 -1

# [모음사전](https://school.programmers.co.kr/learn/courses/30/lessons/84512)

## 문제 설명
사전에 알파벳 모음 'A', 'E', 'I', 'O', 'U'만을 사용하여 만들 수 있는, 길이 5 이하의 모든 단어가 수록되어 있습니다. 사전에서 첫 번째 단어는 "A"이고, 그다음은 "AA"이며, 마지막 단어는 "UUUUU"입니다.  

단어 하나 word가 매개변수로 주어질 때, 이 단어가 사전에서 몇 번째 단어인지 return 하도록 solution 함수를 완성해주세요.  

## 제한사항
word의 길이는 1 이상 5 이하입니다.  
word는 알파벳 대문자 'A', 'E', 'I', 'O', 'U'로만 이루어져 있습니다.  

## 입출력 예
|word|result|
|---|---|
|"AAAAE"|6|
|"AAAE"|10|
|"I"|1563|
|"EIO"|1189|

### 입출력 예 설명
입출력 예 #1  

사전에서 첫 번째 단어는 "A"이고, 그다음은 "AA", "AAA", "AAAA", "AAAAA", "AAAAE", ... 와 같습니다. "AAAAE"는 사전에서 6번째 단어입니다.  
  
입출력 예 #2  

"AAAE"는 "A", "AA", "AAA", "AAAA", "AAAAA", "AAAAE", "AAAAI", "AAAAO", "AAAAU"의 다음인 10번째 단어입니다.  
  
입출력 예 #3  

"I"는 1563번째 단어입니다.  
  
입출력 예 #4  

"EIO"는 1189번째 단어입니다.  

## ver1. 전체 트리 생성 + 해시맵 조회
```
unordered_map<string, int> m;
const string s = "AEIOU";

void dfs(const string &word, const string &cur, int &cnt)
{
    m[cur]=cnt;
    if(cur.length() == s.length())
        return;
    
    for(int i=0; i<s.length(); i++)
        dfs(word, cur+s[i], ++cnt);
}

int solution(string word) {
    int cnt = 0;
    dfs(word, "", cnt);
    
    return m[word];
}
```
시간복잡도: O(5^0 + 5^1 + ... + 5^5) = O(5^6) = O(3906)  
공간복잡도: O(5^6) = O(3906)  
모음 5개로 만들 수있는 길이 0~5의 모든 문자열을 프리오더로 순회하면서, 각 문자열과 순번을 unordered_map에 전부 저장. 이후 word를 키로 조회.   

## ver2. 조기 종료 DFS
```
const string s = "AEIOU";

void dfs(const string &word, const string &cur, int &cnt, int &ans)
{
    if(cur==word)
    {
        ans=cnt;
        return;
    }
    
    if(cur.length() == s.length())
        return;
    
    for(int i=0; i<s.length() && ans==0; i++)
        dfs(word, cur+s[i], ++cnt, ans);
}

int solution(string word) {
    int cnt = 0;
    int answer = 0; 
    dfs(word, "", cnt, answer);
    
    return answer;
}
```
시간복잡도: 최선(O(1)), 최악(O(5^6)=O(3906))  
공간복잡도: O(L) (L=word 길이)  
프리오더 순회 중 word와 일치하는 순간 ans 정하고, 이후 모든 상위 호출 즉시 종료  
입력 의존적(input-dependent) 복잡도  

## ver+. 조합론적 직접 계산
```
int solution(string word) {
    const string s = "AEIOU";
    auto subtreeSize = [](int len) {
        int total = 0, p = 1;
        for (int i = 0; i <= len; i++) { total += p; p *= 5; }
        return total;
    };
    
    int answer = 0;
    for (int pos = 0; pos < (int)word.size(); pos++) {
        int idx = s.find(word[pos]);
        for (int j = 0; j < idx; j++) {
            answer += subtreeSize(4 - pos);   // word.size() 대신 상수 4 사용
        }
        answer++;
    }
    return answer;
}
```
시간복잡도: O(L^2) (L=word 길이)  
공간복잡도: O(1)  
트리 직접 만들기 X. word의 각 자리에서 현재 글자보다 사전순으로 앞서는 글자 선택 시 서브트리 크기 조합적 계산   

### 1. 트리 구조로 바라보기

이 문제의 사전 순서는 실제로 **트라이(Trie) 형태의 트리를 프리오더(전위) 순회**한 것과 동일합니다.

```
""  (root)
├── "A"
│   ├── "AA"
│   │   ├── "AAA"
│   │   ├── "AAE"
│   │   └── ...
│   ├── "AE"
│   ├── "AI"
│   ├── "AO"
│   └── "AU"
├── "E"
├── "I"
├── "O"
└── "U"
```

각 노드는 자식을 **A, E, I, O, U 순서**로 정확히 5개씩 가집니다 (단, 길이 5에 도달하면 자식 없음).

> **핵심 아이디어**: 프리오더 순회 번호 = 사전순 순위. 이 성질을 이용해 트리를 실제로 만들지 않고도 순위를 직접 계산할 수 있다.

---

### 2. `subtreeSize(len)`의 의미

```cpp
auto subtreeSize = [](int len) {
    int total = 0, p = 1;
    for (int i = 0; i <= len; i++) { total += p; p *= 5; }
    return total;
};
```

이 함수는 **"어떤 노드 아래로 앞으로 `len`개의 자리를 더 채울 수 있을 때, 그 노드를 루트로 하는 서브트리 전체의 노드 개수"** 를 계산합니다.

#### 왜 $\sum_{k=0}^{len} 5^k$ 인가?

어떤 노드에서 앞으로 `len`개의 자리를 더 채울 수 있다고 하면, 그 서브트리는 깊이별로 다음과 같이 구성됩니다.

| 깊이 | 의미 | 경우의 수 |
|---|---|---|
| 0 | 자기 자신 (아무것도 안 채운 상태) | $5^0 = 1$ |
| 1 | 한 글자 추가 | $5^1 = 5$ |
| 2 | 두 글자 추가 | $5^2 = 25$ |
| ⋮ | ⋮ | ⋮ |
| len | len개 글자 모두 채움 | $5^{len}$ |

각 깊이마다 가능한 경우의 수는 공비 5인 등비수열을 이루므로, 서브트리 전체 노드 수는 이를 모두 더한 값입니다.

$$
\text{subtreeSize}(len) = 1 + 5 + 5^2 + \cdots + 5^{len} = \sum_{k=0}^{len} 5^k
$$

**직관적으로**: "자기 자신 하나 + 그 아래 매달릴 수 있는 모든 가능한 문자열의 개수"입니다. 자기 자신도 사전에 등재된 유효한 단어이므로(`"AA"`도 유효한 단어) 반드시 카운트에 포함해야 합니다.

### 3. 메인 로직 — 순위를 누적하는 방법

```cpp
for (int pos = 0; pos < (int)word.size(); pos++) {
    int idx = s.find(word[pos]);
    for (int j = 0; j < idx; j++) {
        answer += subtreeSize(4 - pos);
    }
    answer++;
}
```

`word`를 앞에서부터 한 글자씩 확정해나가면서, **"이 자리에서 고른 글자보다 사전순으로 앞서는 다른 글자를 골랐다면 몇 개의 단어가 먼저 나왔을까"** 를 누적합니다.

#### 예시: `"AI"`의 순위 구하기

**pos = 0, 글자 'A' (idx = 0)**
- 'A'보다 사전순으로 앞선 글자 없음 → inner loop 실행 안 됨
- `answer++` → 접두어 `"A"` 자신의 순위(1)를 더함
- `answer = 1`

**pos = 1, 글자 'I' (idx = 2)**
- 이 자리에서 'I'보다 앞선 글자는 'A'(idx=0), 'E'(idx=1) 두 개
- 만약 이 자리에 'A'를 넣었다면 → `"AA"`를 루트로 하는 서브트리 전체(`subtreeSize(4-1)`)가 `"AI"`보다 먼저 옴
- 만약 'E'를 넣었다면 → `"AE"`를 루트로 하는 서브트리 전체도 마찬가지
- 따라서 `answer += subtreeSize(4-1) * 2`
- `answer++` → `"AI"` 자기 자신의 순위를 더함

#### `4 - pos`가 의미하는 것

- `4` = 최대 단어 길이(5) − 1 (고정 상수)
- `pos`(0-indexed) 위치에서 글자를 하나 확정하면, 그 노드는 깊이 `pos + 1`에 위치
- 최대 깊이 5까지 앞으로 채울 수 있는 자리 수 = $5 - (pos+1) = 4 - pos$

따라서 `subtreeSize(4 - pos)`는 **"이 자리에 다른 글자를 넣었다면 그 서브트리가 몇 개의 노드를 갖는가"** 를 정확히 나타냅니다.

---

### 4. 알고리즘 요약

> **word의 각 자리마다, 그 자리에서 실제로 고른 글자보다 사전순으로 앞선 글자들이 만드는 서브트리들의 크기를 모두 더하고, 마지막에 현재 접두어 자신의 순위 1을 더한다.**

이는 **자릿수 DP(digit DP)** 또는 **"몇 번째로 작은 순열/조합을 구하라"** 유형의 전형적인 패턴입니다.

- 각 자리에서 "더 작은 선택지를 골랐다면 몇 개가 먼저 나왔을지"를 조합적으로 계산
- 트리(또는 순열 전체)를 실제로 만들지 않고도 순위를 $O(L^2)$ (또는 캐싱 시 $O(L)$)에 직접 계산

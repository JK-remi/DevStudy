# [바이러스 파이프](https://school.programmers.co.kr/learn/courses/30/lessons/468373)

## 문제 설명
1번부터 n번까지 번호가 붙은 n개의 배양체를 n-1개의 파이프로 이어 하나의 트리 모양을 만들었습니다. 각 파이프는 A,B,C 3개의 종류 중 하나로 초기에 모든 파이프는 닫혀있습니다.

배양체 중 하나가 바이러스에 감염되어 있습니다. 바이러스에 감염된 배양체는 열린 파이프를 통해 연결된 다른 인접한 배양체를 감염시킵니다.

당신은 종류가 같은 파이프를 한꺼번에 모두 열었다가 닫을 수 있습니다. 단, 한 종류의 파이프를 연 후 다시 닫기 전에 다른 종류의 파이프를 열 수 없습니다. 
파이프를 열었다 닫는 행동을 최대 k번 반복해 최대한 많은 배양체에 바이러스를 감염시키려고 합니다.

배양체의 개수를 나타내는 정수 n, 감염된 배양체의 노드 번호를 나타내는 정수 infection, 파이프의 정보를 나타내는 2차원 정수 배열 edges, 최대 행동 수를 나타내는 정수 k가 매개변수로 주어집니다. 
최대 k번 파이프를 열었다 닫은 후, 감염된 배양체 개수의 최댓값을 return 하도록 solution 함수를 완성해 주세요.

## 제한사항
- 2 ≤ n ≤ 100
- 1 ≤ infection ≤ n
- edges의 길이 = n-1
  - edges\[i]는 \[x, y, type]의 형태로 x번 노드의 배양체와 y번 노드의 배양체 사이가 type 종류의 파이프로 연결되어 있음을 의미합니다.
  - 1 ≤ x < y ≤ n
  - 1 ≤ type ≤ 3
  - 1은 A, 2는 B, 3은 C 를 나타냅니다.
- 1 ≤ k ≤ 10

## 입출력 예
|n|infection|edges|k|result|
|--|--|----------------|--|--|
|10|1|\[\[1, 2, 1], \[1, 3, 1], \[1, 4, 3], \[1, 5, 2], \[5, 6, 1], \[5, 7, 1], \[2, 8, 3], \[2, 9, 2], \[9, 10, 1]]|2|6|
|7|6|\[\[1, 2, 3], \[1, 4, 3], \[4, 5, 1], \[5, 6, 1], \[3, 6, 2], \[3, 7, 2]]|3|7|

## ver1. DFS 완전탐색 + 인접행렬 BFS
```c++
vector<vector<int>> graph;
vector<vector<pair<int,int>>> pipe;
void dfs(const int n, vector<bool> &vis, int pre, int k, int &ans)
{
    if(n==ans) return;
    else if(k==0)
    {
        int cnt=0;
        for(int i=1; i<=n; i++)
            if(vis[i]) cnt++;
        ans=max(cnt,ans);
        return;
    }
    
    for(int i=0; i<3 && ans<n; i++)
    {
        if(pre==i) continue;
        
        unordered_set<int> s;
        queue<int> q;
        for(int j=0, tmp; j<pipe[i].size(); j++)
        {
            if(vis[pipe[i][j].first]==vis[pipe[i][j].second]) continue;
            
            if(vis[pipe[i][j].first]) tmp=pipe[i][j].second;
            else tmp=pipe[i][j].first;
            
            s.insert(tmp), q.push(tmp);
        }
        
        for(;!q.empty(); q.pop())
            for(int j=1; j<=n; j++)
                if(!vis[j] && graph[q.front()][j]==i && s.insert(j).second)
                    q.push(j);
            
        for(auto it=s.begin(); it!=s.end(); ++it)
            vis[*it]=true;
        
        dfs(n, vis, i, k-1, ans);

        for(auto it=s.begin(); it!=s.end(); ++it)
            vis[*it]=false;
    }
}

int solution(int n, int infection, vector<vector<int>> edges, int k) {
    graph = vector<vector<int>>(n+1, vector<int>(n+1, -1));
    pipe = vector<vector<pair<int,int>>>(3);
    for(int i=0; i<edges.size(); i++)
    {
        graph[edges[i][0]][edges[i][1]] = edges[i][2]-1;
        graph[edges[i][1]][edges[i][0]] = edges[i][2]-1;
        pipe[edges[i][2]-1].push_back({edges[i][0],edges[i][1]});
    }
    
    vector<bool> vis(n+1, false);
    vis[infection]=true;
    int answer = 0; // 감염 수
    dfs(n, vis, -1, k, answer);
    
    return answer;
}
```
### 시간복잡도
- 상태 수 = 약 3 * 2^(k-1)개의 리프
- 상태 당 BFS에서 노드를 pop할 때마다 j=1..n을 훑으므로, O(n^2)
- = O(3 * 2^k * n^2) = 약 3천 * 1만 = 3 * 10^7

### 동작 원리
- 파이프 종류(0,1,2)를 DFS로 고른다
  - 직전과 같은 종류는 건너뛰고, 깊이는 k까지
- 선택한 종류의 간선 중 한쪽만 감염된 간선의 비감염 끝점을 시드로 삼는다
- 시드에서 인접행렬 graph\[u]\[j]==i인 BFS로 확산하고, unordered_set으로 중복 막는다
- 집합 s의 노드를 vis에 true로 표시한 뒤 재귀하고, 돌아와서 false로 복구
- k==0이 되면 vis를 1~n까지 훑어 감염수를 세고, ans 갱신

### 문제점
- 로직 오류 없음
- 인접 행렬이라 이웃이 몇 개든 매번 n칸을 훑는 낭비
- unordered_set 해시 오버헤드
- 말단마다 O(n)의 카운트 루프
- 모든 노드가 감염되어도 k==0까지 내려가지만, ans==n 가지치기가 일부 막음

## ver+. DFS 완전탐색 + 인접행렬 BFS (vis 즉시 표시)
```c++
vector<vector<pair<int,int>>> graph;
vector<vector<pair<int,int>>> line;
void dfs(const int n, vector<bool> &vis, int pre, int k, int cnt, int &ans)
{
    if(n==ans) return;
    else if(k==0 || cnt==n)
    {
        ans=max(cnt,ans);
        return;
    }
    
    for(int i=0; i<3 && ans<n; i++)
    {
        if(pre==i) continue;
        
        vector<int> added;  // 이번 단계에서 새로 감염된 노드 (BFS 큐 겸 복구 목록)
        
        // 시드: i종 파이프 중 한쪽만 감염된 간선의 비감염 끝점
        for(int j=0, tmp; j<line[i].size(); j++)
        {
            if(vis[line[i][j].first]==vis[line[i][j].second]) continue;
            
            if(vis[line[i][j].first]) tmp=line[i][j].second;
            else tmp=line[i][j].first;
            
            vis[tmp]=true;
            added.push_back(tmp);
        }
        
        // added를 큐처럼 사용해 i종 간선으로 확산
        for(int h=0; h<added.size(); h++)
        {
            int cur=added[h];
            for(int j=0, to, type; j<graph[cur].size(); j++)
            {
                to=graph[cur][j].first, type=graph[cur][j].second;
                if(type==i && !vis[to])
                {
                    vis[to]=true;
                    added.push_back(to);
                }
            }
        }
        
        dfs(n, vis, i, k-1, cnt+added.size(), ans);
        
        for(int j=0; j<added.size(); j++)
            vis[added[j]]=false;
    }
}

int solution(int n, int infection, vector<vector<int>> edges, int k) {
    graph = vector<vector<pair<int,int>>>(n+1);
    line = vector<vector<pair<int,int>>>(3);
    for(int i=0; i<edges.size(); i++)
    {
        graph[edges[i][0]].push_back({edges[i][1], edges[i][2]-1});
        graph[edges[i][1]].push_back({edges[i][0], edges[i][2]-1});
        line[edges[i][2]-1].push_back({edges[i][0],edges[i][1]});
    }
    
    vector<bool> vis(n+1, false);
    vis[infection]=true;
    int answer = 0; // 감염 수
    dfs(n, vis, -1, k, 1, answer);
    
    return answer;
}
```
### 시간복잡도
- 상태 수는 원본과 같음 (약 3 * 2^k 개)
- 상태 당 시드 수집 = O(n)
  - BFS는 새 노드의 차수 합이므로 O(n)이하, 복구 O(n)
- = O(3 * 2^k * n) = 약 3천 * 100 = 3 * 10^5
  - 원본보다 n배 빠름

### 동작 원리
- 정확성 문제 없음
- 지수 시간 O(2^k)는 그대로. k<=0이라 문제 없음
  - 상태 중복 제거(메모이제이션) 하지 않음
- 시드 수집 중 이미 표시한 시드가 뒤 간선의 vis 비교에 영향을 줌
  - 결과는 같지만 순서 의존적 구조라 읽을 때 한 번 더 따져 봐야 함

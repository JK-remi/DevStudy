# [단속카메라](https://school.programmers.co.kr/learn/courses/30/lessons/42884#)

## 문제 설명
고속도로를 이동하는 모든 차량이 고속도로를 이용하면서 단속용 카메라를 한 번은 만나도록 카메라를 설치하려고 합니다.

고속도로를 이동하는 차량의 경로 routes가 매개변수로 주어질 때, 모든 차량이 한 번은 단속용 카메라를 만나도록 하려면 최소 몇 대의 카메라를 설치해야 하는지를 return 하도록 solution 함수를 완성하세요.

## 제한사항

차량의 대수는 1대 이상 10,000대 이하입니다.  
routes에는 차량의 이동 경로가 포함되어 있으며 routes\[i]\[0]에는 i번째 차량이 고속도로에 진입한 지점, routes\[i]\[1]에는 i번째 차량이 고속도로에서 나간 지점이 적혀 있습니다.  
차량의 진입/진출 지점에 카메라가 설치되어 있어도 카메라를 만난것으로 간주합니다.  
차량의 진입 지점, 진출 지점은 -30,000 이상 30,000 이하입니다.  

## 입출력 예

|routes|return|
|------|---|
|\[\[-20,-15], \[-14,-5], \[-18,-13], \[-5,-3]]|2|

### 입출력 예 설명

-5 지점에 카메라를 설치하면 두 번째, 네 번째 차량이 카메라를 만납니다.

-15 지점에 카메라를 설치하면 첫 번째, 세 번째 차량이 카메라를 만납니다.

## ver1. 사전식 정렬
```
int solution(vector<vector<int>> routes) {
    priority_queue<vector<int>, vector<vector<int>>, greater<vector<int>>> pq(routes.begin(), routes.end());
    int answer = 0;
    int l=-30000,r=30000, cnt=0;
    while(!pq.empty())
    {
        vector<int> v=pq.top(); pq.pop();
        l=max(l, v[0]);
        r=min(r, v[1]);
        
        cnt++;
        if(l>r)
        {
            cnt=pq.empty();
            l=r;
            r=v[1];
            answer++;
        }
    }
    answer+=cnt>0;
    
    return answer;
}
```
시간복잡도: 정렬/힙 구성(O(N logN) (heapify + N번 pop, 각 (O(logN)) + 비교 연산 비용(벡터 2개) = O(N logN)  
첫점 기준 오름차순 정렬해서 pq에 저장  
l, r로 교집합 구간 추적  
l > r (교집합 깨짐)이 되면 그룹 끊고 카메라 배치(answer++)  

### 문제점
- 오름차순 정렬했기 때문에 l = v[0] (항상)
- cnt = pq.empty() (카운터 불리언 재활용) / l=r (다음 스텝에서만 의미) = 가독성 떨어짐, 의도 파악 어려움

## ver+. 끝점 기준 정렬
```
int solution(vector<vector<int>> routes) {
    sort(routes.begin(), routes.end(),
         [](const vector<int>& a, const vector<int>& b) {
             return a[1] < b[1];
         });

    int answer = 0;
    int camera = -30001; // 가장 작은 route[0]보다 작은 초기값

    for (auto& r : routes) {
        if (r[0] > camera) {   // 현재 카메라로 커버 안 되면
            camera = r[1];     // 새 카메라를 이 구간의 끝점에 배치
            answer++;
        }
    }
    return answer;
}
```
시간복잡도: 정렬(O(N logN)) + int 1개 비교 = O(N logN) (ver1과 점근적으로 동일하나 상수 계수 우세 + 가독성)  
카메라 최대한 뒤로 미룬다. (= 그리디 교환 논증(exchange argument) = 직관적 증명 = 이해/유지보수 쉬움)  
vector<int> 비교보다 int 하나 비교하므로, 더 빠름  
힙 구조 유지 오버헤드 없이 단순 배열 순회

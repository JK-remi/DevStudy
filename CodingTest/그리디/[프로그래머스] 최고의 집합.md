# [최고의 집합](https://school.programmers.co.kr/learn/courses/30/lessons/12938)

## 문제 설명
자연수 n 개로 이루어진 중복 집합(multi set, 편의상 이후에는 "집합"으로 통칭) 중에 다음 두 조건을 만족하는 집합을 최고의 집합이라고 합니다.

1. 각 원소의 합이 S가 되는 수의 집합
2. 위 조건을 만족하면서 각 원소의 곱 이 최대가 되는 집합

예를 들어서 자연수 2개로 이루어진 집합 중 합이 9가 되는 집합은 다음과 같이 4개가 있습니다.
{ 1, 8 }, { 2, 7 }, { 3, 6 }, { 4, 5 }
그중 각 원소의 곱이 최대인 { 4, 5 }가 최고의 집합입니다.

집합의 원소의 개수 n과 모든 원소들의 합 s가 매개변수로 주어질 때, 최고의 집합을 return 하는 solution 함수를 완성해주세요.

## 제한사항
- 최고의 집합은 오름차순으로 정렬된 1차원 배열(list, vector) 로 return 해주세요.
- 만약 최고의 집합이 존재하지 않는 경우에 크기가 1인 1차원 배열(list, vector) 에 -1 을 채워서 return 해주세요.
- 자연수의 개수 n은 1 이상 10,000 이하의 자연수입니다.
- 모든 원소들의 합 s는 1 이상, 100,000,000 이하의 자연수입니다.

## 입출력 예
|n|s|result|
|-|-|-----|
|2|9|/[4, 5]|
|2|1|/[-1]|
|2|8|/[4, 4]|

### 입출력 예 설명
#### 입출력 예#1
문제의 예시와 같습니다.

#### 입출력 예#2
자연수 2개를 가지고는 합이 1인 집합을 만들 수 없습니다. 따라서 -1이 들어있는 배열을 반환합니다.

#### 입출력 예#3
자연수 2개로 이루어진 집합 중 원소의 합이 8인 집합은 다음과 같습니다.

{ 1, 7 }, { 2, 6 }, { 3, 5 }, { 4, 4 }

그중 각 원소의 곱이 최대인 { 4, 4 }가 최고의 집합입니다.

## ver1. 오름차순 조합 DFS 완전 탐색
```c++
void dfs(const int n, const int s, int sum, int mul, int &m, vector<int> &v, vector<int> &ans)
{
    if(v.size()==n)
    {
        if(sum==s && mul>m)
            ans=v, m=mul;            
        return;
    }
    
    if(n-v.size()==1)
    {
        if(s-sum>=v.back())
        {
            v.push_back(s-sum);
            dfs(n, s, s, mul*v.back(), m, v, ans);
            v.pop_back();
        }
    }
    else
    {
        for(int i=v.empty()?1:v.back(); sum+n*i<=s; i++)
        {
            v.push_back(i);
            dfs(n, s, sum+v.back(), mul*v.back(), m, v, ans);
            v.pop_back();
        }
    }
}

vector<int> solution(int n, int s) {
    vector<int> answer;
    vector<int> tmp;
    int mul=1;
    dfs(n, s, 0, 1, mul, tmp, answer);
    
    if(answer.empty()) answer.push_back(-1);
    return answer;
}
```
### 시간복잡도
- 합이 s인 n개의 오름차순 자연수 조합수 = s의 n분할(partition)개수만큼 탐색
- n,s 커질수록 지수적 폭발
- 조합마다 ans=v 복사(O(n)) 추가

### 동작 원리
- 벡터 v에 원소를 하나씩 push하며 오름차순 조합 모두생성
- 각 원소는 직전 원소 이상의 값만 선택(i의 시작값이 v.back())
- 마지막원소는 s-sum으로 자동 결정, 직전 원소 이상일 때만 유효
- 조합이 완성될 때마다 곱 mul을 현재 최댓값 m과 비교해 더 크면 ans를 갱신
- 반복문 조건 sum + n*i <= s로 남은 원소가 모두 i 이상이어야 한다는 최소한의 가지치기만 함   

### 문제점
- 시간초과: 곱이 최대인 조합이 균등 분배라는 규칙을 활용하지 않고 모든 경우 확인
- 최댓값을 알 수 없어 끝까지 내려가야 하므로 곱 기준 가지치기가 불가능
- 재귀 깊이가 n이라 n이 크면 스택 부담 있음
- long long 곱이 커지면 오버플로 위험
- ans=v 복사 비용 반복

## ver+. 균등 분배 그리디 (몫/나머지)
```c++
vector<int> solution(int n, int s) {
    if(n>s) return {-1};
    
    vector<int> answer(n, s/n);
    for(int i=n-1, t=s%n; t>0; i--, t--)
        answer[i]++;
    return answer;
}
```
### 시간복잡도
- O(n): 벡터 생성 O(n) + 나머지 분배 최대 O(n)이 전부
  - 곱셈 / 재귀 없음

### 동작 원리
-  n>s 이면 자연수로 채울 수 없으므로 {-1}을 반환
-  모든 원소를 s/n으로 초기화
-  나머지 s%n만큼 뒤에서부터 1씩 더함
-  결과는 앞쪽이 몫, 뒤쪽이 몫+1이라 자동으로 오름차순
-  근거는 합이 같을때 두 수의 차이가 작을수록 곱이 커진다는 성질

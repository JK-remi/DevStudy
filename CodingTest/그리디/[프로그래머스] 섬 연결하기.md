# [섬 연결하기](https://school.programmers.co.kr/learn/courses/30/lessons/42861)

## 문제 설명
n개의 섬 사이에 다리를 건설하는 비용(costs)이 주어질 때, 최소의 비용으로 모든 섬이 서로 통행 가능하도록 만들 때 필요한 최소 비용을 return 하도록 solution을 완성하세요.  

다리를 여러 번 건너더라도, 도달할 수만 있으면 통행 가능하다고 봅니다. 예를 들어 A 섬과 B 섬 사이에 다리가 있고, B 섬과 C 섬 사이에 다리가 있으면 A 섬과 C 섬은 서로 통행 가능합니다.  

## 제한사항

섬의 개수 n은 1 이상 100 이하입니다.  
costs의 길이는 ((n-1) * n) / 2이하입니다.  
임의의 i에 대해, costs\[i]\[0] 와 costs\[i]\[1]에는 다리가 연결되는 두 섬의 번호가 들어있고, costs\[i]\[2]에는 이 두 섬을 연결하는 다리를 건설할 때 드는 비용입니다.  
같은 연결은 두 번 주어지지 않습니다. 또한 순서가 바뀌더라도 같은 연결로 봅니다. 즉 0과 1 사이를 연결하는 비용이 주어졌을 때, 1과 0의 비용이 주어지지 않습니다.  
모든 섬 사이의 다리 건설 비용이 주어지지 않습니다. 이 경우, 두 섬 사이의 건설이 불가능한 것으로 봅니다.  
연결할 수 없는 섬은 주어지지 않습니다.  

## 입출력 예
|n|costs|return|
|---|---|---|
|4|\[\[0,1,1],\[0,2,2],\[1,2,5],\[1,3,1],\[2,3,8]]|4|

## ver1. DFS
```
void dfs(const int n, const vector<vector<int>> &m, vector<int> &vis, int idx, int sum, int &ans)
{
    bool f = true;
    for(int i=0; i<n && f; i++)
        f&=vis[i]>0;
    
    if(f)
    {
        ans=min(ans,sum);
        return;
    }
    
    for(int i=0; i<n; i++)
    {
        if(vis[i]>1 || m[idx][i]<0) continue;
        vis[i]++;
        if(vis[i]==1)
            dfs(n, m, vis, i, sum+m[idx][i], ans);
        else if(vis[i]==2)
            dfs(n, m, vis, i, sum, ans);
        vis[i]--;
    }
}

int solution(int n, vector<vector<int>> costs) {
    vector<vector<int>> m(n, vector<int>(n, -1));
    int answer = 0;
    vector<int> cnt(n,0);
    for(int i=0; i<costs.size(); i++)
    {
        vector<int> tmp = costs[i];
        m[tmp[0]][tmp[1]]=tmp[2];
        m[tmp[1]][tmp[0]]=tmp[2];
        cnt[tmp[0]]++, cnt[tmp[1]]++;
        answer+=tmp[2];
    }
    
    int idx = min_element(cnt.begin(), cnt.end()) - cnt.begin();
    vector<int> vis(n, 0);
    vis[idx]++;
    dfs(n, m, vis, idx, 0, answer);
    vis[idx]--;
    
    return answer;
}
```
시간복잡도: 지수적 (사실상(O(N!))   
모든 트리 완전 탐색(브루트 포스 DFS)  

### 문제점
- 시간복잡도 폭발
  -  이미 방문 노드 "공짜 이동(vis\[i]==2)" 무제한 허용 = 같은 상태 반복
  -  n 커지면 시간 내 끝나지 않음 = **시간 초과**
  -  메모리제이션 X: 같은 vis 상태 & idx 조합 재계산

**MST 에는 완전 탐색 필요 없음** 

## ver+1. Kruskal
```
vector<int> parent;

int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]); // 경로 압축
}

bool unite(int a, int b) {
    a = find(a), b = find(b);
    if (a == b) return false; // 이미 같은 집합 -> 사이클
    parent[a] = b;
    return true;
}

int solution(int n, vector<vector<int>> costs) {
    parent.resize(n);
    iota(parent.begin(), parent.end(), 0); // 0,1,2,...,n-1로 초기화

    sort(costs.begin(), costs.end(), [](const vector<int>& a, const vector<int>& b) {
        return a[2] < b[2]; // 비용 오름차순
    });

    int answer = 0;
    int edgeCount = 0;
    for (auto& c : costs) {
        if (unite(c[0], c[1])) {
            answer += c[2];
            edgeCount++;
            if (edgeCount == n - 1) break; // 트리 완성되면 종료
        }
    }

    return answer;
}
```
시간복잡도: 정렬(O(E logE)) + Union-Find(O(E a(V)) = O(E log(E)) (E=Edge, V=Vertex)  
간선을 비용 중심 오름차순 정렬  
**작은 것**부터 순서대로, 사이클 안 생기면(find()로 parent 중복 검사) 채택  
Union-Find로 **같은 집합**인지 O(a(n)) 거의 상수 시간에 판별  
edgeCount: n-1개면 스패닝 트리(모든 노드 연결) 완성  

## ver+2. Prim
```
int solution(int n, vector<vector<int>> costs) {
    vector<vector<pair<int,int>>> adj(n); // adj[u] = {(cost, v), ...}
    for (auto& c : costs) {
        adj[c[0]].push_back({c[2], c[1]});
        adj[c[1]].push_back({c[2], c[0]});
    }

    vector<bool> vis(n, false);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq; // (cost, node)
    pq.push({0, 0}); // 0번 노드에서 시작

    int answer = 0, count = 0;
    while (!pq.empty() && count < n) {
        auto [cost, u] = pq.top(); pq.pop();
        if (vis[u]) continue; // 이미 트리에 포함된 노드면 스킵

        vis[u] = true;
        answer += cost;
        count++;

        for (auto& [w, v] : adj[u]) {
            if (!vis[v]) pq.push({w, v});
        }
    }

    return answer;
}
```
시간복잡도: O(E logV) (E=Edge, V=Vertex)   
vis로 방문 체크  
count: 트리에 편입시킨 (방문 완료) 노드 수  

1. pq에서 제일 cost 작은 거 꺼냄(우선순위 큐 자동 정렬)
2. 그 노드가 vis면 무시. 다음 것 꺼냄(더 싼 경로로 이미 편입)
3. vis 아니면 트리에 편입 (vis=true, answer+=cost, count++)
4. 편입된 노드에서 연결된 간선 중 방문 X 노드 전부 pq에 삽입

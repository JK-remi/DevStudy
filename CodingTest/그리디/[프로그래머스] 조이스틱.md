# [조이스틱](https://school.programmers.co.kr/learn/courses/30/lessons/42860)

## 문제 설명
조이스틱으로 알파벳 이름을 완성하세요. 맨 처음엔 A로만 이루어져 있습니다.  
ex) 완성해야 하는 이름이 세 글자면 AAA, 네 글자면 AAAA  

조이스틱을 각 방향으로 움직이면 아래와 같습니다.  

▲ - 다음 알파벳  
▼ - 이전 알파벳 (A에서 아래쪽으로 이동하면 Z로)  
◀ - 커서를 왼쪽으로 이동 (첫 번째 위치에서 왼쪽으로 이동하면 마지막 문자에 커서)  
▶ - 커서를 오른쪽으로 이동 (마지막 위치에서 오른쪽으로 이동하면 첫 번째 문자에 커서)  
예를 들어 아래의 방법으로 "JAZ"를 만들 수 있습니다.  

- 첫 번째 위치에서 조이스틱을 위로 9번 조작하여 J를 완성합니다.  
- 조이스틱을 왼쪽으로 1번 조작하여 커서를 마지막 문자 위치로 이동시킵니다.  
- 마지막 위치에서 조이스틱을 아래로 1번 조작하여 Z를 완성합니다.  
따라서 11번 이동시켜 "JAZ"를 만들 수 있고, 이때가 최소 이동입니다.  
만들고자 하는 이름 name이 매개변수로 주어질 때, 이름에 대해 조이스틱 조작 횟수의 최솟값을 return 하도록 solution 함수를 만드세요.  

## 제한 사항
name은 알파벳 대문자로만 이루어져 있습니다.  
name의 길이는 1 이상 20 이하입니다.  

## 입출력 예
|name|return|
|---|---|
|"JEROEN"|56|
|"JAN"|23|

## 핵심 구조
* 상하(문자 변경) 비용: 각 자리마다 독립적으로 방문순서와 무관하게 항상 동일한 값 합산 ('A' 시작)
* 좌우(커서 이동) 비용: 원형 배열에서 0번부터 시작해 'A가 아닌' 자리를 모두 방문하는 최소 이동 거리

## ver1. 최근접 탐색
```
int solution(string name) {
    int l=name.length();
    string tmp(l, 'A');
    vector<int> cntV(l, 0);
    for(int i=0, c; i<l; i++)
    {
        c=name[i]-tmp[i];
        cntV[i]=min(c, 26-c);
    }
    
    int answer = 0;
    for(int idx=0, t; tmp!=name; )
    {
        pair<int, int> next;
        answer += cntV[idx];
        tmp[idx]=name[idx];
        if(tmp==name) break;
        
        for(int i=idx+1, m=50; i%l!=idx; i++)
        {
            i%=l;
            if(tmp[i]==name[i]) continue;
            t=min(abs(i-idx), l-abs(idx-i));
            if(t+cntV[i]<m)
            {
                next = {i, t};
                m = t+cntV[i];
            }
        }
        
        answer+=next.second;
        idx = next.first;
    }
    
    return answer;
}
```
시간복잡도: O(N^2)  
공간복잡도: O(N)  
매번 '지금' 가장 가까운 곳(이동 + 문자 변환 적은 곳) 찾아 움직임  
문제: 지역적으로는 최적. but 전체 이동 경로 최적 보장 X  

## ver2. 모든(전환점, 방향) 조합 탐색
```
int calc(const string &name, const int l, int idx, int dir)
{
    int move = min(idx, l-idx);
    
    for(int i=dir>0?idx:l+idx, j=1, cnt=0; j<l; j++)
    {
        if(name[i+dir*j]=='A') cnt++;
        else 
        {
            move+=cnt+1;
            cnt=0;
        }
    }
    
    return move;
}

int solution(string name) {
    int l=name.length();
    
    int answer = 0, tmp=l;
    name+=name;
    for(int i=0; i<l; i++)
    {
        answer += min((int)(name[i]-'A'), (int)('Z'-name[i])+1);
        tmp = min({tmp, calc(name, l, i, 1), calc(name, l, i, -1)});
    }
    answer+=tmp;
    
    return answer;
}
```
시간복잡도: O(N^2)  
공간복잡도: O(N) (문자열 2배 (dir))  
name+name: 배열을 이어붙여 원형을 직선으로 펼침  
모든 idx에 대해 0에서 idx까지 최단 직선 이동 후, dir 방향으로 끝까지 훑기 (단, 마지막 연속된 A는 스킵)  
모든 전환 지점(idx) & 방향(dir) 탐색하므로 정확  

## ver+. 단일 패스
```
int solution(string name) {
    int size=name.size();
    int answer = 0, tmp=size-1;
    for(int i=0, s=0; i<size; i++)
    {
        answer += min(name[i]-'A', 'Z'-name[i]+1);
        if(name[i]!='A'&&s!=i)
        {
            tmp=min({tmp,2*s+(size-i),(size-i)*2+s});
            s=i;
        }
        else if(name[i]=='A'&&i==name.size()-1)
            tmp=min(tmp, s);
    }
    answer+=tmp;
    
    return answer;
}
```
시간복잡도: O(N)  
공간복잡도: O(1)  
연속된 A구간 기준 방향 바꾸는 것이 이득인지 계산  
s(이전), i(현재) 쌍마다 두 후보를 비교: 
- 2 * s + (n-i): s까지 갔다가 원점으로 복귀 후, wrap으로 i까지
  - 오른쪽으로 s까지 이동 후 원점 까지 돌아온 후 남은 구간 방문 
- 2 * (n-i) + s: 반대쪽(wrap)으로 i까지 갔다가 복귀 후, s까지
  - 왼쪽부터 먼저 방문한 뒤 오른쪽으로 돌아오는 경우

**좌우 이동은 방향을 여러번 바꾸는 것보다 최대 한 번만 방향을 바꾸는 것이 항상 최적.**

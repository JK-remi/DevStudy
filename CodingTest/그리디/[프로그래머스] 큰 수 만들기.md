# [큰 수 만들기](https://school.programmers.co.kr/learn/courses/30/lessons/42883)

## 문제 설명
어떤 숫자에서 k개의 수를 제거했을 때 얻을 수 있는 가장 큰 숫자를 구하려 합니다.  

예를 들어, 숫자 1924에서 수 두 개를 제거하면 \[19, 12, 14, 92, 94, 24] 를 만들 수 있습니다. 이 중 가장 큰 숫자는 94 입니다.  

문자열 형식으로 숫자 number와 제거할 수의 개수 k가 solution 함수의 매개변수로 주어집니다. number에서 k 개의 수를 제거했을 때 만들 수 있는 수 중 가장 큰 숫자를 문자열 형태로 return 하도록 solution 함수를 완성하세요.

## 제한 조건
number는 2자리 이상, 1,000,000자리 이하인 숫자입니다.  
k는 1 이상 number의 자릿수 미만인 자연수입니다.  

## 입출력 예
|number|k|return|
|---|---|---|
|"1924"|2|"94"|
|"1231234"|3|"3234"|
|"4177252841"|4|"775841"|

## ver1. DFS
```
void dfs(const string &num, const int l, int idx, string tmp, string &ans)
{
    if(tmp.length()==l)
    {
        ans = tmp>ans? tmp:ans;
        return;
    }
    if(num.length()-idx < l-tmp.length()) return;

    for(int i=idx+1; i<num.length(); i++)
        dfs(num, l, i, tmp+num[i], ans);
}

string solution(string number, int k) {
    string answer = "";
    dfs(number, number.length()-k, -1, "", answer);
    return answer;
}
```
시간복잡도: O(N! / (N-1)!) = O(C(N, l) * l) = 지수적 증가 (최악)  
전체 조합을 탐색 후 가장 큰 값 색출  
순열 수만큼 재귀 호출 =  N * (N-1) * ... * (N-l+1) = N! / (N-1)! = P(N, l)  

## ver2. find 기반 Greedy
```
string solution(string number, int k) {
    string answer = "";
    
    int l = number.length() - k;
    int idx=0, pre=0;
    for(char c='9'; c>='0' && answer.length() != l; )
    {
        idx = number.find(c, pre);
        if(idx == string::npos
            || answer.length() + number.length()-idx < l)
        {
            c--;
            continue;
        }
        
        answer+=number[idx];
        pre=idx+1;
        c='9';
    }
    
    return answer;
}
```
시간복잡도: O(9 * l * N)(find = 선형 탐) = O(N^2) (최악)  
각 자리마다 '9'부터 내려가며 find(c, pre)로 그 문자가 실현 가능 범위 안에 있는지 확인하는 방식  

## ver+. 모노토닉 스택
```
string solution(string number, int k) {
    string st;
    st.reserve(number.size());

    for (char c : number) {
        while (k > 0 && !st.empty() && st.back() < c) {
            st.pop_back();
            k--;
        }
        st.push_back(c);
    }
    st.resize(st.size() - k);  // k가 남아있으면 뒤에서 제거
    return st;
}
```
시간복잡도: O(N)  
스택 top이 현재 문자보다 작다 = 더 큰 수 만들 여지 있음 = pop(k하나 소모)  
각 문자는 최대 한 번 push, 한 번 pop

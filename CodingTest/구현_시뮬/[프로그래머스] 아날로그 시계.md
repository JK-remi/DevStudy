## 문제 설명
시침, 분침, 초침이 있는 아날로그시계가 있습니다. 시계의 시침은 12시간마다, 분침은 60분마다, 초침은 60초마다 시계를 한 바퀴 돕니다. 따라서 시침, 분침, 초침이 움직이는 속도는 일정하며 각각 다릅니다. 
이 시계에는 초침이 시침/분침과 겹칠 때마다 알람이 울리는 기능이 있습니다. 당신은 특정 시간 동안 알람이 울린 횟수를 알고 싶습니다.

## 제한사항
- 0 ≤ h1, h2 ≤ 23
- 0 ≤ m1, m2 ≤ 59
- 0 ≤ s1, s2 ≤ 59
- h1시 m1분 s1초부터 h2시 m2분 s2초까지 알람이 울리는 횟수를 센다는 의미입니다.
  - h1시 m1분 s1초 < h2시 m2분 s2초
  - 시간이 23시 59분 59초를 초과해서 0시 0분 0초로 돌아가는 경우는 주어지지 않습니다.

## ver1. 초 단위 시뮬레이션
```
int solution(int h1, int m1, int s1, int h2, int m2, int s2) {
    int answer = 0;
    for(int h=h1, m=m1, s=s1; h!=h2&&m!=m2&&s!=s2; s++)
    {
        if(s==60) m++, s=0;
        if(m==60) h++, m=0;
        if(h==h2 && m==m2 && s==s2) break;
        
        if(h/2==m/5||h/2==s/5||m==s) answer++;
    }
    return answer;
}
```
### 시간복잡도
- s가 1씩 증가하면서 매 반복마다 h,m,s 갱신 단일 for문 = O(N)=86399(c최악)

### 동작 원리
- h,m,s를 h1,m1,s1부터 시작해 매 반복마다 1초씩 늘리고 60초가 되면 분을, 60분이 되면 시를 올리는 방식
- 매 정수초마다 h/2==m/5 || h/2==s/5 || m==s 검사해서 알람 카운트
- 반복 종료는 h!=h2 && m!=m2 && s!=s2. 세 값이 목표값과 다를 떄 계속 반복

### 문제점
- 겹침이 실제로 일어나는 시간은 항상 소수점 이하
  - 정수 단위 검사이므로, 겹침 잡아낼 수 없음
- 겹침 조건이 실제 각도와 무관함
- 종료 조건이 AND이므로, 한 값이라도 목표와 같아지는 경우 반복 멈춤

## ver+. 겹침 주기 계산
```
int solution(int h1, int m1, int s1, int h2, int m2, int s2) {
    int t1=h1*60*60+m1*60+s1;
    int t2=h2*60*60+m2*60+s2;
    
    int answer = 0;
    for(int k=0;  ;k++)
    {
        int hs=k*360*120;
        int ms=k*360*10;
        if(hs>=t1*719 && hs<=t2*719) answer++;
        if(ms>=t1*59 && ms<=t2*59) answer++;
        
        if(hs>t2*719 && ms>t2*59) break;
    }
    const int mn=0, noon=12*60*60;
    if(t1<=mn && mn<=t2) answer--;
    if(t1<=noon && noon<=t2) answer--;
    
    return answer;
}
```
### 시간복잡도
- O(N/60): N=구간 길이

### 동작 원리
- 시간을 정수 초로 환산. 이후 모든 계산은 실수 없이 정수로만 진행
- 두 종류의 **겹침 사건**을 각각 등차수열로 모델링
  - 초침(6°/초), 시침(1/120°/초)의 상대각속도 = 6-1/120 = 719/120(°초)
    - 상대각이 360°씩 쌓일 때마다 다시 겹침
    - T_hs(k) = (360/(719/120))*k = (43200/719)*k
  - 초침, 분침(0.1°/초) 상대각속도 = 6-0.1 = 59/10(°초)
    - T_ms(k) = (360/(59/10))*k = (3600/59)*k
  - 서로 완전히 독립된 두 개의 등차수열
  - \[t1, t2]구간에 몇개의 k있는지 세면 된다.
- 나눗셈 대신 정수 스케일링으로 부동소수점오차 제거
  - T_hs(k)는 분모가 719이므로, t1 <= 43200*k/719 <= t2의 양변에 719 곱해서 스케일링
    - t1*719 <= 43200*k <= t2*719
  - T_ms(k)는 분모가 59이므로, t1 <= 3600*k/59 <= t2의 양변에 59 곱해서 스케일링
    - t1*59 <= 3600*k <= t2*59
- k를 늘려가며 두 수열을 각각 독립적으로 검사
- 자정/정오 이중 카운트 보정
  - 자정: t=0, 정오: t=12*60*60=43200
  - 자정/정오는 세 바늘이 동시에 겹치는 특수 시각 = hs, ms 양쪽 모두 속함 (더블 카운트)
  - 루프 끝난 후 \[t1, t2]에 자정/정오 속한 경우 -1

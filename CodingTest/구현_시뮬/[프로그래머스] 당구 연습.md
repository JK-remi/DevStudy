# [당구 연습](https://school.programmers.co.kr/learn/courses/30/lessons/169198#)

## 문제 설명
프로그래머스의 마스코트인 머쓱이는 최근 취미로 당구를 치기 시작했습니다.

머쓱이는 손 대신 날개를 사용해야 해서 당구를 잘 못 칩니다. 하지만 끈기가 강한 머쓱이는 열심히 노력해서 당구를 잘 치려고 당구 학원에 다니고 있습니다.

오늘도 당구 학원에 나온 머쓱이에게 당구 선생님이"원쿠션"(당구에서 공을 쳐서 벽에 맞히는 걸 쿠션이라고 부르고, 벽에 한 번 맞힌 후 공에 맞히면 원쿠션이라고 부릅니다) 
연습을 하라면서 당구공의 위치가 담긴 리스트를 건네줬습니다. 리스트에는 머쓱이가 맞춰야 하는 공들의 위치가 담겨있습니다. 
머쓱이는 리스트에 담긴 각 위치에 순서대로 공을 놓아가며 "원쿠션" 연습을 하면 됩니다. 이때, 머쓱이는 항상 같은 위치에 공을 놓고 쳐서 리스트에 담긴 위치에 놓인 공을 맞춥니다.

머쓱이와 달리 최근 취미로 알고리즘 문제를 풀기 시작한 당신은, 머쓱이가 친 공이 각각의 목표로한 공에 맞을 때까지 최소 얼마의 거리를 굴러가야 하는지가 궁금해졌습니다.

당구대의 가로 길이 m, 세로 길이 n과 머쓱이가 쳐야 하는 공이 놓인 위치 좌표를 나타내는 두 정수 startX, startY, 
그리고 매 회마다 목표로 해야하는 공들의 위치 좌표를 나타내는 정수 쌍들이 들어있는 2차원 정수배열 balls가 주어집니다. 
"원쿠션" 연습을 위해 머쓱이가 공을 적어도 벽에 한 번은 맞춘 후 목표 공에 맞힌다고 할 때, 
각 회마다 머쓱이가 친 공이 굴러간 거리의 최솟값의 제곱을 배열에 담아 return 하도록 solution 함수를 완성해 주세요.

단, 머쓱이가 친 공이 벽에 부딪힐 때 진행 방향은 항상 입사각과 반사각이 동일하며, 만약 꼭짓점에 부딪힐 경우 진입 방향의 반대방향으로 공이 진행됩니다. 
공의 크기는 무시하며, 두 공의 좌표가 정확히 일치하는 경우에만 두 공이 서로 맞았다고 판단합니다. 공이 목표 공에 맞기 전에 멈추는 경우는 없으며, 목표 공에 맞으면 바로 멈춘다고 가정합니다.

## 제한사항
- 3 ≤ m, n ≤ 1,000
- 0 < startX < m
- 0 < startY < n
- 2 ≤ balls의 길이 ≤ 1,000
- balls의 원소는 \[a, b] 형태입니다.
  - a, b는 머쓱이가 맞춰야 할 공이 놓인 좌표를 의미합니다.
  - 0 < a < m, 0 < b < n
  - (a, b) = ( startX, startY )인 입력은 들어오지 않습니다.

|---|---|---|---|----------|-----|

## ver1. 벽·모서리 반사 공식 개별 나열형
```c++
int pow(int n)
{
    return n*n;
}

vector<int> solution(int m, int n, int startX, int startY, vector<vector<int>> balls) {
    vector<int> answer(balls.size(), 2000000);
    for(int i=0, y, x; i<balls.size(); i++)
    {
        x=balls[i][0], y=balls[i][1];
        
        if(!(y==startY && x<startX)) answer[i]=min(answer[i], pow(startY-y)+pow(startX+x));
        if(!(x==startX && y<startY)) answer[i]=min(answer[i], pow(startY+y)+pow(startX-x));
        if(!(y==startY && x>startX)) answer[i]=min(answer[i], pow(startY-y)+pow(startX-(2*m-x)));
        if(!(x==startX && y>startY)) answer[i]=min(answer[i], pow(startY-(2*n-y))+pow(startX-x));
        
        if(x*startY==startX*y && !(x<startX)) 
            answer[i]=min(answer[i], pow(x+startX)+pow(y+startY));
        if((x-m)*startY==(startX-m)*y && !(x>startX))
            answer[i]=min(answer[i], pow(x+startX-2*m)+pow(y+startY));
        if(x*(startY-n)==startX*(y-n) && !(x<startX))
            answer[i]=min(answer[i], pow(x+startX)+pow(y+startY-2*n));
        if((x-m)*(startY-n)==(startX-m)*(y-n) && !(x>startX))
            answer[i]=min(answer[i], pow(x+startX-2*m)+pow(y+startY-2*n));
    }
    return answer;
}
```
## 시간복잡도
- 공 하나당 상수 개(8개)의 후보만 계산
- = O(N) (N = balls.size())

## 동작 원리
- 목표 공을 각 벽(왼쪽/오른쪽/위/아래) 기준으로 대칭이동시킨 뒤 시작점과의 직선거리 제곱을 후보로 계산하는 "미러링(거울상)" 기법을 4번 반복
- 시작점과목표점이 같은 행(y==startY) 또는 같은 열(x==startX)에 잇을 때 목표가 시작점과 벽 사이에 끼어 있으면 해당 방향 후보 배제
  - 공이 벽에 닿기 전에 목표를 먼저 지나쳐버리므로
- 시작점·목표점·모서리가 일직선(콜리니어, x*startY==startX*y)이고, 목표가 모서리에서 더 먼 경우 **모서리에서 반대 방향으로 튕겨 나온다**는 규칙에 따라 
  두 벡터가 평행할 때 성립하는 |A| + |B| = |A+B|를 이용해 루트 없이 (x+startX)^2 + (y+startY)^2 형태로 정확한 값을 구하는 후보 4개를 추가로 계산
- 총 8개(벽4 + 모서리4) 후보 중 최솟값 취함
  
## 문제점
- 각 방향 모서리 4개를 각각 부호를 바꿔가며 따로 적기 때문에 코드가 길고 중복이 많음
  - 구조적 실수 쉬운 형태 (세미콜론 오타, 부등호 방향, 모서리 공식 계산 실수)
- 벽 4개, 모서리 4개의 **무효 조건**이 서로 다른 부등호(<,>)를 쓰고 있어서 나중에 유사 문제를 풀 때 그대로 재활용 시 조건을 매번 다시 검증   
- 2,000,000이라는 매직넘버를 상한값으로 하드코딩 = 제약 바뀌면(m,n 더 커지면) 별도 계산 없이 값을 눈대중으로 다시 잡아야 함

## ver+. 루프 기반 통합형 (ver1 refactoring)
```c++
long long sq(long long v) { return v * v; }

vector<int> solution(int m, int n, int startX, int startY, vector<vector<int>>& balls) {
    vector<int> answer;
    answer.reserve(balls.size());

    for (auto& b : balls) {
        long long x = b[0], y = b[1];
        long long best = 8LL * ((long long)m*m + (long long)n*n); // 충분히 큰 안전한 상한

        // --- 벽 4개: x축 벽(0, m) / y축 벽(0, n) ---
        // wallX 방향 반사: target을 (2*w - x, y)로 미러링
        for (int w : {0, m}) {
            // 같은 행(y==startY)이고, target이 start와 벽 사이에 끼어 있으면
            // 벽에 닿기 전에 target을 먼저 맞히므로 무효
            bool blocked = (y == startY) && ((x - w) * (x - startX) < 0);
            if (!blocked)
                best = min(best, sq(startX + x - 2*w) + sq(startY - y));
        }
        // wallY 방향 반사: target을 (x, 2*w - y)로 미러링
        for (int w : {0, n}) {
            bool blocked = (x == startX) && ((y - w) * (y - startY) < 0);
            if (!blocked)
                best = min(best, sq(startX - x) + sq(startY + y - 2*w));
        }

        // --- 모서리 4개: (0,0), (m,0), (0,n), (m,n) ---
        for (int cx : {0, m}) for (int cy : {0, n}) {
            long long sx = startX - cx, sy = startY - cy; // 모서리 기준 상대좌표
            long long tx = x - cx,      ty = y - cy;
            bool collinear = (sx * ty == sy * tx);                 // 모서리·시작·목표 일직선
            bool fartherOrSame = (tx*tx + ty*ty) >= (sx*sx + sy*sy); // target이 모서리에서 더 멀어야 유효
            if (collinear && fartherOrSame)
                best = min(best, sq(sx + tx) + sq(sy + ty));
        }

        answer.push_back((int)best);
    }
    return answer;
}
```
## 동작 원리
- 벽 반사를 w ∈ {0, m} (x축 벽), w ∈ {0, n} (y축 벽)에 대해 루프로 통일
  - 무효 조건도 **목표가 시작점과 벽 사이 구간에 있는가**를 같은 부호 곱 하나로 표현
    - (x-w)*(x-startX) < 0
    - 벽이 어느 쪽이든 같은 식이 자동으로 맞는 부호를 만듦
- 모서리도 cx ∈ {0,m}, cy ∈ {0,n} 조합 4개를 루프로 순회
  - 모서리 기준 상대좌표로 바꾼 뒤 콜리니어 조건과 **목표가 모서리에서 더 멀거나 같은 거리인가**(거리 제곱 비교)를 판정합
  - 방향에 따라 다른 부등호를 쓰지 않고 항상 같은 비교식 사용
- 최종적으로 안전한 상한값(8*(m²+n²))에서 시작해 8개 후보의 최솟값을 취하는 구조는 동일

# [파괴되지 않은 건물](https://school.programmers.co.kr/learn/courses/30/lessons/92344)

## 문제 설명
N x M 크기의 행렬 모양의 게임 맵이 있습니다. 이 맵에는 내구도를 가진 건물이 각 칸마다 하나씩 있습니다. 적은 이 건물들을 공격하여 파괴하려고 합니다. 건물은 적의 공격을 받으면 내구도가 감소하고 내구도가 0이하가 되면 파괴됩니다. 반대로, 아군은 회복 스킬을 사용하여 건물들의 내구도를 높이려고 합니다.

적의 공격과 아군의 회복 스킬은 항상 직사각형 모양입니다.  
예를 들어, 아래 사진은 크기가 4 x 5인 맵에 내구도가 5인 건물들이 있는 상태입니다.

## 제한사항
- 1 ≤ board의 행의 길이 (= N) ≤ 1,000
- 1 ≤ board의 열의 길이 (= M) ≤ 1,000
- 1 ≤ board의 원소 (각 건물의 내구도) ≤ 1,000
- 1 ≤ skill의 행의 길이 ≤ 250,000
- skill의 열의 길이 = 6
- skill의 각 행은 \[type, r1, c1, r2, c2, degree]형태를 가지고 있습니다.
  - type은 1 혹은 2입니다.
    - type이 1일 경우는 적의 공격을 의미합니다. 건물의 내구도를 낮춥니다.
    - type이 2일 경우는 아군의 회복 스킬을 의미합니다. 건물의 내구도를 높입니다.
  - (r1, c1)부터 (r2, c2)까지 직사각형 모양의 범위 안에 있는 건물의 내구도를 degree 만큼 낮추거나 높인다는 뜻입니다.
    - 0 ≤ r1 ≤ r2 < board의 행의 길이
    - 0 ≤ c1 ≤ c2 < board의 열의 길이
    - 1 ≤ degree ≤ 500
    - type이 1이면 degree만큼 건물의 내구도를 낮춥니다.
    - type이 2이면 degree만큼 건물의 내구도를 높입니다.
- 건물은 파괴되었다가 회복 스킬을 받아 내구도가 1이상이 되면 파괴되지 않은 상태가 됩니다. 즉, 최종적으로 건물의 내구도가 1이상이면 파괴되지 않은 건물입니다.

## ver1. 부르트포스 구간 갱신
```c++
int solution(vector<vector<int>> board, vector<vector<int>> skill) {
    const int N=board.size(), M=board[0].size();
    int answer = N*M;
    for(const vector<int> &v:skill)
    {
        int n=v[0]==1?-1:1;
        n*=v[5];
        for(int i=v[1]; i<=v[3]; i++)
            for(int j=v[2]; j<=v[4]; j++)
            {
                int ori=board[i][j];
                board[i][j]+=n;
                if(ori<=0&&board[i][j]>0) answer++;
                else if(ori>0&&board[i][j]<=0) answer--;
            }
    }
    return answer;
}
```
### 시간복잡도
- O(K * N * M) = 최악 25만 * 1000 * 1000 = 2.5 * 10^11
  - K=skill 수 (최대 250,000), N*M = 보드 크기(최대 1,000*1,000)

### 동작 원리
- answer를 전체 칸 수 (N*M)으로 시작
- skill마다 (r1,c1)~(r2,c2)영역을 이중 for문으로 돌며 각 칸의내구도를 작접 더하거나 뺌
- 칸을 갱신할때마다 전후 상태를 비교해서 answer를 증감
  - 내구도가 1이상이던 칸이 0이하로 떨어지면 -1
  - 내구도가 0이하였다가 1이상으로 회복되면 +1
- 모든 skill 처리 후 answer = 파괴되지 않을 건물 수

### 문제점
- 정확성 O, 효율성 X
- 같은 칸을 skill마다 반복해서 건드리는 중복 연산

## ver+. 2차원 차이 배열 + 누적합
```c++
int solution(vector<vector<int>> board, vector<vector<int>> skill) {
    const int N=board.size(), M=board[0].size();
    vector<vector<int>> sum(N+1, vector<int>(M+1, 0));
    for(const vector<int> &v:skill)
    {
        int n=v[0]==1?-v[5]:v[5];
        int r1=v[1],c1=v[2],r2=v[3]+1,c2=v[4]+1;
        sum[r1][c1]+=n, sum[r2][c2]+=n;
        sum[r1][c2]-=n, sum[r2][c1]-=n;
    }
    
    for(int i=0; i<N; i++)
        for(int j=1; j<M; j++)
            sum[i][j]+=sum[i][j-1];
    for(int j=0; j<M; j++)
        for(int i=1; i<N; i++)
            sum[i][j]+=sum[i-1][j];
    
    int answer = 0;
    for(int i=0; i<N; i++)
        for(int j=0; j<M; j++)
            if(board[i][j]+sum[i][j]>0)
                answer++;
    
    return answer;
}
```
### 시간복잡도
- O(K + N*M) = 25만 + 1000\*1000= 1.25*10^6

### 동작 원리
- (N+1)*(M+1) 크기의 차이 배열 sum 생성
- skill마다 영역 전체를 건드리지 않고 모서리 네 점만 기록
  - (r1,c1)+n, (r1,c2+1)-n, (r2+1,c1)-n, (r2+1,c2+1)+n
- 모든skill 기록이 끝난뒤 행 누적 -> 열 누적을한 번씩 수행
  - 각 칸에 그 칸에 적용된 모든 skill의 변화량 총합 저장
- board\[i]\[j] + sum\[i]\[j] > 0 인 칸만 세서 답 제출

## 참고

### 2차원 누적합 (2D Difference Array + Prefix Sum)

#### 1. 개념

직사각형 구간에 값을 반복해서 더하는 갱신이 많고, 조회는 마지막에 한 번만 필요할 때 쓰는 기법입니다. 갱신마다 영역을 직접 순회하지 않고, **차이 배열에 모서리 4점만 기록**한 뒤 **마지막에 한 번 누적**해서 실제 값을 복원합니다.

#### 2. 핵심 아이디어

구간 `(r1,c1) ~ (r2,c2)`에 `+n`을 적용하려면 차이 배열 `diff`에 다음 4점을 기록합니다.

| 위치 | 변화량 | 의미 |
|---|---|---|
| `(r1, c1)` | `+n` | 영역 시작점 |
| `(r1, c2+1)` | `-n` | 오른쪽으로 빠져나가는 지점 |
| `(r2+1, c1)` | `-n` | 아래로 빠져나가는 지점 |
| `(r2+1, c2+1)` | `+n` | 중복으로 빠진 `-n` 상쇄 |

시작 부호를 `s`라 하면 **(+s, −s, −s, +s)** 로 기억하면 됩니다.

#### 3. 동작 과정

1. `(N+1)×(M+1)` 크기의 `diff` 배열을 0으로 초기화합니다.
2. 모든 갱신에 대해 모서리 4점을 기록합니다. (갱신 1개당 O(1))
3. **행 누적**: 각 행을 왼쪽에서 오른쪽으로 `diff[i][j] += diff[i][j-1]`
4. **열 누적**: 각 열을 위에서 아래로 `diff[i][j] += diff[i-1][j]`
5. `diff[i][j]`가 해당 칸에 적용된 모든 갱신의 총합이 됩니다. 원본 배열과 합산해 판정합니다.

> 행 누적을 배열 전체에 끝낸 뒤 열 누적을 시작해야 합니다. (순서를 바꿔도 결과는 같지만, 두 방향을 섞으면 안 됩니다.)

한 패스로 처리하는 방법도 있습니다.

```
diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1]
```

#### 4. 왜 동작하는가

- 행 누적을 하면 `(r1,c1)`의 `+n`이 오른쪽으로 퍼지고, `(r1,c2+1)`의 `-n`이 `c2+1` 이후를 0으로 되돌립니다.
- 열 누적을 하면 위 결과가 아래로 퍼지고, `(r2+1, ...)`의 값들이 `r2+1` 이후를 0으로 되돌립니다.
- `(r2+1, c2+1)`에는 오른쪽 끝과 아래 끝에서 `-n`이 두 번 전파되므로 `+n`으로 한 번 복구해야 합니다.
- 결과적으로 직사각형 영역에만 `n`이 남습니다.

#### 5. 복잡도

| 방식 | 시간복잡도 |
|---|---|
| 브루트포스 (갱신마다 영역 순회) | O(K × N × M) |
| 2차원 차이 배열 | O(K + N × M) |

K는 갱신 횟수, N×M은 배열 크기입니다.

#### 6. 구현 템플릿 (C++)

```cpp
vector<vector<int>> diff(N + 1, vector<int>(M + 1, 0));

// 갱신: (r1,c1) ~ (r2,c2)에 n 더하기
diff[r1][c1]         += n;
diff[r1][c2 + 1]     -= n;
diff[r2 + 1][c1]     -= n;
diff[r2 + 1][c2 + 1] += n;

// 행 누적
for (int i = 0; i < N; i++)
    for (int j = 1; j < M; j++)
        diff[i][j] += diff[i][j - 1];

// 열 누적
for (int j = 0; j < M; j++)
    for (int i = 1; i < N; i++)
        diff[i][j] += diff[i - 1][j];
```

#### 7. 주의사항

- 배열 크기를 `(N+1)×(M+1)`로 잡아 `r2+1`, `c2+1` 접근 시 범위 초과를 방지합니다.
- 누적 루프는 `N×M`까지만 돌려도 충분합니다. 여분의 행/열은 모서리 기록용입니다.
- 누적은 **모든 갱신을 기록한 뒤 한 번만** 수행합니다.
- 갱신 도중의 중간 상태를 조회해야 하는 문제에는 쓸 수 없습니다. (이 경우 세그먼트 트리, 2D BIT 등을 고려)
- 값이 누적되므로 오버플로 가능성을 확인합니다.

#### 8. 적용 신호

- 구간 갱신이 매우 많음 (K가 큼)
- 조회는 모든 갱신이 끝난 뒤 한 번
- 브루트포스로는 시간 초과가 나는 제약

# [공 이동 시뮬레이션](https://school.programmers.co.kr/learn/courses/30/lessons/87391)

## 문제 설명
n행 m열의 격자가 있습니다. 격자의 각 행은 0, 1, ..., n-1번의 번호, 그리고 각 열은 0, 1, ..., m-1번의 번호가 순서대로 매겨져 있습니다. 당신은 이 격자에 공을 하나 두고, 그 공에 다음과 같은 쿼리들을 날리고자 합니다.

- 열 번호가 감소하는 방향으로 dx칸 이동하는 쿼리 (query(0, dx))
- 열 번호가 증가하는 방향으로 dx칸 이동하는 쿼리 (query(1, dx))
- 행 번호가 감소하는 방향으로 dx칸 이동하는 쿼리 (query(2, dx))
- 행 번호가 증가하는 방향으로 dx칸 이동하는 쿼리 (query(3, dx))

단, 공은 격자 바깥으로 이동할 수 없으며, 목적지가 격자 바깥인 경우 공은 이동하다가 더 이상 이동할 수 없을 때 멈추게 됩니다. 예를 들어, 5행 × 4열 크기의 격자 내의 공이 3행 2열에 있을 때 query(3, 10) 쿼리를 받은 경우 공은 4행 2열에서 멈추게 됩니다. (격자의 크기가 5행 × 4열이므로, 0~4번 행과 0~3번 열로 격자가 구성되기 때문입니다.)

격자의 행의 개수 n, 열의 개수 m, 정수 x와 y, 그리고 쿼리들의 목록을 나타내는 2차원 정수 배열 queries가 매개변수로 주어집니다. n × m개의 가능한 시작점에 대해서 해당 시작점에 공을 두고 queries 내의 쿼리들을 순서대로 시뮬레이션했을 때, x행 y열에 도착하는 시작점의 개수를 return 하도록 solution 함수를 완성해주세요.

## 제한사항
- 1 ≤ n ≤ 109
- 1 ≤ m ≤ 109
- 0 ≤ x < n
- 0 ≤ y < m
- 1 ≤ queries의 행의 개수 ≤ 200,000
  - queries의 각 행은 \[command,dx] 두 정수로 이루어져 있습니다.
  - 0 ≤ command ≤ 3
  - 1 ≤ dx ≤ 109
  - 이는 query(command, dx)를 의미합니다.

## ver1. 전체 시작점 정방향 시뮬레이션(브루트포스)
```c++
const int dy[] = {0,0,-1,1};
const int dx[] = {-1,1,0,0};
long long solution(int n, int m, int x, int y, vector<vector<int>> queries) {
    const int S=queries.size();
    
    long long answer = 0;
    for(int i=0; i<n; i++)
        for(int j=0; j<m; j++)
        {
            int ny=i, nx=j;
            for(int k=0; k<S; k++)
            {
                ny=clamp(ny+dy[queries[k][0]]*queries[k][1], 0, n-1);
                nx=clamp(nx+dx[queries[k][0]]*queries[k][1], 0, m-1);
            }
            
            if(ny==x&&nx==y) answer++;
        }
    return answer;
}
```
### 시간복잡도
- O(n*m * Q)

### 동작 원리
- 격자의 모든 시작점 (i,j)에 대해 쿼리를 순서대로 적용
- 매 쿼리마다 이동 후 clamp로 벽에 막히는 경우 처리
- 최종 위치가 목표 (x,y)와 같으면 카운트 

### 문제점
- n,m이 최대 10^9이라 이중 반복문 자체가 불가능해서 시간 초과

## ver+. 도착점 기준 역방향 범위 추적  
```c++
long long solution(int n, int m, int y, int x, vector<vector<int>> queries) {
    long long lY=y,hY=y, lX=x,hX=x;
    for(int i=queries.size()-1;i>=0;i--)
    {
        const vector<int> &v=queries[i];
        if(v[0]==0)
        {
            if(lX>0) lX+=v[1], hX+=v[1];
            else hX+=v[1];
        }
        else if(v[0]==1)
        {
            if(hX<m-1) lX-=v[1], hX-=v[1];
            else lX-=v[1];
        }
        else if(v[0]==2)
        {
            if(lY>0) lY+=v[1], hY+=v[1];
            else hY+=v[1];
        }
        else if(v[0]==3)
        {
            if(hY<n-1) lY-=v[1], hY-=v[1];
            else lY-=v[1];
        }
        
        if((lX<0&&hX<0)||(lX>=m&&hX>=m)||(lY<0&&hY<0)||(lY>=n&&hY>=n)) return 0;
        lX=clamp(lX,0ll,(long long)m-1), hX=clamp(hX,0ll,(long long)m-1);
        lY=clamp(lY,0ll,(long long)n-1), hY=clamp(hY,0ll,(long long)n-1);
    }
    
    long long answer = (hY-lY+1)*(hX-lX+1);
    return answer;
}
```
### 시간복잡도
- O(Q)

### 동작 원리
- 도착점 한 점에서 시작해 쿼리를 뒤에서부터 거꾸로 처리하며 **여기에 도착할 수 있는 시작점들의 연속 구간 \[lo,hi]** 를 유지
- 행(Y)과 열(X)를 독립적으로 관리
- 벽에 붙어 있지 않으면 구간 전체 평행 이동, 벽에 붙어 있으면 벽 쪽 끝은 고정한 채 반대쪽 끝 d만큼 이동해 구간이 넓어짐 (벽에 막혀 멈춘 시작점들을 포함하기 위함)
- 이동 후 구간이 격자 밖으로 완전히 나가면 0을 반환하고, 일부만 나가면 clamp
- 마지막에 (행 구간 길이) x (열 구간 길이)가 답

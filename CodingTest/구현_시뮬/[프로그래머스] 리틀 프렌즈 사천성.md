# [리틀 프렌즈 사천성](https://school.programmers.co.kr/learn/courses/30/lessons/1836)

## 문제 설명
```text
언제나 맛있는 음식들이 가득한 평화로운 푸드 타운.
푸드 타운에서 행복하게 사는 리틀 프렌즈들은
마을에 있는 매직 스푼을 보물처럼 보관하고 있다.

매직 스푼은 재료만 준비해서 냄비에 넣고 휘젓기만 하면
순식간에 최고의 요리로 만들어주는 신비의 아이템.
어느 날 매직 스푼을 호시탐탐 노리는 악당들이 보물을 훔쳐간다.

매직 스푼을 되찾고 다시 마을에 평화를 가져오기 위해
프렌즈의 대모험이 시작되는데...
```
리틀 프렌즈 사천성은 프렌즈 사천성과 유사한 게임이다. 게임은 2차원 배열에서 진행되는데, 여러 가지 무늬로 구성된 타일이 배치되어 있으며 같은 모양의 타일은 두 개씩 배치되어 있다. 
게임의 목적은 배치된 모든 타일을 제거하는 것으로, 같은 모양의 타일을 규칙에 따라 제거하면 된다. 타일을 제거할 수 있는 경우는 다음과 같다.

다음 조건을 만족하는 경로가 있을 때 두 타일을 제거할 수 있다.

- 경로의 양 끝은 제거하려는 두 타일이다.
- 경로는 두 개 이하의 수평/수직 선분으로 구성되어 있고, 이들은 모두 연결되어 있다. (즉, 경로를 한 번 이하로 꺾을 수 있다)
  - 참고: 프렌즈 사천성은 경로가 세 개 이하의 선분으로 구성되어야 한다는 점이 다르다. (즉, 경로를 두 번 이하로 꺾을 수 있다)
- 경로 상에는 다른 타일 또는 장애물이 없어야 한다.

<img src="https://t1.kakaocdn.net/codefestival/scpuzzle.png">

위의 배열에서 어피치 타일은 직선의 경로로 이을 수 있으므로 제거 가능하다. 라이언 타일 역시 한 번 꺾인 경로로 연결되므로 제거 가능하다. 
무지 타일의 경우 다른 타일을 지나지 않는 경로는 두 번 꺾여야 하므로 제거할 수 없는 타일이며, 튜브 타일 역시 직선의 경로 사이에 장애물이 있으므로 제거 가능하지 않다.

타일 배열이 주어졌을 때, 규칙에 따라 타일을 모두 제거할 수 있는지, 그 경우 어떤 순서로 타일을 제거하면 되는지 구하는 프로그램을 작성해보자.

## 입력 형식
입력은 게임판의 크기를 나타내는 m과 n, 그리고 배치된 타일의 정보를 담은 문자열 배열 board로 주어진다. 이 배열의 크기는 m이며, 각각의 원소는 n글자의 문자열로 구성되어 있다. 입력되는 값의 제한조건은 다음과 같다.

- 1 <= m, n <= 100
- board의 원소는 아래 나열된 문자로 구성된 문자열이다. 각 문자의 의미는 다음과 같다.
  - .: 빈칸을 나타낸다.
  - *: 막힌 칸을 나타낸다.
  - 알파벳 대문자(A-Z): 타일을 나타낸다. 이 문제에서, 같은 글자로 이루어진 타일은 한 테스트 케이스에 항상 두 개씩만 존재한다.
  - board에는 알파벳 대문자가 항상 존재한다. 즉, 타일이 없는 입력은 주어지지 않는다.

## 출력 형식
해가 존재하는 경우 타일을 제거하는 순서대로 한 글자씩 이루어진 문자열을, 그렇지 않은 경우 **IMPOSSIBLE**을 리턴한다. 해가 여러 가지인 경우, 알파벳 순으로 가장 먼저인 문자열을 리턴한다.

## 예제 입출력
|m|n|board|answer|
|-|-|---------|-----|
|3|3|\["DBA", "C*A", "CDB"]|"ABCD"|
|2|4|\["NRYN", "ARYA"]|"RYAN"|
|4|4|\[".ZI.", "M.**", "MZU.", ".IU."]|"MUZI"|
|2|2|\["AB", "BA"]|"IMPOSSIBLE"|

### 예제에 대한 설명
첫 번째 테스트 케이스에서 처음으로 제거 가능한 타일은 A와 C이다. 그리고 모든 가능한 경우를 나열하면 ABCD, ACBD, ACDB, CABD, CADB, CDAB이다. 이 중 알파벳 순으로 가장 먼저인 ABCD가 정답이다.

네 번째 테스트 케이스는 초기 상태에서 제거할 수 있는 타일이 없으므로 타일을 모두 제거하는 것이 불가능하다. 따라서 정답은 IMPOSSIBLE이다.

## ver1. 경로 의존성 사전 계산 + 그리디 제거
```c++
bool func(const vector<string> &board, const pair<int,int> &d,
         unordered_set<char> &block, pair<int,int> &p)
{
    if(p==d) return true;
    
    char c=board[p.first][p.second];
    if(c=='*')
    {
        p=d;
        return false;
    }
    else if(isalpha(c)) block.insert(c);
    
    return true;
}

string solution(int m, int n, vector<string> board) {
    const int S=26;
    const string Err="IMPOSSIBLE";

    vector<vector<pair<int,int>>> pos(S);
    vector<bool> vis(S, true);
    int L=0;
    for(int i=0; i<m; i++)
        for(int j=0; j<n; j++)
            if(isalpha(board[i][j]))
            {
                pos[board[i][j]-'A'].push_back({i,j});
                vis[board[i][j]-'A']=false;
                L++;
            }
    L/=2;
        
    vector<vector<unordered_set<char>>> block(S, vector<unordered_set<char>>(2));
    int start=-1;
    for(int i=0; i<S; i++)
    {
        if(pos[i].empty()) continue;
        
        bool f1=true, f2=true;
        for(pair<int,int> right=pos[i][0],down=pos[i][0],dest=pos[i][1]; right!=dest||down!=dest; )
        {
            if(right!=dest)
            {
                if(right.second<dest.second) right.second++;
                else if(right.second>dest.second) right.second--;
                else right.first++;
                
                f1=func(board,dest,block[i][0],right);
            }
            if(down!=dest)
            {
                if(down.first!=dest.first) down.first++;
                else if(down.second<dest.second) down.second++;
                else if(down.second>dest.second) down.second--;
                
                f2=func(board,dest,block[i][1],down);
            }
        }
        
        if(!f1) block[i][0].insert(i+'A');
        if(!f2) block[i][1].insert(i+'A');
        if(!f1&&!f2) return Err;
        
        if(start<0 && (block[i][0].empty()||block[i][1].empty()))
           start=i;
    }
    
    string answer = "";
    for(int a=0; a<L; a++)
    {
        if(start<0) return Err;
        
        char c=(char)(start+'A');
        answer+=c;
        vis[start]=true;
        
        start=-1;
        for(int i=0; i<S; i++)
        {
            if(vis[i]) continue;
            for(int j=0; j<2; j++)
                block[i][j].erase(c);
            
            if(start<0 && (block[i][0].empty()||block[i][1].empty()))
                start=i;
        }
    }
    
    return answer;
}
```
### 시간복잡도
- 보드 스캔: m\*n 전체 한 번 훑으며 pos 채움 = O(m\*n)
- 경로 사전 계산: 글자 하나당 right/down경로 한 번 씩 끝까지 이동
  - 경로1 = O(m+n)
  - func(=해시셋 insert) = 평균 O(1)
- 제거: 한 번 제거마다 남은 글자 K개 돌며 block\[i]\[0], block\[i]\[1]에서 erase = O(1), empty() 검사 = O(K)
  - = O(K^2) (총 L(L=K)번 일어나므로)
- = O(K * (m+n) + K^2)
  - K = 글자 동류 수 (최대 26)

### 동작 원리
- 글자마다 두 L자 경로를 한 번씩 훑어서 경로 위에 놓인 글자를 blcok\[글자]\[경로] 집합에 저장
- 벽(*)을 만난 경로는 자기 글자를 넣어 영구 차단, 둘 다 막히면 바로 IMPOSSIBLE 반환
- 어느 한 경로의 집합이 비어 있으면 제거 가능
- 가장 앞선 글자를 답에 추가하고, 나머지 글자들의 집합에서 그 글자를 erase한 뒤 다음 후보 다시 찾음

### 문제점
- p=d로 루프를 강제 종료하는 트릭이라 의도가 코드에 드러나지 않음
- 상태(block, vis, start)가 많아 구현 실수 가능성 높음
- unordered_set 2차원 구조라 공간이 크고, 제약에 비해 과한 설계
- **로직은 맞지만 입력 크기에 비해 과한 상태관리와 암묵적 트릭이 많아 읽기 어렵고 실수하기 쉬운 과설계**

## ver+. 보드 직접 갱신 반복 시뮬레이션 + 그리디
```c++
// a, b가 같은 행 또는 같은 열일 때, 두 점 사이(양 끝 제외)가 모두 '.'인지 검사
bool clear(const vector<string>& board, pair<int,int> a, pair<int,int> b)
{
    int dr = (b.first > a.first) - (b.first < a.first);
    int dc = (b.second > a.second) - (b.second < a.second);
    int r = a.first + dr, c = a.second + dc;
    while (r != b.first || c != b.second)
    {
        if (board[r][c] != '.') return false;
        r += dr; c += dc;
    }
    return true;
}

// 꺾는 점 corner를 거쳐 a -> b로 갈 수 있는지
bool viaCorner(const vector<string>& board, pair<int,int> a, pair<int,int> b, pair<int,int> corner)
{
    if (corner != a && corner != b && board[corner.first][corner.second] != '.') return false;
    return clear(board, a, corner) && clear(board, corner, b);
}

bool canRemove(const vector<string>& board, pair<int,int> a, pair<int,int> b)
{
    return viaCorner(board, a, b, {a.first, b.second})
        || viaCorner(board, a, b, {b.first, a.second});
}

string solution(int m, int n, vector<string> board) {
    vector<vector<pair<int,int>>> pos(26);
    int L = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (isalpha(board[i][j]))
            {
                pos[board[i][j] - 'A'].push_back({i, j});
                L++;
            }
    L /= 2;

    string answer = "";
    while (L > 0)
    {
        bool found = false;
        for (int i = 0; i < 26; i++)
        {
            if (pos[i].empty()) continue;
            if (!canRemove(board, pos[i][0], pos[i][1])) continue;

            answer += (char)('A' + i);
            for (auto& p : pos[i]) board[p.first][p.second] = '.';
            pos[i].clear();
            L--;
            found = true;
            break;
        }
        if (!found) return "IMPOSSIBLE";
    }
    return answer;
}
```
### 시간복잡도
- 보드 스캔 = O(m*n)
- canRemove 한 번 비용 = viaCorner 2번 호출, clear 2번 호출 + clear는 두 점 사이 한번씩 가므로, O(m+n)
- 라운드 구조:
  - 바깥 while은 제거가 일어날 때마다 1회 돌아서 최대 K라운드
  - 한 라운드에서는 A부터 순서대로 canRemove호출하다가 처음 성공하는 글자에서 break = 최악 남은 글자 전부 검사 = O(K)
  - 한 라운드 비용 = O(K * (m+n))
- = O(m*n * K^2 * (m+n))

### 동작 원리
- A~Z 순서로 순회하며넛 각 글자가 지금 보드 상태에서 제거 가능한지 두 L자 경로를 직접 검사
- 처음 제거 가능한 글자 찾으면 보드에서 지우고, 답에 추가한 뒤 break해서 다시 A부터 시작
- 한 바퀴를 돌아도 지울 글자가 없으면 IMPOSSIBLE

### 문제점
- 같은 경로 라운드마다 다시 검사해서 중복 계산 많음
- K나 보드가 커지면 비효율적이지만, 이 문제에선 영향 없음
- 같은 행/열, 인접한 타일 같은 경계 케이스(꺾는 점이 타일 자신과 겹치는 경우)를 viaCorner에서 따로 처리

# [전력망을 둘로 나누기](https://school.programmers.co.kr/learn/courses/30/lessons/86971)

## 문제 설명
n개의 송전탑이 전선을 통해 하나의 트리 형태로 연결되어 있습니다. 당신은 이 전선들 중 하나를 끊어서 현재의 전력망 네트워크를 2개로 분할하려고 합니다. 이때, 두 전력망이 갖게 되는 송전탑의 개수를 최대한 비슷하게 맞추고자 합니다.  

송전탑의 개수 n, 그리고 전선 정보 wires가 매개변수로 주어집니다. 전선들 중 하나를 끊어서 송전탑 개수가 가능한 비슷하도록 두 전력망으로 나누었을 때, 두 전력망이 가지고 있는 송전탑 개수의 차이(절대값)를 return 하도록 solution 함수를 완성해주세요.  

## 제한사항
n은 2 이상 100 이하인 자연수입니다.  
wires는 길이가 n-1인 정수형 2차원 배열입니다.  
wires의 각 원소는 [v1, v2] 2개의 자연수로 이루어져 있으며, 이는 전력망의 v1번 송전탑과 v2번 송전탑이 전선으로 연결되어 있다는 것을 의미합니다.  
1 ≤ v1 < v2 ≤ n 입니다.  
전력망 네트워크가 하나의 트리 형태가 아닌 경우는 입력으로 주어지지 않습니다.

|---|---|---|

|4|\[\[1,2],\[2,3],\[3,4]]|0|
|7|\[\[1,2],\[2,7],\[3,7],\[3,4],\[4,5],\[6,7]]|1|

## ver1. BFS
```
int func(const int n, const unordered_map<int, vector<int>> &m, const vector<int> &cut)
{
    vector<bool> vis(n+1, false);
    vis[cut[0]]=true;
    vis[cut[1]]=true;
    
    int idx, cnt=0;
    queue<int> q;
    q.push(cut[0]);
    while(!q.empty())
    {
        idx=q.front();
        q.pop();
        cnt++;
        
        const vector<int> &v = m.at(idx);
        for(int i=0; i<v.size(); i++)
            if(!vis[v[i]])
            {
                q.push(v[i]);
                vis[v[i]]=true;
            }
    }
    
    return abs(cnt-(n-cnt));
}

int solution(int n, vector<vector<int>> wires) {
    unordered_map<int, vector<int>> m;
    for(int i=0; i<wires.size(); i++)
    {
        m[wires[i][0]].push_back(wires[i][1]);    
        m[wires[i][1]].push_back(wires[i][0]);    
    }
    
    int answer = n;
    for(int i=0; i<wires.size(); i++)
        answer = min(answer, func(n, m, wires[i]));
    
    return answer;
}
```
시간복잡도: 간선마다 func 호출(O(N-1)) * 전체 그래프 BFS (O(N + N-1) = O(N)) = O(N^2)  
m: 인접 리스트  
cut: 자를 전선. vis로 cut\[0], cut\[1]마킹 후 cut\[0]부터 BFS  
cnt: BFS로 도달한 노드 수. (n-cnt = 남은 노드 수)  
반복하여 최소값 찾기  

## ver+. DFS. 서브 트리 크기.
```
vector<int> adj[101];
int subtreeSize[101];

// 반복문(stack) 기반 post-order DFS로 서브트리 크기 계산
void dfs(int root, int n) {
    vector<int> parent(n + 1, -1);
    vector<int> order;      // 방문 순서 저장 (post-order 처리용)
    vector<bool> visited(n + 1, false);

    vector<int> st;
    st.push_back(root);
    visited[root] = true;

    while (!st.empty()) {
        int cur = st.back();
        st.pop_back();
        order.push_back(cur);
        for (int next : adj[cur]) {
            if (!visited[next]) {
                visited[next] = true;
                parent[next] = cur;
                st.push_back(next);
            }
        }
    }

    fill(subtreeSize, subtreeSize + n + 1, 1);
    // 역순(리프 -> 루트)으로 처리하면 자식 크기가 먼저 확정됨
    for (int i = order.size() - 1; i >= 0; i--) {
        int cur = order[i];
        if (parent[cur] != -1)
            subtreeSize[parent[cur]] += subtreeSize[cur];
    }
}

int solution(int n, vector<vector<int>> wires) {
    for (int i = 1; i <= n; i++) adj[i].clear();
    for (auto& w : wires) {
        adj[w[0]].push_back(w[1]);
        adj[w[1]].push_back(w[0]);
    }

    dfs(1, n); // 1번을 루트로 고정, DFS는 딱 한 번만

    int answer = n;
    for (int i = 2; i <= n; i++) { // 루트(1번) 제외 전 노드 = 전 간선과 1:1 대응
        int side1 = subtreeSize[i];
        int side2 = n - side1;
        answer = min(answer, abs(side1 - side2));
    }

    return answer;
}
```
시간복잡도: O(N) (순회 1회)  
트리를 임의의 루트로 한 번만 순회 = 모든 노드의 서브 트리 크기 동시 계산  
루트 제외 모든 노드 = 부모 간선이 유일하게 존재 (서브 트리 크기 = 간선 끊었을 때 한쪽 크기)
2~n 노드 순회하며 subtreeSize[]만 조회 (추가 탐색 0)  
**post-order**: 자식 계산 후 부모에 더함

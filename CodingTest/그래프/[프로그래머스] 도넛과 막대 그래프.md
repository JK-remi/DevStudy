도넛 모양 그래프, 막대 모양 그래프, 8자 모양 그래프가 여러 개 있습니다. 
이 그래프들과 무관한 정점을 하나 생성한 뒤, 각 도넛 모양 그래프, 막대 모양 그래프, 8자 모양 그래프의 임의의 정점 하나로 향하는 간선들을 연결했습니다.

그 후 각 정점에 서로 다른 번호를 매겼습니다.

이때 당신은 그래프의 간선 정보가 주어지면 생성한 정점의 번호와 정점을 생성하기 전 도넛 모양 그래프의 수, 막대 모양 그래프의 수, 8자 모양 그래프의 수를 구해야 합니다.

그래프의 간선 정보를 담은 2차원 정수 배열 edges가 매개변수로 주어집니다. 
이때, 생성한 정점의 번호, 도넛 모양 그래프의 수, 막대 모양 그래프의 수, 8자 모양 그래프의 수를 순서대로 1차원 정수 배열에 담아 return 하도록 solution 함수를 완성해 주세요.

## 제한사항
- 1 ≤ edges의 길이 ≤ 1,000,000
  - edges의 원소는 \[a,b] 형태이며, a번 정점에서 b번 정점으로 향하는 간선이 있다는 것을 나타냅니다.
  - 1 ≤ a, b ≤ 1,000,000
- 문제의 조건에 맞는 그래프가 주어집니다.
- 도넛 모양 그래프, 막대 모양 그래프, 8자 모양 그래프의 수의 합은 2이상입니다.

## ver1. BFS기반 unordered_map + 후보 별 서브그래프 탐색
```c++
vector<int> solution(vector<vector<int>> edges) {
    vector<int> answer(4,0); //정점, 도넛, 막대, 8
    unordered_map<int, vector<int>> in, out;
    vector<bool> tVis(1000001, true);   // M != 노드 수
    int M=0;
    for(int i=0; i<edges.size(); i++)
    {
        in[edges[i][0]].push_back(edges[i][1]);
        out[edges[i][1]].push_back(edges[i][0]);
        tVis[edges[i][0]]=false;
        tVis[edges[i][1]]=false;
        M=max(M,max(edges[i][0], edges[i][1]));
    }
    
    queue<int> q;   // 정점 후보
    for(auto it=in.begin(); it!=in.end(); ++it)
        if(out.find(it->first)==out.end() && it->second.size()>=2) 
            q.push(it->first);
    
    while(!q.empty())
    {
        int n=q.front(); q.pop();
        queue<int> gq;
        vector<bool> vis(tVis.begin(), tVis.begin()+M+1);
        vis[n]=true;
        int d=0, s=0, e=0;
        for(int i=0; i<in[n].size(); i++)
        {
            int node=0, edge=0;
            gq.push(in[n][i]);
            for(int tmp; !gq.empty(); gq.pop())
            {
                tmp=gq.front();
                vis[tmp]=true;
                node++;
                edge+=in[tmp].size();
                
                for(int j=0; j<in[tmp].size(); j++)
                    if(!vis[in[tmp][j]])
                        gq.push(in[tmp][j]);
            }
            
            if(node==edge) d++;
            else if(node-1==edge) 
            {
                gq.push(in[n][i]);
                for(int tmp; !gq.empty(); gq.pop())
                {
                    tmp=gq.front();
                    vis[tmp]=true;

                    for(int j=0; j<out[tmp].size(); j++)
                        if(!vis[out[tmp][j]])
                            gq.push(out[tmp][j]);
                }
                cout<<endl;
                s++;
            }
            else if(node+1==edge) e++;
        }
        
        bool f=true;
        for(int j=1; j<=M&&f; j++)
            f&=vis[j];
        if(f) 
        {
            answer={n,d,s,e};
            break;
        }
    }
    
    return answer;
}
```
### 시간복잡도
- 간선 정보 구성 = O(E) (E = 간선 수)
- 후보 탐색 = O(V) (V = 정점 수)
- 전체 그래프 BFS = O(V+E)
- vector<bool> vis 생성/복사 = O(V) 
- 가짜 후보(진입차수 0인 막대 머리) 여러 개인 경우 발생 = 서브그래프 탐색 + vis 복사(O(V)) = O(V^2) 

### 동작 방식
- 각 정점의 순방향(in), 역방향(out) 인접리스트를 해시맵으로 구성
- 진입차수 0인 정점을 후보 큐에 넣음
  - 진출차수 2이상이면 막대 머리 아님으로 제외
  - **정점에는 두개 이상의 그래프가 연결되어 있음**
- 후보를 하나씩 꺼내, 그 정점에서 뻗어나가는 각 자식마다 BFS로 서브그래프 전체 순회하며, node, edge를 세고, 그 비율로 도넛/막대/8자 판별
- 막대로 판별되면 역방향으로 한 번 더 순회해 보정
- 전체 정점을 다 방문했는지 확인해서 맞으면 그 후보가 진짜 생성 정점

### 문제점
- 가짜 후보 처리로 인항 성능 불안정성(시간초과 위험)
- unordered_map 사용으로 상수 비용 큼 (해시 충돌/메모리 오버헤드)
- 후보마다 vector<bool> vis 재생성/복사, 중첩 큐 사용 등 구현 복잡함

### ver2. ver1 수정
```
vector<int> solution(vector<vector<int>> edges) {
    unordered_map<int, vector<int>> in, out;
    int M=0;
    for(int i=0; i<edges.size(); i++)
    {
        in[edges[i][0]].push_back(edges[i][1]);
        out[edges[i][1]].push_back(edges[i][0]);
        M=max(M,max(edges[i][0], edges[i][1]));
    }
    
    vector<int> answer(4,0); //정점, 도넛, 막대, 8
    for(auto it=in.begin(); it!=in.end() && answer[0]==0; ++it)
        if(out.find(it->first)==out.end()&&it->second.size()>=2) 
            answer[0]=it->first;
    
    int n=answer[0];
    vector<bool> vis(M+1, false);
    vis[n]=true;
    queue<int> gq;
    for(int i=0; i<in[n].size(); i++)
    {
        int node=0, edge=0;
        gq.push(in[n][i]);
        for(int tmp; !gq.empty(); gq.pop())
        {
            tmp=gq.front();
            vis[tmp]=true;
            node++;
            edge+=in[tmp].size();

            for(int j=0; j<in[tmp].size(); j++)
                if(!vis[in[tmp][j]])
                    gq.push(in[tmp][j]);
        }

        if(node==edge) answer[1]++;
        else if(node-1==edge) answer[2]++;
        else if(node+1==edge) answer[3]++;
    }

    return answer;
}
```
### 수정 사항
- 정점 후보 노드는 해당 조건 하에 하나만 나오므로, 바로 정점 확정
- 막대 그래프 역산 제거: 정점에 연결된 그래프가 막대인지 확인만 하면 되므로, 역산까지는 필요 없음
-  vis 체크 제거: 정점 하나로 확정 + 해당 그래프 형태 확인만 하면 되므로, 삭제

## ver+. 진입/진출 차수 기반
```c++
vector<int> solution(vector<vector<int>> edges) {
    vector<int> sD(1000001, 0), eD(1000001, 0);
    int M=0;
    for(int i=0; i<edges.size(); i++)
    {
        sD[edges[i][0]]++;
        eD[edges[i][1]]++;
        M=max(M,max(edges[i][0],edges[i][1]));
    }
    
    vector<int> answer(4,0);
    for(int i=1; i<=M; i++)
    {
        if(sD[i]==0&&eD[i]==0) continue;
        
        if(eD[i]==0 && sD[i]>=2) answer[0]=i;
        else if(sD[i]==0) answer[2]++;
        else if(eD[i]>=2&&sD[i]>=2) answer[3]++;
    }
    answer[1]=sD[answer[0]]-(answer[2]+answer[3]);
        
    return answer;
}
```
### 시간복잡도
- 간선 순회(O(E)) + 정점 순회(O(V)) = O(V+E)
  - 항상 고정. 후보 수나 그래프 모양에 따라 흔들리지 않음
- 추가 자료구조 없이 배열 두 개만 사용해서 메모리도 O(V)로 가볍고, 상수 계수도 작음

### 동작 방식
- 간선을 한 번 순회하며 각 정점의 진입차수(eD), 진출차수(sD)만 집계
- 정점을 1~M까지 한 번 더 순회하며, 차수 조합만으로 즉시 분류
  - 생성 정점: eD==0 && sD>=2
  - 막대 끝: SD==0
  - 8자 교차점: eD>=2 && sD>=2
  - 나머지: 판별 X, 넘어감
- 생성 정점의 sD(연결된 그래프 총 개수)에서 막대, 8자 개수를 빼서 도넛 개수역산

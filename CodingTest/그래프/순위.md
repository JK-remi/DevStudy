# [순위](https://school.programmers.co.kr/learn/courses/30/lessons/49191)

## 문제 설명
n명의 권투선수가 권투 대회에 참여했고 각각 1번부터 n번까지 번호를 받았습니다. 권투 경기는 1대1 방식으로 진행이 되고, 만약 A 선수가 B 선수보다 실력이 좋다면 A 선수는 B 선수를 항상 이깁니다. 심판은 주어진 경기 결과를 가지고 선수들의 순위를 매기려 합니다. 하지만 몇몇 경기 결과를 분실하여 정확하게 순위를 매길 수 없습니다.

선수의 수 n, 경기 결과를 담은 2차원 배열 results가 매개변수로 주어질 때 정확하게 순위를 매길 수 있는 선수의 수를 return 하도록 solution 함수를 작성해주세요.

## 제한사항
- 선수의 수는 1명 이상 100명 이하입니다.
- 경기 결과는 1개 이상 4,500개 이하입니다.
- results 배열 각 행 [A, B]는 A 선수가 B 선수를 이겼다는 의미입니다.
- 모든 경기 결과에는 모순이 없습니다.

## 입출력 예
|n|results|return|
|--|----------|--|
|5|\[\[4, 3], \[4, 2], \[3, 2], \[1, 2], \[2, 5]]|2|

입출력 예 설명
2번 선수는 \[1, 3, 4] 선수에게 패배했고 5번 선수에게 승리했기 때문에 4위입니다.  
5번 선수는 4위인 2번 선수에게 패배했기 때문에 5위입니다.

## ver1. BFS
```
void func(const int n, vector<vector<int>> &v, const int tgt)
{
    vector<bool> vis(n+1, false);
    queue<pair<int,int>> q;
    q.push({0,tgt});
    vis[tgt]=true;
    
    for(int i, p; !q.empty(); q.pop())
    {
        p = q.front().first;
        i = q.front().second;
        for(int j=1; j<=n; j++)
        {
            if(vis[j] || v[i][j]==0) continue;
            
            if(i==tgt || v[i][j]==v[p][i])
            {
                if(i!=tgt) 
                    v[tgt][j]=v[i][j];
                    
                q.push({i,j});
                vis[j]=true;
            }
        }
    }
}

int solution(int n, vector<vector<int>> results) {
    vector<vector<int>> v(n+1, vector<int>(n+1, 0));
    for(int i=0; i<results.size(); i++)
    {
        v[results[i][0]][results[i][1]]++;
        v[results[i][1]][results[i][0]]--;
    }
    
    for(int i=1; i<=n; i++)
        func(n, v, i);
    
    int answer = 0;
    for(int i=1, cnt=0; i<=n; i++, cnt=0)
    {
        for(int j=1; j<=n; j++)
            cnt+=v[i][j]!=0;
        answer+=cnt==n-1;
    }
    
    return answer;
}
```
### 시간복잡도
- BFS: 각 노드 한 번씩 pop, 내부 for(1~n) 순회 = O(N^2)
- BFS N번 호출 = O(N^2) * O(N) = O(N^3)

### 동작 방식
- tgt(각 선수 번호)마다 별도의 BFS
- 경로 상 모든 간선 값 동일할 때만 확장
- vis로 중복 방문 차단

### 문제점
- 로직은 맞음
  - vis를 통한 노드 재방문 방지 = BFS보단 각 노드 도달 유효 경로 한번씩 확인
- 경로 전체 간선 값 일치(v\[i]\[j]==v\[p]\[i]) = 항상 참
  - v\[i]\[j]는 승패에 따라 +1/-1만 갖음
  - 도달 가능 = 간선 존재
  - 경로 따라옴 = 부호 일관됨
  - 실질적 의미가 없어짐. **방문 안 했고, 간선 존재 시 확장**과 동일
- 로직 불필요하게 복잡(predecessor 추적, 부호 비교 등) = Floyd-Warshall과 같은 일 하지만 훨씬 돌아감.

## ver+. Floys-Warshall (전이적 폐쇄)
```
int solution(int n, vector<vector<int>> results) {
    // reach[i][j] = true : i가 j를 이겼다 (직접 또는 간접적으로)
    vector<vector<bool>> reach(n+1, vector<bool>(n+1, false));

    for (auto& r : results)
        reach[r[0]][r[1]] = true;  // r[0]이 r[1]을 이김

    // Floyd-Warshall 식 전이적 폐쇄
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (reach[i][k] && reach[k][j])
                    reach[i][j] = true;

    int answer = 0;
    for (int i = 1; i <= n; i++) {
        int cnt = 0;
        for (int j = 1; j <= n; j++)
            if (j != i && (reach[i][j] || reach[j][i]))
                cnt++;
        if (cnt == n - 1) answer++;
    }

    return answer;
}
```
## 시간복잡도
- 3중 루프 = O(N^3) (단순 bool AND 연산 뿐)

## 동작 방식
- k를 경유 노드로 하여, i→k와 k→j가 모두 성립하면 i→k도 성립 = in-place 갱신
- n번 거치며, 임의 길이의 경로까지 전부 전파

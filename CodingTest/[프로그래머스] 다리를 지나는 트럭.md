# [다리를 지나는 트럭](https://school.programmers.co.kr/learn/courses/30/lessons/42583)

## 문제 설명
트럭 여러 대가 강을 가로지르는 일차선 다리를 정해진 순으로 건너려 합니다. 모든 트럭이 다리를 건너려면 최소 몇 초가 걸리는지 알아내야 합니다. 다리에는 트럭이 최대 bridge_length대 올라갈 수 있으며, 다리는 weight 이하까지의 무게를 견딜 수 있습니다. 단, 다리에 완전히 오르지 않은 트럭의 무게는 무시합니다.  
  
예를 들어, 트럭 2대가 올라갈 수 있고 무게를 10kg까지 견디는 다리가 있습니다. 무게가 [7, 4, 5, 6]kg인 트럭이 순서대로 최단 시간 안에 다리를 건너려면 다음과 같이 건너야 합니다.  

|경과 시간|다리를 지난 트럭|다리를 건너는 트럭|대기 트럭|
|---|---|---|---|
|0|[]|[]|\[7,4,5,6]|
|1~2|[]|\[7]|\[4,5,6]|
|3|\[7]|\[4]|\[5,6]|
|4|\[7]|\[4,5]|\[6]|
|5|\[7,4]|\[5]|\[6]|
|6~7|\[7,4,5]|\[6]|\[]|
|8|\[7,4,5,6]|\[]|\[]|  
따라서, 모든 트럭이 다리를 지나려면 최소 8초가 걸립니다.  

solution 함수의 매개변수로 다리에 올라갈 수 있는 트럭 수 bridge_length, 다리가 견딜 수 있는 무게 weight, 트럭 별 무게 truck_weights가 주어집니다. 이때 모든 트럭이 다리를 건너려면 최소 몇 초가 걸리는지 return 하도록 solution 함수를 완성하세요.  

## 제한 조건
bridge_length는 1 이상 10,000 이하입니다.  
weight는 1 이상 10,000 이하입니다.  
truck_weights의 길이는 1 이상 10,000 이하입니다.  
모든 트럭의 무게는 1 이상 weight 이하입니다.  

### 입출력 예
|bridge_length|weight|truck_weights|return|
|---|---|---|---|
|2|10|\[7,4,5,6]|8|
|100|100|\[10]|101|
|100|100|\[10,10,10,10,10,10,10,10,10,10]|110|

### ver1. 이벤트 기반 진입시각 카운터
```
int solution(int bl, int w, vector<int> tw) {
    int time = 0;
    queue<pair<int, int>> curB;
    for (int i = 0, bw = 0; i < tw.size() || !curB.empty(); i++)
    {
        if (i < tw.size() && bw + tw[i] <= w)
        {
            curB.push({ tw[i],time++ });
            bw += tw[i];
        }
        else if (!curB.empty()) i--;
        
        if ((i + 1 < tw.size() && bw + tw[i + 1] > w)
            || (i == tw.size()-1 && !curB.empty()))
        {
            time += bl - (time - curB.front().second);
            bw -= curB.front().first;
            curB.pop();
        }
    }

    return time+1;
}
```
다리 위 트럭 큐에 삽입.  
진입 시 time 1씩 증가시켜 진입 시각으로 기록.  
다음 트럭 못 들어오는 경우 맨 앞 트럭의 퇴장 시각으로 점프.  

- 문제점
진입 가능 여부: 무게O, 트럭 수 X
반례: bl=1, w=6, tw=\[4,1,3], return=4)  

### ver2. 매 tick 큐 정리 + 조건부 진입
```
#include <string>
#include <vector>
#include <queue>
using namespace std;

int solution(int bl, int w, vector<int> tw) {
    int time = 0;
    queue<pair<int, int>> cur;

    for (int i = 0, bw = 0; i < tw.size() || !cur.empty(); time++)
    {
        if (!cur.empty() && (time - cur.front().second) >= bl)
        {
            bw -= cur.front().first;
            cur.pop();
        }
        if (cur.empty() && i == tw.size()) break;

        if (cur.empty() || (i < tw.size() && tw[i] + bw <= w && cur.size() < bl))
        {
            bw += tw[i];
            cur.push({ tw[i++], time });
        }
    }

    return time+1;
}
```
time 매 tick 증가.  
조건 만족하는 트럭 큐에서 제거.  
무게 & 자리 만족할 때만 트럭 진입.  

### ver+. 큐 시뮬레이션
```
int solution(int bridge_length, int weight, vector<int> truck_weights) {
    queue<int> bridge;
    for (int i = 0; i < bridge_length; i++) bridge.push(0);  // 다리를 0(빈 칸)으로 채움

    int time = 0;
    int weightSum = 0;
    int idx = 0, n = truck_weights.size();

    while (!bridge.empty()) {
        time++;
        weightSum -= bridge.front();
        bridge.pop();                       // 맨 앞 칸(트럭) 퇴장

        if (idx == n) {
            if (weightSum == 0) break;       // 남은 트럭 없고 다리도 비었으면 종료
            bridge.push(0);
            continue;
        }

        if (weightSum + truck_weights[idx] <= weight) {  // 무게 되면 진입
            weightSum += truck_weights[idx];
            bridge.push(truck_weights[idx]);
            idx++;
        } else {
            bridge.push(0);                  // 못 들어가면 빈 칸으로 채움 (자릿수 유지)
        }
    }
    return time;
}
```
앞 코드의 진입/퇴장 로직 조건문 개선.  
다리 자체를 bridge_length(bl) 크기의 큐로 표현.

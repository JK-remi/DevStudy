# [선입 선출 스케줄링](https://school.programmers.co.kr/learn/courses/30/lessons/12920)

## 문제 설명
처리해야 할 동일한 작업이 n 개가 있고, 이를 처리하기 위한 CPU가 있습니다.

이 CPU는 다음과 같은 특징이 있습니다.

- CPU에는 여러 개의 코어가 있고, 코어별로 한 작업을 처리하는 시간이 다릅니다.
- 한 코어에서 작업이 끝나면 작업이 없는 코어가 바로 다음 작업을 수행합니다.
- 2개 이상의 코어가 남을 경우 앞의 코어부터 작업을 처리 합니다.

처리해야 될 작업의 개수 n과, 각 코어의 처리시간이 담긴 배열 cores 가 매개변수로 주어질 때, 마지막 작업을 처리하는 코어의 번호를 return 하는 solution 함수를 완성해주세요.

## 제한 사항
- 코어의 수는 10,000 이하 2이상 입니다.
- 코어당 작업을 처리하는 시간은 10,000이하 입니다.
- 처리해야 하는 일의 개수는 50,000개를 넘기지 않습니다.

## 입출력 예
|n|cores|result|
|---|---|---|
|6|\[1,2,3]|2|

### 입출력 예 설명
#### 입출력 예 #1
처음 3개의 작업은 각각 1,2,3번에 들어가고, 1시간 뒤 1번 코어에 4번째 작업,다시 1시간 뒤 1,2번 코어에 5,6번째 작업이 들어가므로 2를 반환해주면 됩니다.

## ver1. 이벤트 점프 시뮬레이션
```c++
const int MAX=10000*50000;
int solution(int n, vector<int> cores) {
    const int S=cores.size();
    vector<int> use(S, 0);

    for(int t=0, m; n>=0; t=m)
    {
        m=MAX;
        for(int i=0; i<S; i++)
        {
            if(use[i]<=t)
            {
                use[i]=t+cores[i];
                n--;
                
                if(n==0) return i+1;
            }
            
            m=min(use[i],m);
        }
    }
    
    int answer = 0;
    return answer;
}
```
### 시간복잡도
- 이벤트 시각마다 최소 1개의 작업이 시작되므로 외부 루프는 최대 n번, 매 번 코어 S개 순회
- = O(n * S) = 최악 5만 * 1만 = 5억

### 동작 원리
- use\[i]는 코어 i가 현재 작업을 끝내는 시각
- 시각 t마다 코어를 전부 훑어 use\[i]<=t인(놀고 있는) 코어에 작업을 하나 배정하고, n--
- n==0이 되는 순간의 코어 번호 반환
- 다음 시각은 1씩 증가시키지 않고, 모든 코어의 종료 시각 중 최솟값(m)으로 점프

### 문제점
- 로직은 맞지만, 복잡도 때문에 시간초과

## ver+. 시간 기준 매개변수 탐색(이분 탐색)
```c++
int solution(int n, vector<int> cores) {
    if(n<=cores.size()) return n;

    int l=0, r=(*max_element(cores.begin(), cores.end()))*n;
    for(long long cnt, mid; l<r; )
    {
        mid=(l+r)/2;
        cnt=0;
        
        for(int i=0; i<cores.size(); i++)
            cnt+=mid/cores[i]+1;
        
        if(cnt>=n) r=mid;
        else l=mid+1;
    }
    
    for(int i=0; i<cores.size(); i++)
        n-=(l-1)/cores[i]+1;
    
    int answer=0;
    for(int i=0; i<cores.size(); i++)
    {
        if(l%cores[i]==0) n--;
        if(n==0) 
        {
            answer=i+1;
            break;
        }
    }
    
    return answer;
}
```
### 시간복잡도
- 이분 탐색 (log(5억) = 29회) * 코어 S개 순회 + 후처리 O(S)
- = O(S log(maxCore * n)) = 30만 

### 동작 원리
- 시각 t까지 시작된 작업수는 Σ(t/cores\[i] + 1)이고, t에 대해 단조 증가
- 이 값이 n이상이 되는 최소 t를 이분 탐색(l<r, r=mid, l=mid+1)으로 찾음
- t가 마지막 작업이 시작되는 시각
- t-1시점까지 작업된 작업 수를 n에서 빼면 시각 t에 배정되어야 할 남은 작업 수 나옴
- 코어를 앞에서부터 보며 t%core\[i]==0(시각 t에 새 작업을 받는 코어)을 셈
  -  남은 수가 0이 되는 코어가 답

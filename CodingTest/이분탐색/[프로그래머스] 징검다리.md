# [징검다리](https://school.programmers.co.kr/learn/courses/30/lessons/43236)

## 문제 설명
출발지점부터 distance만큼 떨어진 곳에 도착지점이 있습니다. 그리고 그사이에는 바위들이 놓여있습니다. 바위 중 몇 개를 제거하려고 합니다.  
예를 들어, 도착지점이 25만큼 떨어져 있고, 바위가 \[2, 14, 11, 21, 17] 지점에 놓여있을 때 바위 2개를 제거하면 출발지점, 도착지점, 바위 간의 거리가 아래와 같습니다.

|제거한 바위의 위치|각 바위 사이의 거리|거리의 최솟값|
|-----|--------|--|
|\[21, 17]|\[2, 9, 3, 11]|2|
|\[2, 21]|[11, 3, 3, 8\]|3|
|\[2, 11]|\[14, 3, 4, 4]|3|
|\[11, 21]|\[2, 12, 3, 8]|2|
|\[2, 14]\\[11, 6, 4, 4]|4|

위에서 구한 거리의 최솟값 중에 가장 큰 값은 4입니다.

출발지점부터 도착지점까지의 거리 distance, 바위들이 있는 위치를 담은 배열 rocks, 제거할 바위의 수 n이 매개변수로 주어질 때, 바위를 n개 제거한 뒤 각 지점 사이의 거리의 최솟값 중에 가장 큰 값을 return 하도록 solution 함수를 작성해주세요.

## 제한사항
- 도착지점까지의 거리 distance는 1 이상 1,000,000,000 이하입니다.
- 바위는 1개 이상 50,000개 이하가 있습니다.
- n 은 1 이상 바위의 개수 이하입니다.

## 입출력 예
|distance|rocks|n|return|
|----|----------|--|---|
|25|\[2, 14, 11, 21, 17]|2|4|

## ver1. DFS
```
void dfs(const int d, const vector<int> &rocks, const int n, int idx, multiset<int> &s, int &ans)
{
    if(idx>rocks.size()) return;
    if(s.size() == n)
    {
        int tmp = min(*s.begin(), d-*s.rbegin());
        int pre = *s.begin();
        for(auto it=++s.begin(); it!=s.end(); pre=*it++)
        {
            tmp = min (tmp, *it-pre);
        }
        
        ans = max(ans, tmp);
        return;
    }
    
    s.insert(rocks[idx]);
    dfs(d, rocks, n, idx+1, s, ans);
    s.erase(rocks[idx]);
    
    dfs(d, rocks, n, idx+1, s, ans);
}

int solution(int distance, vector<int> rocks, int n) {
    int answer = 0;
    multiset<int> s;
    dfs(distance, rocks, rocks.size()-n, 0, s, answer);
    return answer;
}
```
### 시간복잡도
- 각 바위마다 포함/미포함 = O(2^S) (S=바위 개수)
- s.size()==n일 때마다 최소 간격 계산 = O(S)
- = O(2^S * S)

### 동작 방식
- 전체 바위 집합에서 모든 조합 시도 (부분집합 완전탐색)
- 남길 개수가 rocks.size()-n개가 되면, 그 조합에서의 최소 간격 계산해서 ans 갱신
- s.insert 후 재귀, s.erase후 다시 재귀 (남김 / 제거)

### 문제점
- 지수 시간 복잡도: 조합 탐색이라 바위 개수 커지면 끝나지 않음
- 가지치기(pruning) 없음: 현재까지의 최소 간격이 ans보다 작아진 시점에도 탐색 이어감

## ver+. 이분탐색+ Greedy
```
int solution(int distance, vector<int> rocks, int n) {
    const int s=rocks.size();
    sort(rocks.begin(), rocks.end());
    
    int l=0, r=distance, mid;
    int answer = 0;
    while(l<=r)
    {
        mid = (l+r)/2;
        int cnt=0, pre=0;
        for(int i=0; i<s; i++)
        {
            if(rocks[i]-pre<mid) cnt++;
            else pre=rocks[i];
        }
        if(distance-pre<mid) cnt++;
        
        if(cnt<=n)
        {
            answer=max(answer, mid);
            l=mid+1;
        }
        else r=mid-1;
    }
    
    return answer;
}
```
### 시간복잡도
- 이분탐색 = O(log D) (D=distance, 최대 10억 기준으로 약 30번)
- 매 판별 그리디 스캔 = O(S) (S = 바위 개수, 최대 5만)
- = O(S logD) = 50000 * 3 = 15만회 수준

### 동작 방식
- **최소 간격이 mid 이상이 되도록 만들 수 있는가**를 이분 탐색으로 탐색
- 그리디로 판별: 왼쪽부터 훑으면서, 직전에 살린 바위(pre)와의 거리가 mid보다 작으면 제거(cnt++), 아니면 살리고 pre갱신
- 최소 제거 개수 cnt가 n이하면 mid는 달성 가능한 답 후보 (더 큰 mid 탐색)
- 최소 제거 개수 cnt가 n보다 크면 범위를 줄여서 재탐색 (작은 mid 탐색)

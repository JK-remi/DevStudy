# [여행경로](https://school.programmers.co.kr/learn/courses/30/lessons/43164#)

## 문제 설명
주어진 항공권을 모두 이용하여 여행경로를 짜려고 합니다. 항상 "ICN" 공항에서 출발합니다.  
  
항공권 정보가 담긴 2차원 배열 tickets가 매개변수로 주어질 때, 방문하는 공항 경로를 배열에 담아 return 하도록 solution 함수를 작성해주세요.  

## 제한사항
모든 공항은 알파벳 대문자 3글자로 이루어집니다.  
주어진 공항 수는 3개 이상 10,000개 이하입니다.  
tickets의 각 행 [a, b]는 a 공항에서 b 공항으로 가는 항공권이 있다는 의미입니다.  
주어진 항공권은 모두 사용해야 합니다.  
만일 가능한 경로가 2개 이상일 경우 알파벳 순서가 앞서는 경로를 return 합니다.  
모든 도시를 방문할 수 없는 경우는 주어지지 않습니다.  

## 입출력 예
|tickets|return|
|---|---|
|\[\["ICN", "JFK"], \["HND", "IAD"], \["JFK", "HND"]]|\["ICN", "JFK", "HND", "IAD"]|
|\[\["ICN", "SFO"], \["ICN", "ATL"], \["SFO", "ATL"], \["ATL", "ICN"], \["ATL","SFO"]]|\["ICN", "ATL", "ICN", "SFO", "ATL", "SFO"]|

### 입출력 예 설명
####예제 #1  
  
\["ICN", "JFK", "HND", "IAD"] 순으로 방문할 수 있습니다.  
  
####예제 #2

\["ICN", "SFO", "ATL", "ICN", "ATL", "SFO"] 순으로 방문할 수도 있지만 \["ICN", "ATL", "ICN", "SFO", "ATL", "SFO"] 가 알파벳 순으로 앞섭니다.

## ver1. 재귀 DFS + 백트래킹
```
void dfs(unordered_map<string, map<string, int>> &m, const int size, 
         string cur, string tmp, string &ans)
{
    tmp+=cur;
    if(tmp.length() == (size+1)*3)
    {
        ans=tmp;
        return;
    }
    
    for(auto it=m[cur].begin(); it!=m[cur].end() && ans.empty(); ++it)
    {
        if(it->second==0) continue;
        it->second--;
        dfs(m, size, it->first, tmp, ans);
        it->second++;
    }
}

vector<string> solution(vector<vector<string>> tickets) {
    const int size = tickets.size();
    const string start = "ICN";
    
    unordered_map<string, map<string, int>> m;
    for(int i=0; i<size; i++)
        m[tickets[i][0]][tickets[i][1]]++;
    
    string r="";
    dfs(m, size, start, "", r);
    
    vector<string> answer;
    for(int i=0; i<=size && !r.empty(); i++)
        answer.push_back(r.substr(i*3, 3));
    
    return answer;
}
```
시간복잡도: 최악의 경우(O(E!) = 분기마다 재귀 재시도) (E = 티켓(간선) 수)  
현재 공항에서 갈 수 있는 목적지를 map 순서로 하나씩 시도  
티켓을 쓰고(it->second--) 재귀 호출 -> 그 경로 끝까지 실패하면 티켓 복구(it->second++)하고, 다음 후보 시도  
ans가 채워지면 상위 호출들의 for문도 즉시 멈춤 = 탐색 X  
**가능한 경로인지 모른 채 일단 가보고, 막히면 취소하고 재시도** = 잘못된 선택 시 되돌아가는 비용 발생

## ver+. Hierholzer(오일러) 알고리즘 (반복문 기반)
```
vector<string> solution(vector<vector<string>> tickets) {
    map<string, multiset<string>> graph;
    for (auto& t : tickets)
        graph[t[0]].insert(t[1]);

    vector<string> route;
    vector<string> stack = {"ICN"};

    while (!stack.empty()) {
        string cur = stack.back();
        auto& dests = graph[cur];
        if (dests.empty()) {
            route.push_back(cur);   // 막다른 길 -> 결과에 기록
            stack.pop_back();
        } else {
            string next = *dests.begin();  // 사전순 최소 목적지
            dests.erase(dests.begin());
            stack.push_back(next);
        }
    }

    reverse(route.begin(), route.end());
    return route;
}
```
시간복잡도: O(E logE) (정렬된 컨테이너에서 삽입/삭제) (E = 티켓(간선), V = 공항(정점))   
stack으로 재귀 대체 (현재 공항에서 갈 곳이 있으면 티켓 소비(multiset.erase)하고 스택에 push  
갈 곳이 없어지면(막다른 길) 그 공항을 route에 기록하고 스택에서 pop  
모든 티켓을 다 쓰면 route엔 **마지막 지점->...->시작점** 순서이므로 reverse  
**오일러 경로 반드시 존재(그래프 이론적 보장)** = 소비한 간선 다시 되돌릴 필요 X = 백트래킹 X

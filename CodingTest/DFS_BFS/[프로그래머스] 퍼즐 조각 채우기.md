# [퍼즐 조각 채우기](https://school.programmers.co.kr/learn/courses/30/lessons/84021)

## 문제 설명
테이블 위에 놓인 퍼즐 조각을 게임 보드의 빈 공간에 적절히 올려놓으려 합니다. 게임 보드와 테이블은 모두 각 칸이 1x1 크기인 정사각 격자 모양입니다. 이때, 다음 규칙에 따라 테이블 위에 놓인 퍼즐 조각을 게임 보드의 빈칸에 채우면 됩니다.  

- 조각은 한 번에 하나씩 채워 넣습니다.
- 조각을 회전시킬 수 있습니다.
- 조각을 뒤집을 수는 없습니다.
- 게임 보드에 새로 채워 넣은 퍼즐 조각과 인접한 칸이 비어있으면 안 됩니다.

다음은 퍼즐 조각을 채우는 예시입니다.

이때, 아래 그림과 같이 3,4,5번 조각을 격자 칸에 놓으면 규칙에 어긋나므로 불가능한 경우입니다.

현재 게임 보드의 상태 game_board, 테이블 위에 놓인 퍼즐 조각의 상태 table이 매개변수로 주어집니다. 규칙에 맞게 최대한 많은 퍼즐 조각을 채워 넣을 경우, 총 몇 칸을 채울 수 있는지 return 하도록 solution 함수를 완성해주세요.

## 제한사항
- 3 ≤ game_board의 행 길이 ≤ 50
- game_board의 각 열 길이 = game_board의 행 길이
  - 즉, 게임 보드는 정사각 격자 모양입니다.
  - game_board의 모든 원소는 0 또는 1입니다.
  - 0은 빈칸, 1은 이미 채워진 칸을 나타냅니다.
  - 퍼즐 조각이 놓일 빈칸은 1 x 1 크기 정사각형이 최소 1개에서 최대 6개까지 연결된 형태로만 주어집니다.
- table의 행 길이 = game_board의 행 길이
- table의 각 열 길이 = table의 행 길이
  - 즉, 테이블은 game_board와 같은 크기의 정사각 격자 모양입니다.
  - table의 모든 원소는 0 또는 1입니다.
  - 0은 빈칸, 1은 조각이 놓인 칸을 나타냅니다.
  - 퍼즐 조각은 1 x 1 크기 정사각형이 최소 1개에서 최대 6개까지 연결된 형태로만 주어집니다.
- game_board에는 반드시 하나 이상의 빈칸이 있습니다.
- table에는 반드시 하나 이상의 블록이 놓여 있습니다.

## ver1. 좌표 정규화 + 회전 퍼즐 생성 + 좌표 리스트 비교
```
const int dx[] = { -1, 0, 1, 0 };
const int dy[] = { 0, -1, 0, 1 };
const int MAX = 51;

pair<int,int> min_coord(const vector<pair<int, int>>& v)
{
    pair<int, int> p({ MAX,MAX });
    for (int i = 0; i < v.size(); i++)
        p.first = std::min(p.first, v[i].first), p.second = std::min(p.second, v[i].second);
    return p;
}

void w_to_l(vector<pair<int, int>>& s)
{
    sort(s.begin(), s.end());

    auto [minY, minX] = min_coord(s);
    for (auto it = s.begin(); it != s.end(); ++it)
        it->first -= minY, it->second -= minX;
}

vector<pair<int, int>> find_piece(const vector<vector<int>>& table, const int n,
    vector<vector<bool>>& vis, int y, int x, int c)
{
    queue<pair<int, int>> q;
    q.push({ y,x });
    vis[y][x] = true;

    vector<pair<int, int>> r;
    while (!q.empty())
    {
        y = q.front().first;
        x = q.front().second;
        r.push_back({ y,x });
        q.pop();

        for (int i = 0, nx, ny; i < 4; i++)
        {
            ny = y + dy[i], nx = x + dx[i];
            if (nx < 0 || ny < 0 || nx >= n || ny >= n) continue;
            if (vis[ny][nx]) continue;
            vis[ny][nx] = true;
            if (table[ny][nx] == c) continue;

            q.push({ ny,nx });
        }
    }

    w_to_l(r);
    return r;
}

vector<vector<pair<int, int>>> bfs(const vector<vector<int>>& table, const int n, int c)
{
    vector<vector<bool>> vis(n, vector<bool>(n, false));
    vector<vector<pair<int, int>>> pieces;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
        {
            if (vis[i][j] || table[i][j] == c) continue;
            pieces.push_back(find_piece(table, n, vis, i, j, c));
        }

    return pieces;
}

vector<pair<int, int>> rot(const vector<pair<int, int>>& v)
{
    const int n = v.size();
    vector<pair<int, int>> tmp(v);
    // rot 90
    for (int i = 0; i < n; i++)
    {
        tmp[i].first = v[i].second;
        tmp[i].second = -v[i].first;
    }

    w_to_l(tmp);
    return tmp;
}

int isFit(const vector<vector<pair<int, int>>>& e, const vector<vector<pair<int, int>>>& p)
{
    int cnt = 0;
    vector<bool> vis(p.size(), false);
    vector<vector<vector<pair<int, int>>>> rotP(p.size());

    // rotation
    for (int i = 0; i < rotP.size(); i++)
    {
        rotP[i].push_back(p[i]);
        for (int j = 0; j < 3; j++)
            rotP[i].push_back(rot(rotP[i][j]));
    }


    for (int i = 0; i < e.size(); i++)
        for (int j = 0; j < p.size(); j++)
        {
            if (vis[j] || e[i].size() != p[j].size()) continue;

            bool f = true;
            for (int k = 0; k < 4; k++)
            {
                f = true;
                for (int n = 0; n < rotP[j][k].size() && f; n++)
                    f &= e[i][n] == rotP[j][k][n];
                
                if (f) break;
            }
                

            if (f)
            {
                cnt+=e[i].size();
                vis[j] = true;
                break;
            }
        }

    return cnt;
}

int solution(vector<vector<int>> game_board, vector<vector<int>> table) {
    const int n = table.size();

    // find pieces
    vector<vector<pair<int, int>>> pieces = bfs(table, n, 0);
    vector<vector<pair<int, int>>> emptys = bfs(game_board, n, 1);

    // on board
    int answer = isFit(emptys, pieces);

    return answer;
}
```
시간복잡도: 
- BFS: O(N^2)
- 4회전
  - 순회: O(4 * P * S)
  - 정렬: O(S logS)
  - = O(P * S logS)
- 매칭
  - 구멍: H
  - 조각: P
  - 회전: 4
  - 좌표 비교: S
  - = O(H * P * 4 * S)
- = =O(H * P * S)

### 전체 흐름
1. bfs(): table(1), game_board(0)을 BFS로 묶어 조각(pieces), 구멍(emptys) 리스트 생성
2. find_piece(): 4방향 BFS로 연결된 영역 하나를 찾아 좌표 리스트로 반환
3. w_to_l(): 좌표를 정렬 후 최소 (y, x)만큼 평행 이동 (정규화(canonical form))
4. rot(): (y,x) → (x,-y) 변환으로 90도 회전 후 재정규화
5. isFit(): 각 구멍에 대해 아직 안 쓴조각 중 4방향 회전 중 하나라도 좌표가 정확히 일치하면 채택(Greedy)   

### 핵심 특징
조각의 회전 4종을 좌표 벡터 형태로 그대로 들고 있고, 매칭 시 좌표 리스트(조각(회전 포함), 구멍) 두 개를 원소 단위로 비교

## ver+. ver1 리팩토링
```
const int dx[] = { -1, 0, 1, 0 };
const int dy[] = { 0, -1, 0, 1 };
using Coord = vector<pair<int, int>>;

// 좌표 리스트를 정렬 + 최소좌표만큼 평행이동하여 정규화
void normalize(Coord& s)
{
    sort(s.begin(), s.end());
    int minY = s[0].first;
    int minX = min_element(s.begin(), s.end(),
        [](const pair<int,int>& a, const pair<int,int>& b) {
            return a.second < b.second;
        })->second;

    for (auto& p : s)
        p.first -= minY, p.second -= minX;
}

// BFS로 연결된 영역(조각/구멍) 하나 탐색
Coord findRegion(const vector<vector<int>>& g, int n,
                  vector<vector<bool>>& vis, int y, int x, int background)
{
    queue<pair<int, int>> q;
    q.push({ y, x });
    vis[y][x] = true;
    Coord region;

    while (!q.empty())
    {
        auto [cy, cx] = q.front();
        q.pop();
        region.push_back({ cy, cx });

        for (int i = 0; i < 4; i++)
        {
            int ny = cy + dy[i], nx = cx + dx[i];
            if (nx < 0 || ny < 0 || nx >= n || ny >= n || vis[ny][nx]) continue;
            vis[ny][nx] = true;
            if (g[ny][nx] == background) continue;
            q.push({ ny, nx });
        }
    }
    normalize(region);
    return region;
}

// 격자 전체를 순회하며 배경이 아닌 모든 영역을 추출
vector<Coord> extractRegions(const vector<vector<int>>& g, int n, int background)
{
    vector<vector<bool>> vis(n, vector<bool>(n, false));
    vector<Coord> regions;

    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (!vis[i][j] && g[i][j] != background)
                regions.push_back(findRegion(g, n, vis, i, j, background));

    return regions;
}

// 좌표 리스트를 90도 회전 후 재정규화
Coord rotate90(const Coord& v)
{
    Coord tmp(v.size());
    for (size_t i = 0; i < v.size(); i++)
        tmp[i] = { v[i].second, -v[i].first };
    normalize(tmp);
    return tmp;
}

// 정규화된 좌표 리스트 → 비교/저장이 쉬운 문자열 키로 변환
string toKey(const Coord& v)
{
    string key;
    key.reserve(v.size() * 6);
    for (auto& [y, x] : v)
        key += to_string(y) + "," + to_string(x) + "/";
    return key;
}

int countFit(const vector<Coord>& holes, const vector<Coord>& pieces)
{
    // 조각들을 key -> 개수 형태로 저장 (동일 모양이 여러 개일 수 있음)
    multiset<string> bag;
    for (auto& p : pieces)
        bag.insert(toKey(p));

    int total = 0;
    for (auto& hole : holes)
    {
        Coord cur = hole;
        for (int r = 0; r < 4; r++)
        {
            string key = toKey(cur);
            auto it = bag.find(key);
            if (it != bag.end())
            {
                total += hole.size();
                bag.erase(it);
                break;
            }
            cur = rotate90(cur);
        }
    }
    return total;
}

int solution(vector<vector<int>> game_board, vector<vector<int>> table)
{
    int n = table.size();
    auto pieces = extractRegions(table, n, 0);
    auto holes = extractRegions(game_board, n, 1);
    return countFit(holes, pieces);
}
```
시간복잡도
- BFS: O(N^2)
- 조각 키 생성 및 multiset 삽입
  - 조각마다 정렬: O(S logS)
  - 문자열 변환: O(S)
  - multiset 삽입: O(logP)
  - = O (P * (S logS + logP))
- 매칭
  - 구멍: H
  - 회전: 4
  - 회전 계산: O(S logS)
  - 키 생성: O(S)
  - multiset find/erase: O(logP * S) (문자열 비교 O(S))
- = O (H * 4 * (S logS + logP * S)) = O(H * S * log(S * P))

### 개선 코드
- normalize: w_to_l과 동일 역할이지만 이름을 의미 중심으로 변경. min_coord 제거하고 min_element로 인라인 처리.
- findRegion: find_piece와 동일한 BFS 탐색
- extractRegions: bfs와 동일, c 라는 모호한이름을 background로 변경
- rotate90: rot과 동일
- toKey: 정규화된 좌표리스트를 "y1,x1/y2,x2/..." 형태의 문자열로 직렬화
- countFit: 조각을 multiset(bag)에 키로 저장. 구멍마다 4번 회전시키며 키를 만들고, bag 에서 바로 찾아서(find) 지움(erase). (조각 4회전 X)

### 핵심 특징
- 좌표 벡터 비교를 문자열 비교
- 해시 기반 자료구조 탐색으로 바꿔서 같음 판정을 O(1)에 가깝게 판단
- 구멍 회전으로 저장공간 줄어듦

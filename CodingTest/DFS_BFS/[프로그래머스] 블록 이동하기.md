# [블록 이동하기](https://school.programmers.co.kr/learn/courses/30/lessons/60063)

## 문제 설명
로봇개발자 "무지"는 한 달 앞으로 다가온 "카카오배 로봇경진대회"에 출품할 로봇을 준비하고 있습니다. 준비 중인 로봇은 2 x 1 크기의 로봇으로 "무지"는 "0"과 "1"로 이루어진 N x N 크기의 지도에서 2 x 1 크기인 로봇을 움직여 (N, N) 위치까지 이동 할 수 있도록 프로그래밍을 하려고 합니다. 로봇이 이동하는 지도는 가장 왼쪽, 상단의 좌표를 (1, 1)로 하며 지도 내에 표시된 숫자 "0"은 빈칸을 "1"은 벽을 나타냅니다. 로봇은 벽이 있는 칸 또는 지도 밖으로는 이동할 수 없습니다. 로봇은 처음에 아래 그림과 같이 좌표 (1, 1) 위치에서 가로방향으로 놓여있는 상태로 시작하며, 앞뒤 구분없이 움직일 수 있습니다.

<img src="https://grepp-programmers.s3.amazonaws.com/files/production/33f5c19ba6/052d3514-5fca-4b85-82aa-0f9eaefae0a3.jpg">

로봇이 움직일 때는 현재 놓여있는 상태를 유지하면서 이동합니다. 예를 들어, 위 그림에서 오른쪽으로 한 칸 이동한다면 (1, 2), (1, 3) 두 칸을 차지하게 되며, 아래로 이동한다면 (2, 1), (2, 2) 두 칸을 차지하게 됩니다. 로봇이 차지하는 두 칸 중 어느 한 칸이라도 (N, N) 위치에 도착하면 됩니다.

로봇은 다음과 같이 조건에 따라 회전이 가능합니다.

<img src="https://grepp-programmers.s3.amazonaws.com/files/production/edfcdf57d3/f87055df-91e5-4f47-b99a-400c54bfdf3a.jpg">

위 그림과 같이 로봇은 90도씩 회전할 수 있습니다. 단, 로봇이 차지하는 두 칸 중, 어느 칸이든 축이 될 수 있지만, 회전하는 방향(축이 되는 칸으로부터 대각선 방향에 있는 칸)에는 벽이 없어야 합니다. 로봇이 한 칸 이동하거나 90도 회전하는 데는 걸리는 시간은 정확히 1초 입니다.

"0"과 "1"로 이루어진 지도인 board가 주어질 때, 로봇이 (N, N) 위치까지 이동하는데 필요한 최소 시간을 return 하도록 solution 함수를 완성해주세요.

## 제한사항
- board의 한 변의 길이는 5 이상 100 이하입니다.
- board의 원소는 0 또는 1입니다.
- 로봇이 처음에 놓여 있는 칸 (1, 1), (1, 2)는 항상 0으로 주어집니다.
- 로봇이 항상 목적지에 도착할 수 있는 경우만 입력으로 주어집니다.

## 입출력 예
|board|result|
|---|-|
|\[\[0, 0, 0, 1, 1],\[0, 0, 0, 1, 0],\[0, 1, 0, 1, 1],\[1, 1, 0, 0, 1],\[0, 0, 0, 0, 0]]|7|

### 입출력 예에 대한 설명
문제에 주어진 예시와 같습니다.
로봇이 오른쪽으로 한 칸 이동 후, (1, 3) 칸을 축으로 반시계 방향으로 90도 회전합니다. 다시, 아래쪽으로 3칸 이동하면 로봇은 (4, 3), (5, 3) 두 칸을 차지하게 됩니다. 이제 (5, 3)을 축으로 시계 방향으로 90도 회전 후, 오른쪽으로 한 칸 이동하면 (N, N)에 도착합니다. 따라서 목적지에 도달하기까지 최소 7초가 걸립니다.

## ver1. 칸 단위 BFS 
```c++
const int dy[]={-1,0,1,0};
const int dx[]={0,1,0,-1};

int solution(vector<vector<int>> board) {
    const int N = board.size(), dest=N-1; 
    vector<vector<int>> vis(N, vector<int>(N, INT_MAX));
    vis[0][0]=vis[0][1]=0;
    queue<vector<int>> q; // y1,x1,y2,x2,s
    q.push({0,0,0,1,0});
    for(int y1,x1,y2,x2,s,d; !q.empty(); q.pop())
    {
        y1=q.front()[0], x1=q.front()[1];
        y2=q.front()[2], x2=q.front()[3];
        s=q.front()[4]+1;
        d=y1-y2;
        
        for(int i=d==0?0:1, ny1,ny2,nx1,nx2, b1,b2; i<4; i+=2)
        {
            ny1=y1+dy[i], nx1=x1+dx[i];
            ny2=y2+dy[i], nx2=x2+dx[i];
            b1=(ny1<0||nx1<0||ny1>=N||nx1>=N||board[ny1][nx1]);
            b2=(ny2<0||nx2<0||ny2>=N||nx2>=N||board[ny2][nx2]);
            if(b1||b2) continue;

            if(vis[ny1][nx1]>=s)
            {
                vis[ny1][nx1]=min(vis[ny1][nx1],s);
                if(ny1==dest&&nx1==dest) return s;
                q.push({y1,x1,ny1,nx1,s});
            }
            if(vis[ny2][nx2]>=s)
            {
                vis[ny2][nx2]=min(vis[ny2][nx2],s);
                if(ny2==dest&&nx2==dest) return s;
                q.push({y2,x2,ny2,nx2,s});
            }
        }
        
        for(int i=0, ny1,ny2,nx1,nx2, b1,b2; i<4; i++)
        {
            ny1=y1+dy[i], nx1=x1+dx[i];
            ny2=y2+dy[i], nx2=x2+dx[i];
            b1=(ny1<0||nx1<0||ny1>=N||nx1>=N||board[ny1][nx1]);
            b2=(ny2<0||nx2<0||ny2>=N||nx2>=N||board[ny2][nx2]);
            if(b1||b2) continue;
            
            if(vis[ny1][nx1]<s&&vis[ny2][nx2]<s) continue;

            vis[ny1][nx1]=min(vis[ny1][nx1],s);
            vis[ny2][nx2]=min(vis[ny2][nx2],s);
            if(ny1==dest&&nx1==dest) return s;
            if(ny2==dest&&nx2==dest) return s;
            q.push({ny1,nx1,ny2,nx2,s});
        }
    }
        
    return -1;
}
```
### 시간복잡도
- O(N^2)
  - 칸마다 큐에 들어가는 횟수가 상수로 제한
  - 상태 당 전이 8개

### 동작 원리
- 큐에 (y1,x1,y2,x2,시간)을 넣고 BFS
- 로봇이 가로면 i=0,2(상하)로 회전 후보를 만들고, 세로면 i=1,3(좌우)로 만듦
  - 회전 후 상태는 **축 칸 + 이동한 칸" 쌍
- 평행 이동은 4방향으로 두 칸을 같이 옮김
- 방문 여부는칸 하나의 최단 시간(vis\[y]\[x])으로 판단 

### 문제점
- 방문 단위 틀림: 상태는 두 칸 쌍인데 칸 하나로 방문 체크
  - 같은 칸이라도 파트너 칸/방향이 다르면 다른 상태이므로 유효한 경로가 잘림
- 중복 push: >=s 조건 때문에 같은단계에서 같은 상태 여러 번들어감 (min 처리 불필요)
- 이동 판정 약함: 평행 이동은 두 칸 모두 방문된 경우에만 건너뜀. 칸 단위 판단이라 정확하지 않음

## ver2. 정규화된 상태를 map<vector<int>,int>에 저장 BFS
```c++
const int dy[]={-1,0,1,0};
const int dx[]={0,1,0,-1};
map<vector<int>, int> vis;

void swap(vector<int> &v)
{
    int &y1=v[0], &x1=v[1];
    int &y2=v[2], &x2=v[3];
    if(y1<y2) return;
    if(y1==y2 && x1<x2) return;
    int ty=y2, tx=x2;
    y2=y1, x2=x1;
    y1=ty, x1=tx;
}

bool func(const int dest, vector<int> &v, int s, int &ans)
{
    swap(v);
    auto it=vis.find(v);
    if(it==vis.end())
    {
        if((v[0]==dest&&v[1]==dest)||(v[2]==dest&&v[3]==dest))
            ans=s;
        
        vis[v]=s;
        return true;
    }
    
    return false;
}

bool check(const vector<vector<int>> &board, int y1, int x1, int y2, int x2)
{
    const int N=board.size();
    if((y1<0||x1<0||y1>=N||x1>=N||board[y1][x1])
       ||(y2<0||x2<0||y2>=N||x2>=N||board[y2][x2])) return false;
    
    return true;
}

int solution(vector<vector<int>> board) {
    const int N = board.size(), dest=N-1; 
    vis[{0,0,0,1}]=0;
    queue<vector<int>> q; // y1,x1,y2,x2
    q.push({0,0,0,1});
    
    int answer=0;
    for(int y1,x1,y2,x2,s,d; !q.empty(); q.pop())
    {
        vector<int> v=q.front();
        y1=v[0], x1=v[1];
        y2=v[2], x2=v[3];
        s=vis[v]+1;
        d=y1-y2;
        
        for(int i=d==0?0:1, ny1,ny2,nx1,nx2; i<4; i+=2)
        {
            ny1=y1+dy[i], nx1=x1+dx[i];
            ny2=y2+dy[i], nx2=x2+dx[i];
            if(!check(board, ny1, nx1, ny2, nx2)) continue;
            
            v[0]=y1,v[1]=x1,v[2]=ny1,v[3]=nx1;
            if(func(dest, v, s, answer))
            {
                if(answer>0) return answer;
                q.push(v);
            }
            
            v[0]=y2,v[1]=x2,v[2]=ny2,v[3]=nx2;
            if(func(dest, v, s, answer))
            {
                if(answer>0) return answer;
                q.push(v);
            }
        }
        
        for(int i=0, ny1,ny2,nx1,nx2; i<4; i++)
        {
            ny1=y1+dy[i], nx1=x1+dx[i];
            ny2=y2+dy[i], nx2=x2+dx[i];
            if(!check(board, ny1, nx1, ny2, nx2)) continue;
            
            v[0]=ny1,v[1]=nx1,v[2]=ny2,v[3]=nx2;
            if(func(dest, v, s, answer))
            {
                if(answer>0) return answer;
                q.push(v);
            }
        }
    }
        
    return answer;
}
```
### 시간복잡도
- 상태 수 = 2*N^2
- 상태 당 전이 = 8
- map 연산 = O(logS)
- = O(N^2 logN) (비교/벡터 생성비용 추가) 

### 동작 원리
- 상태 (y1,x1,y2,x2)를 정규화. 작은 칸이 앞으로 오도록 정렬해서 (a,b)와 (b,a)를 같은 상태 취급
- vis map이 방문 여부와 최단 시간 함께 저장
- 회전(루프1)과 이동(루프2) 분리
- 회전은 check로 이동 후 두 칸이 모두 유효할 때만 허용, 축 칸2 종류로 상태 만듦
- 새 상태를 처음 방문할 때문 vis에 기록하고 push. 한 칸이라도 도착하면 즉시 반환    

### 문제점
- map 할당 / 비교 비용 크므로, vis\[N]\[N]\[2] (앞 칸 좌표 + 방향) 으로 바꾸면 O(N^2) 가능

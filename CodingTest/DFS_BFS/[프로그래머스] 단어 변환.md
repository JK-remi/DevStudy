# [단어 변환](https://school.programmers.co.kr/learn/courses/30/lessons/43163)

## 문제 설명
두 개의 단어 begin, target과 단어의 집합 words가 있습니다. 아래와 같은 규칙을 이용하여 begin에서 target으로 변환하는 가장 짧은 변환 과정을 찾으려고 합니다.
```text
1. 한 번에 한 개의 알파벳만 바꿀 수 있습니다.
2. words에 있는 단어로만 변환할 수 있습니다.
```
예를 들어 begin이 "hit", target가 "cog", words가 \["hot","dot","dog","lot","log","cog"]라면 "hit" -> "hot" -> "dot" -> "dog" -> "cog"와 같이 4단계를 거쳐 변환할 수 있습니다.  

두 개의 단어 begin, target과 단어의 집합 words가 매개변수로 주어질 때, 최소 몇 단계의 과정을 거쳐 begin을 target으로 변환할 수 있는지 return 하도록 solution 함수를 작성해주세요.

## 제한사항
각 단어는 알파벳 소문자로만 이루어져 있습니다.  
각 단어의 길이는 3 이상 10 이하이며 모든 단어의 길이는 같습니다.  
words에는 3개 이상 50개 이하의 단어가 있으며 중복되는 단어는 없습니다.  
begin과 target은 같지 않습니다.  
변환할 수 없는 경우에는 0를 return 합니다.  

## 입출력 예
|begin|target|words|return|
|"hit"|"cog"|\["hot", "dot", "dog", "lot", "log", "cog"]|4|
|"hit"|"cog"|\["hot", "dot", "dog", "lot", "log"]|0|

## ver1. BFS (레벨 단위 집합)
```
int cmp(const string &s1, const string &s2)
{
    if(s1==s2) return -1;
    
    int cnt=0;
    for(int i=0; i<s1.length(); i++)
        cnt+=s1[i]!=s2[i];
    
    return cnt;    
}

int solution(string begin, string target, vector<string> words) {
    int answer = 0;
    if(words.end() == find(words.begin(), words.end(), target)) return answer;
    
    int l = begin.length();
    queue<unordered_set<string>> q;
    q.push(unordered_set<string>({begin}));
    
    for(string tmp; !q.empty(); q.pop())
    {
        unordered_set<string> s=q.front();
        unordered_set<string> next;
        answer++;
        
        for(auto it=s.begin(); it!=s.end(); ++it)
        {
            tmp = *it;
            int st=cmp(tmp, target);
            for(int i=0; i<words.size(); i++)
                if(cmp(tmp, words[i])==1 && cmp(target, words[i])<=st)
                {
                    if(words[i]==target) return answer;
                    next.insert(words[i]);
                }
        }
        
        if(next.empty()) return 0;
        q.push(next);
    }
    
    return answer;
}
```
BFS를 "레벨 단위 집합 (unordered_set<string>)"으로 처리  
target까지의 해밍 거리 줄어들거나 같은 경우로 제한 (그리디 가지치기)  

### 문제점
- 방문 처리 부재: 한 번 사용한 단어 제외 로직 없음
  - 그래프에 사이클 있고 target 도달 불가능한 경우 = 무한 루프
  - 불필요한 재방문 = 탐색량 늘어남
- 거리 기반 가지치기(단조 비증가) = 이론적 안전 but, 방문 처리 없으면 의미 없음

## ver2. BFS + visited
```
int cmp(const string &s1, const string &s2)
{
    if(s1==s2) return -1;
    
    int cnt=0;
    for(int i=0; i<s1.length() && cnt<2; i++)
        cnt+=s1[i]!=s2[i];
    
    return cnt;    
}

int solution(string begin, string target, vector<string> words) {
    int answer = 0;
    
    vector<bool> vis(words.size(), false);
    queue<pair<string, int>> q;
    q.push({begin, 0});
    string tmp;
    while(!q.empty())
    {
        tmp=q.front().first;
        answer = q.front().second;
        q.pop();
        
        if(tmp==target) break;
        
        for(int i=0; i<words.size(); i++)
            if(!vis[i] && cmp(tmp, words[i])==1)
            {
                vis[i]=true;
                q.push({words[i],answer+1});
            }
    }
    
    if(tmp!=target) answer=0;
    
    return answer;
}
```
시간복잡도: O(N^2 * L) (N=wrods 수, L=문자열 길이) (각 단어 최대 한번(N) * 매 방문 모든 단어 비교(N))
방문 처리(vis)로 무한루프 X  
BFS이므로 target 처음 꺼내는 순간의 answer가 항상 최단 거리 보장  
target이 words에 없는 경우: tmp에 target 할당 안 됨  
begin이 target인 경우: 첫 pop에서 break

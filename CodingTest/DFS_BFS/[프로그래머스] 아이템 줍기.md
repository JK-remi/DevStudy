## 문제 설명
다음과 같은 다각형 모양 지형에서 캐릭터가 아이템을 줍기 위해 이동하려 합니다.  

<img src="https://asset.programmers.co.kr/files/production/9b96b07f-72db-4b1c-bd7a-6a9c9b8d0dc6/rect_1.png">  

지형은 각 변이 x축, y축과 평행한 직사각형이 겹쳐진 형태로 표현하며, 캐릭터는 이 다각형의 둘레(굵은 선)를 따라서 이동합니다.  

만약 직사각형을 겹친 후 다음과 같이 중앙에 빈 공간이 생기는 경우, 다각형의 가장 바깥쪽 테두리가 캐릭터의 이동 경로가 됩니다.  

<img src="https://asset.programmers.co.kr/files/production/38b0739b-8dd8-40d8-ac44-c71678d28d07/rect_2.png">  

단, 서로 다른 두 직사각형의 x축 좌표 또는 y축 좌표가 같은 경우는 없습니다.  

<img src="https://asset.programmers.co.kr/files/production/ec976181-987e-494e-bb2d-0615ce16252f/rect_4.png">  

즉, 위 그림처럼 서로 다른 두 직사각형이 꼭짓점에서 만나거나, 변이 겹치는 경우 등은 없습니다.  

다음 그림과 같이 지형이 2개 이상으로 분리된 경우도 없습니다.  

<img src="https://asset.programmers.co.kr/files/production/7eda8d92-ebe0-4b5f-bd15-0c9dc7af3a3e/rect_3.png">  

한 직사각형이 다른 직사각형 안에 완전히 포함되는 경우 또한 없습니다.  

<img src="https://asset.programmers.co.kr/files/production/1e178b0d-6580-4981-aae3-dd82a1b95362/rect_7.png">  

지형을 나타내는 직사각형이 담긴 2차원 배열 rectangle, 초기 캐릭터의 위치 characterX, characterY, 아이템의 위치 itemX, itemY가 solution 함수의 매개변수로 주어질 때, 캐릭터가 아이템을 줍기 위해 이동해야 하는 가장 짧은 거리를 return 하도록 solution 함수를 완성해주세요.  

## 제한사항
- rectangle의 세로(행) 길이는 1 이상 4 이하입니다.  
- rectangle의 원소는 각 직사각형의 \[좌측 하단 x, 좌측 하단 y, 우측 상단 x, 우측 상단 y] 좌표 형태입니다.  
  - 직사각형을 나타내는 모든 좌표값은 1 이상 50 이하인 자연수입니다.
  - 서로 다른 두 직사각형의 x축 좌표, 혹은 y축 좌표가 같은 경우는 없습니다.
  - 문제에 주어진 조건에 맞는 직사각형만 입력으로 주어집니다.
- charcterX, charcterY는 1 이상 50 이하인 자연수입니다.
  - 지형을 나타내는 다각형 테두리 위의 한 점이 주어집니다.
- itemX, itemY는 1 이상 50 이하인 자연수입니다.
  - 지형을 나타내는 다각형 테두리 위의 한 점이 주어집니다.
- 캐릭터와 아이템의 처음 위치가 같은 경우는 없습니다.
  
- 전체 배점의 50%는 직사각형이 1개인 경우입니다.
- 전체 배점의 25%는 직사각형이 2개인 경우입니다.
- 전체 배점의 25%는 직사각형이 3개 또는 4개인 경우입니다.

## ver1. BFS
```
int dx[] = { -1, 0, 1, 0 };
int dy[] = { 0, -1, 0, 1 };

bool IsIn(const vector<int>& v, int px, int py, int x, int y)
{
    float fx = (float)(px + x) * 0.5f, fy = (float)(py + y) * 0.5f;
    bool f = !(fx > v[0] && fx<v[2] && fy>v[1] && fy < v[3]);
    return f;
}

bool IsIn(const vector<vector<int>>& v, int px, int py, int x, int y)
{
    bool f=true;
    for (int i = 0; i < v.size() && f; i++)
        f &= IsIn(v[i], px, py, x, y);

    return !f;
}

bool IsOn(const vector<vector<int>>& v, int px, int py, int x, int y)
{
    float fx = (float)(px + x) * 0.5f, fy = (float)(py + y) * 0.5f;
    bool f = false;
    for (int i = 0; i < v.size() && !f; i++)
        f |= ((fx == v[i][0] || fx == v[i][2]) && (fy>=v[i][1] && fy<=v[i][3]))
            || ((fy == v[i][1] || fy == v[i][3]) && (fx >= v[i][0] && fx <= v[i][2]));

    return f;
}

const int MAX = 50;
int solution(vector<vector<int>> rectangle, int characterX, int characterY, int itemX, int itemY) {
    pair<int, int> cur({ characterX, characterY }), goal({ itemX, itemY });
    vector<vector<int>> vis(MAX + 1, vector<int>(MAX + 1, -1));
    queue<pair<int, int>> q;
    q.push(cur);
    vis[cur.first][cur.second] = 0;
    for (int x, y; !q.empty(); q.pop())
    {
        cur = q.front();
        if (cur == goal) break;

        x = cur.first, y = cur.second;
        for (int i = 0, nx, ny; i < 4; i++)
        {
            nx = x + dx[i], ny = y + dy[i];
            if (nx<0 || ny<0 || nx>MAX || ny>MAX) continue;
            if (vis[nx][ny] >= 0) continue;
            if (IsIn(rectangle, x, y, nx, ny)) continue;
            if (!IsOn(rectangle, x, y, nx, ny)) continue;

            q.push({ nx,ny });
            vis[nx][ny] = vis[x][y] + 1;
            if(q.back()==goal) return vis[nx][ny];
        }
    }
    
    int answer = vis[itemX][itemY];
    return answer;
}
```
### 전체 흐름
1. characterX, characterY에서 시작해 4방향 BFS를 돌린다.
2. 인접 칸으로 이동을 시도할 때마다, 현재 칸과 인접 칸 사이의 간선(edge)의 중점을 계산해서 그 지점이
  - 사각형 내부를 관통하면(IsIn) → 이동 불가
  - 어떤 사각형의 변 위에 있지 않으면(!IsOn) → 이동 불가 (둘레만 이동 허용)
3. 두 조건을 통과한 칸만 큐에 넣고 vis(거리), p(부모)를 기록한다.
4. itemX, itemY까지의 vis 값이 최단 거리.

### 함수별 역할
|함수|역할|
|---|---|
|IsIn(단일 사각형)|간선 중점이 그 사각형의 열린 내부(경계 제외)에 있으면 false|
|IsIn(전체)|사각형 중 하나라도 내부를 관통하면 true (차단)|
|IsOn(전체)|간선 중점이 어떤 사각형의 변(테두리) 위에 정확히 있으면 true (허용)|

(px+x)*0.5f 방식은 좌표를 실제로 2배 확장한 배열을 쓰는 대신, 간선의 "중간 지점"을 그때그때 계산해서 좌표 2배 확장과 동일한 효과를 얻는 방식입니다. 두 정수 좌표의 평균이므로 항상 .0 또는 .5가 나와 float 등호 비교(==)도 이 문제 범위에서는 안전합니다.

### 시간 복잡도
- 사각형 개수 R (문제 제약상 최대 4개)
- 좌표 범위 MAX = 50 → 격자 크기 O(MAX²)
|단계|복잡도|
|---|---|
|BFS 방문 노드 수|O(MAX²) = 2,601|
|노드당 이웃 탐색|4방향|
|이웃당 IsIn + IsOn 호출|각각 O(R)|
|전체|O(MAX² × 4 × R) ≈ 2,601 × 4 × 4 ≈ 최대 약 41,616 연산|

공간 복잡도는 vis, p 배열 모두 O(MAX²). 두 지표 다 이 문제 제약(좌표 ≤50, 사각형 ≤4) 안에서는 사실상 상수 시간에 가까워 성능 걱정은 전혀 필요 없습니다.

## ver+. 정수 2배 스케일링
```
int solution(vector<vector<int>> rectangle, int characterX, int characterY, int itemX, int itemY) {
    // 1. 좌표를 모두 2배로 확장 (경계-내부 구분을 위해)
    for (auto& r : rectangle) for (auto& v : r) v *= 2;
    int sx = characterX * 2, sy = characterY * 2;
    int gx = itemX * 2, gy = itemY * 2;

    const int N = 102; // 좌표값 최대 50*2=100, 여유 포함
    vector<vector<int>> board(N, vector<int>(N, 0));

    // 2. 각 사각형을 '내부 포함'하여 칠한다
    for (auto& r : rectangle)
        for (int x = r[0]; x <= r[2]; x++)
            for (int y = r[1]; y <= r[3]; y++)
                board[x][y] = 1;

    // 3. 진짜 내부(경계 제외)만 다시 0으로 지운다 → 남는 1은 '둘레'뿐
    for (auto& r : rectangle)
        for (int x = r[0] + 1; x <= r[2] - 1; x++)
            for (int y = r[1] + 1; y <= r[3] - 1; y++)
                board[x][y] = 0;

    // 4. 둘레(board==1) 위에서만 BFS
    vector<vector<int>> dist(N, vector<int>(N, -1));
    queue<pair<int,int>> q;
    dist[sx][sy] = 0;
    q.push({sx, sy});

    int dx[] = {-1, 0, 1, 0};
    int dy[] = {0, -1, 0, 1};

    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        if (x == gx && y == gy) break;

        for (int i = 0; i < 4; i++) {
            int nx = x + dx[i], ny = y + dy[i];
            if (nx < 0 || ny < 0 || nx >= N || ny >= N) continue;
            if (board[nx][ny] != 1) continue;
            if (dist[nx][ny] >= 0) continue;

            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }

    return dist[gx][gy] / 2; // 2배 확장했으니 결과도 절반
}
```
- 선(간선) 판정을 매 이동마다 계산 → 격자 전체를 한 번에 전처리하는 방식으로 바꿨습니다. IsIn/IsOn을 매번 호출하지 않고, BFS 시작 전에 board 배열에 "둘레인지 아닌지"를 미리 다 칠해놓습니다.  
- 이 덕분에 BFS 루프 안에서는 배열 조회 O(1)만 하면 되고, R(사각형 개수)에 대한 반복이 전처리 단계로 옮겨져 로직이 더 명확해집니다.  
- float 연산이 완전히 사라져 부동소수점 관련 걱정이 없습니다.

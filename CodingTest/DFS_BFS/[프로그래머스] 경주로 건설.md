# [경주로 건설](https://school.programmers.co.kr/learn/courses/30/lessons/67259)

## 문제 설명
<img src="https://grepp-programmers.s3.ap-northeast-2.amazonaws.com/files/production/384b9e2a-4eb5-460d-bce2-d12359b03b14/kakao_road1.png">

건설회사의 설계사인 죠르디는 고객사로부터 자동차 경주로 건설에 필요한 견적을 의뢰받았습니다.  
제공된 경주로 설계 도면에 따르면 경주로 부지는 N x N 크기의 정사각형 격자 형태이며 각 격자는 1 x 1 크기입니다.  
설계 도면에는 각 격자의 칸은 0 또는 1 로 채워져 있으며, 0은 칸이 비어 있음을 1은 해당 칸이 벽으로 채워져 있음을 나타냅니다.  
경주로의 출발점은 (0, 0) 칸(좌측 상단)이며, 도착점은 (N-1, N-1) 칸(우측 하단)입니다. 죠르디는 출발점인 (0, 0) 칸에서 출발한 자동차가 도착점인 (N-1, N-1) 칸까지 무사히 도달할 수 있게 중간에 끊기지 않도록 경주로를 건설해야 합니다.  
경주로는 상, 하, 좌, 우로 인접한 두 빈 칸을 연결하여 건설할 수 있으며, 벽이 있는 칸에는 경주로를 건설할 수 없습니다.  
이때, 인접한 두 빈 칸을 상하 또는 좌우로 연결한 경주로를 직선 도로 라고 합니다.  
또한 두 직선 도로가 서로 직각으로 만나는 지점을 코너 라고 부릅니다.  
건설 비용을 계산해 보니 직선 도로 하나를 만들 때는 100원이 소요되며, 코너를 하나 만들 때는 500원이 추가로 듭니다.  
죠르디는 견적서 작성을 위해 경주로를 건설하는 데 필요한 최소 비용을 계산해야 합니다.  

예를 들어, 아래 그림은 직선 도로 6개와 코너 4개로 구성된 임의의 경주로 예시이며, 건설 비용은 6 x 100 + 4 x 500 = 2600원 입니다.

또 다른 예로, 아래 그림은 직선 도로 4개와 코너 1개로 구성된 경주로이며, 건설 비용은 4 x 100 + 1 x 500 = 900원 입니다.

도면의 상태(0은 비어 있음, 1은 벽)을 나타내는 2차원 배열 board가 매개변수로 주어질 때, 경주로를 건설하는데 필요한 최소 비용을 return 하도록 solution 함수를 완성해주세요.

## 제한사항
- board는 2차원 정사각 배열로 배열의 크기는 3 이상 25 이하입니다.
- board 배열의 각 원소의 값은 0 또는 1 입니다.
  - 도면의 가장 왼쪽 상단 좌표는 (0, 0)이며, 가장 우측 하단 좌표는 (N-1, N-1) 입니다.
  - 원소의 값 0은 칸이 비어 있어 도로 연결이 가능함을 1은 칸이 벽으로 채워져 있어 도로 연결이 불가능함을 나타냅니다.
- board는 항상 출발점에서 도착점까지 경주로를 건설할 수 있는 형태로 주어집니다.
- 출발점과 도착점 칸의 원소의 값은 항상 0으로 주어집니다.

## ver1. 방향 무시 2차원 vis기반 BFS
```c++
const int dy[]={-1,0,1,0};
const int dx[]={0,1,0,-1};
const int I=100, L=500;

int solution(vector<vector<int>> board) {
    const int N=board.size();
    vector<vector<int>> vis(N, vector<int>(N,N*N*L));
    queue<vector<int>> q;
    q.push({0,0,-1});
    vis[0][0]=0;    
    for(int y,x,dir,c;!q.empty();q.pop())
    {
        y=q.front()[0], x=q.front()[1];
        dir=q.front()[2]; //0:| 1:-
        c=vis[y][x];
        for(int i=0, ny,nx,nc,nd; i<4; i++)
        {
            ny=y+dy[i], nx=x+dx[i];
            if(ny<0||nx<0||ny>=N||nx>=N||board[ny][nx]) continue;
            
            nd=i%2, nc=c+I;
            if(dir>=0 && nd!=dir) nc+=L;
                
            if(nc<=vis[ny][nx])
            {
                vis[ny][nx]=nc;
                q.push({ny,nx,nd});
            }
        }
    }
    
    return vis[N-1][N-1];
}
```
### 시간복잡도
- 비용이 줄어들 때마다 재삽입되므로, 상한 없음
- 대략 O(N^2 * 칸당 갱신 횟수)

### 동작 원리
- vis\[y]\[x]에 칸 별 최소 비용 하나만 저장
- 큐에서 꺼낼 때 vis에서 비용을 다시 읽고, 4방향으로 확장
- 직선이면 +100, 방향이 꺾이면 +600을 더하고, 기존 값 이하이면 갱신해서 큐에 삽입

### 문제점
- 상태에 방향이 없어서 오답
  - 비용이 높아도 이후 직선으로 유리한 방향으로 도착한 경로가 값이 더 작은 경로에 막힘
- 큐에서 꺼낼 때 vis를 다시 읽기 때문에 큐에 들어갈 떄의 (방향/비용)과 어긋남
- <= 때문에 불필요한 재방문 생김

## ver2. 방향 포함 3차원 vis기반 BFS(SPFA형 최단 경로)
```c++
const int dy[]={-1,0,1,0};
const int dx[]={0,1,0,-1};
const int I=100, L=500;

int solution(vector<vector<int>> board) {
    const int N=board.size(), MAX=N*N*(L+I);
    vector<vector<vector<int>>> vis(N, vector<vector<int>>(N,vector<int>(2,MAX)));
    queue<vector<int>> q;
    q.push({0,0,-1,0});
    vis[0][0][0]=vis[0][0][1]=0;    
    for(int y,x,dir,c;!q.empty();q.pop())
    {
        y=q.front()[0], x=q.front()[1];
        dir=q.front()[2]; //0:| 1:-
        c=q.front()[3];
        if(c>vis[y][x][dir<0?0:dir]) continue;
        
        for(int i=0, ny,nx,nc,nd; i<4; i++)
        {
            ny=y+dy[i], nx=x+dx[i];
            if(ny<0||nx<0||ny>=N||nx>=N||board[ny][nx]) continue;
            
            nd=i%2, nc=c+I;
            if(dir>=0 && nd!=dir) nc+=L;
                
            if(nc<vis[ny][nx][nd])
            {
                vis[ny][nx][nd]=nc;
                q.push({ny,nx,nd,nc});
            }
        }
    }
    
    return min(vis[N-1][N-1][0],vis[N-1][N-1][1]);
}
```
### 시간복잡도
- 상태 수는 2N^2이고, 상태당 확장은 4번
- = O(N^2) (이론적 최악은 SPFA와 같은 label-correcting 방식이라 O(V*E)까지 가능)
- 우선 순위 큐(다익스트라)를 쓰면 O(N^2 logN)으로 상한 보장

### 동작 원리
- 상태를 (y,x,방향)으로 잡고 vis\[y]\[x]\[0/1](세로/가로)에 최소 비용 저장
- 큐에 {y,x,dir,cost}를 함께 삽입
- 꺼낼 때 c>vis\[...]이면 오래된 항목이라 건너뜀
- 시작점은 dir=-1이라 첫 이동에 코너 비용이 붙지 않고, 비교용 인덱스만 0으로 처리
- 엄격한 <비교로 갱신하고, 도착점은 두 방향 중 최솟값을 반환
